## Как не перепутать ID

Исторический пилот **выпуск №2 = BG-032**. Поэтому №33 уже оформлен как BG-033, №34 = BG-034, №35 = BG-035, и **здесь №36–50 = BG-036–BG-050**. Никогда не переписывать BG-032 ради №33. Старые номера вне серии (прошлые Remotion-фильмы в репозитории) не равны номерам этой кампании.

## 15 свежих сессий Claude Code

Для каждого эпизода отдельный новый чат, отдельная ветка `feature/bg-NNN-episode-XX`, отдельный PR **в документную ветку**, а при уже слитой цепочке — в согласованный целевой branch. Все короткие копируемые промпты сохранены в [PROMPTS-36-50.md](PROMPTS-36-50.md).

Каждая новая сессия обязана **читать `AGENTS.md`, `CLAUDE.md`, затем `SESSION_PROTOCOL.md`, `BRAND_FACTS.md`, `STYLE_GUIDE.md`, `PRODUCTION.md` и только один свой сценарий и один свой TASK**. Перед потерей контекста `handoffs/BG-NNN.md` плюс git commit.

## Постановка и факты

Единый фирменный стиль: белый, жёлтый, тёмно-синий, 2D-анимация, кыргызские буквы ү/ө/ң, Бишкек в VO/кадре, дети родителям на «сиз», безопасные места/ремни, белая легковая машина. Сначала причинный мост (вопрос → видимое действие/поиск → правило BalaGo), затем полезная информация. Запрещены резкие рекламные перебивки, слайд-шоу, фальшивый GPS, мгновенный «заказ», непроверенная безопасность и еда.

Группы не гарантируются; поиск до 2 недель — не гарантия успешной группы или старта. Бесплатная первая полная проба **после формирования группы**, оплата после выбора продолжать. Тариф/бонус/пропуски/сервисные сбои сверять по исходникам сайта перед публикацией. Условия №36–39 особо сверены на момент подготовки с `pricingPlans.ts`, `absenceDiscount.ts`, `serviceGuarantee.ts`: пакет 40→45, пропуски прошлого месяца (2–3→5%, 4–5→10%, 6–7→15%, 8+→20%) на следующий платный период максимум один месяц, при вине сервиса весь полный день бесплатен и не списывается из пакета.

**Финал:** одновременно видимы Бишкек, ссылка в профиле, WhatsApp **0998 08 38 28** не меньше 5 секунд, после голоса ещё 3 секунды, оба CTA в голосе. MP4 после утверждения: 1080×1920/30fps H.264/AAC, оригинал и отдельное превью, проверенные ссылки просмотра/скачивания. Не менять предыдущие видео, общие `Root`, `STATUS.json`, правила или общий workflow.

**Важно:** все №36–50 теперь `approved`; документ [APPROVAL-36-50.md](APPROVAL-36-50.md) официально подтверждает согласие владельца на создание видео. Отдельное повторное утверждение сценария не требуется. **Готовый MP4 не считается принятым, пока владелец не посмотрел его.**
