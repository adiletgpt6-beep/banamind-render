## Обязательные требования
Все ролики 2D 9:16, кыргызский, ~60–75 с под естественную речь, Бишкек, логичный сюжет **проблема → поступок/осознание → BalaGo → условия → CTA**. Белый фон, яркий жёлтый, тёмно-синий, белое авто. Не имитировать завершённую поездку до формирования группы. Уважительное обращение детей **сиз**.

Каждый финал: в голосе и кадре «Бишкек • Балдар үчүн такси», **профильная ссылка + WhatsApp 0998 08 38 28**; крупно ≥5 секунд, ≥3 секунды после последнего слова. Файл 1080×1920, 30fps, H264/AAC; обе реальные ссылки «посмотреть» и «скачать оригинал MP4» должны работать. Известная проблема ранней версии BG-001: резкий обрыв сюжета рекламой. **Не повторять.**
