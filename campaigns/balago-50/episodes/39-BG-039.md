# BalaGo-50 — выпуск №39 / BG-039 «Сапар үзгүлтүккө учурасачы?»

> **Статус: DRAFT, подготовлено 15.10.2026.** Сценарий записан по поручению подготовить проект до 50 выпусков; он **не утверждён отдельно владельцем для платного производства**. В этом документном PR нет MP4, синтеза речи или изменений предыдущих роликов.

**Название в ролике:** «Сапар үзгүлтүккө учурасачы?» — только кыргызский язык.
**Внутренний смысл по-русски:** Если по вине сервиса один этап поездки сорвался.
**Формат:** вертикальная рекламная 2D-анимация Remotion 9:16. После утверждения оригинал 1080×1920, 30 fps, H.264/AAC, faststart; ориентир 75–90 секунд, без ускорения естественной кыргызской речи и с читаемым CTA после финального слова.

## Идея и режиссёрская механика

- **Хук первых 3–6 секунд.** Условный маршрут в двух кадрах: утро до школы выполнено, обратный путь помечен «Кызматтын себебинен аткарылган жок». Появляется вопрос о полном дне.
- **Главная проверяемая мысль.** Если утром или после уроков один из двух этапов сорвался по причине сервиса, весь полный день бесплатен и из пакета не списывается. Не смешивать с пропусками ребёнка.
- **Визуальная форма, не повторяющая прежнюю серию.** анимация двустороннего бумажного билета, при сбое одна сторона теряет цвет, весь билет становится «0 сом».
- **Драматургическое отличие.** Один сложный гипотетический случай с ответственным взрослым; никаких опасных детей, оставленных ждать одних.
- **Причинный мост к бренду.** Сначала у героя есть реальный вопрос / видимое самостоятельное действие, из него возникает понятная потребность, затем родитель знакомится с фактическими правилами BalaGo. Для прямой инфографики вместо выдуманного семейного конфликта идёт «вопрос → демонстрация правила → следствие». Резкое «появился логотип вместо развязки» запрещено.

## Монтажный и безопасностный план

1. **Уникальная форма:** анимация двустороннего бумажного билета, при сбое одна сторона теряет цвет, весь билет становится «0 сом». Использовать выразительные 2D движения тела, рук, предметов и мягкий параллакс, а не шесть статичных слайдов; реалистичные позы, не «ломающиеся» шеи, без слепящих вспышек.
2. **Драматургия:** Один сложный гипотетический случай с ответственным взрослым; никаких опасных детей, оставленных ждать одних. Переход к названию BalaGo должен быть понятен зрителю даже без звука. Сцена поиска/чтения правил или прямое объяснение условий обязательно перед финалом.
3. **Подтверждённые условия:** Если утром или после уроков один из двух этапов сорвался по причине сервиса, весь полный день бесплатен и из пакета не списывается. Не смешивать с пропусками ребёнка. Любые цифры и обещания сверить с актуальным сайтом `adiletzainidinov/BalaGo` на момент публикации. Сайт открывает подготовленное сообщение в WhatsApp: отправку пользователь делает сам; имитация подтверждённой сервером заявки недопустима.
4. **Маршрут и деньги:** одна полная поездка = утром **үй → мектеп**, после уроков **мектеп → үй**. Подбор 3–4 совместимых детей только с учётом безопасных мест и ремней, старт не обещан сразу; первоначальный поиск до 2 недель не гарантирует найденную группу. Бесплатная **первая полная** проба только ПОСЛЕ формирования группы, пакет и оплата только ПОСЛЕ решения родителя продолжать. Пробный полный день отдельно от бонусов 20+2 и 40+5.
5. **Безопасность:** только белая легковая машина, если машина нужна по сюжету; ремень на реально существующем месте, никто не пишет за рулём, ребёнка не оставлять одного и не передавать незнакомому человеку. Детские реплики к родителям только на **сиз/сиздер**. Никаких еды, сладостей, газированных напитков, неподтверждённых автокресел/проверок водителя, постоянного GPS, авто-push и гарантии безопасности.

Балаңызды алдын ала каттоо үчүн профилдеги шилтемеге өтүңүз же экрандагы номерге WhatsApp аркылуу жазыңыз. BalaGo менен жолго чыгалы!».
