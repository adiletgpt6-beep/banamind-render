## Нумерация
Серия BalaGo-50 использует глобальные идентификаторы каталога: 1-й видеоролик = BG-001, 2-й = BG-032 (пилоты). Теперь 3-й = BG-002, 4-й = BG-003, ..., 10-й = BG-009. Названия из исходного каталога IDEAS.md сохраняются. Номера BG не обязаны совпадать с порядковым номером выпуска.

## Авторизация
Владелец разрешил **подготовить и производить ролики 03–10**. Диалоги ниже — производственные редакции v1, которые можно улучшать только для естественности кыргызской речи и соответствия длительности, не меняя драматургии и подтверждённых фактов без ревью. **Не утверждать, что владелец уже посмотрел каждый из новых сценариев или MP4.** Готовые видео передать на его просмотр до merge финальных PR.

## Git и независимость
Базовый PR #50 ещё открыт. Ветка этой партии: `feature/balago-50-episodes-03-10`, основана на `feature/balago-50-campaign-plan`. Запуск каждого отдельного Claude Code чата:
- Прочитать ROOT `AGENTS.md` и `CLAUDE.md`, затем `SESSION_PROTOCOL.md`, `STYLE_GUIDE.md`, `BRAND_FACTS.md`, конкретный сценарий и своё `production/TASK_*.md`.
- Создать **свою** ветку от ветки партии (если пакет ещё не слит), PR направить **в ветку партии**, не в main, не в PR #51 (BG-001) или PR #52 (BG-032). Если пакет уже влит, базу определить по реальному Git.
- **Семь чатов могут работать параллельно**. Не менять общие `STATUS.json`, `src/Root.tsx`, `src/campaign50/Root.tsx`, `src/campaign50/index.ts` или чужие кампанийные композиции/MP3; создавать независимую точку входа `src/campaign50/bg-NNN/index.ts` и локальный Root. Массовый workflow старых роликов не запускается. При интеграции — отдельное аккуратное обновление общего индекса.
- Рендер только свой. Не пытаться объединять семь PR одновременно в main. Общие интеграционные конфликты разрешать **последовательно** при объединении.

- Каждое готовое видео: две фактически проверенные ссылки **«Посмотреть видео» и «Скачать видео в хорошем качестве»**, original 1080×1920/30fps/H.264/AAC, мобильная копия при наличии. Проверить содержимое MP4, а не только статус GitHub Actions.
