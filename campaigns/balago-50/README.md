# BalaGo-50 — вход для человека и ИИ

**Цель:** 50 уникальных рекламных 2D-роликов в Бишкеке для BalaGo. Один ролик ≈60 секунд, вертикальное MP4 1080×1920/30 fps, на кыргызском. Репозиторий уже содержит ранее сделанные видео — **не трогать их**.

## С чего начинать каждую новую сессию Claude Code
1. Прочитать корневые `AGENTS.md` и `CLAUDE.md` — высший приоритет, ничего не переопределять.
2. Прочитать `campaigns/balago-50/SESSION_PROTOCOL.md`, `BRAND_FACTS.md`, `STYLE_GUIDE.md`, `PRODUCTION.md`, `STATUS.json`.
3. Открыть **ровно один** утверждённый сценарий `scripts/BG-NNN.md` и соответствующее задание `production/TASK_BG-NNN.md`.
4. Если у ролика есть `handoffs/BG-NNN.md`, восстановить прогресс по нему и текущим файлам Git. Нельзя принимать чекпойнт на веру без сверки с рабочим деревом.
5. Работать только в отдельной ветке ролика; открыть отдельный PR, проверить всё и выдать прямые ссылки на MP4 для просмотра и скачивания.

## Утверждённые пилоты
- [BG-001 — Восемь открытых вкладок](scripts/BG-001.md) → [задание Claude Code](production/TASK_BG-001.md)
- [BG-032 — 7, 12 или 20 километров?](scripts/BG-032.md) → [задание Claude Code](production/TASK_BG-032.md)

Оба сценария утверждены владельцем 12.10.2026. **Исходники композиций и рендер ещё не созданы.** Каталог остальных 48 идей находится в [IDEAS.md](IDEAS.md); они не утверждены как полные сценарии.

## Чат ChatGPT ≠ источник истины
Можно менять чаты и сессии: вся ценная информация сохраняется в репозитории и PR. После каждого существенного этапа обновлять checkpoint; история разговора без коммита не считается сохранением проекта.

## Как сделать первый шаг
В Claude Code открыть именно этот репозиторий **после слияния PR #50** и написать:

`Прочитай campaigns/balago-50/README.md и выполни production/TASK_BG-001.md. Делай только BG-001, не BG-032, следуя всем правилам. Создай отдельную ветку и PR. Начинай с анализа репозитория и плана минимальных изменений.`

Для второго пилота аналогично заменить `001` на `032` и открыть отдельную новую сессию. При незалитом PR #50 работать лишь с его веткой и не начинать новый PR от main без нужных файлов.
