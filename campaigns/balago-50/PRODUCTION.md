# Порядок производства 50 роликов

## Статусы
`idea` → `draft` → `approved` → `in_production` → `review` → `done` (либо `blocked`). Статус `approved` задаётся только после явного согласования сценария пользователем. Наличие файла сценария не означает одобрение.

## Команды человеку и Claude Code
1. Перед работой прочитать корневые AGENTS.md и CLAUDE.md, затем BRAND_FACTS.md, STYLE_GUIDE.md, выбранный сценарий и STATUS.json.
2. Выполнять только номер `BG-NNN`, а не все 50 разом; не запускать старые композиции без необходимости.
3. Если сценарий `draft`, **не рендерить** и не тратить кредиты. Предоставить сценарий на согласование.
4. Для утверждённого сценария создать отдельную композицию (не переписывать старые), изолировать исходники и звуковые дорожки, не допускать конфликтов путей с существующим проектом.
5. Сначала дешёвый предпросмотр, проверка хука, титров, анимации, кыргызских голосов, верных фактов. Затем оригинал 1080×1920 30 fps.
6. Новые workflow GitHub Actions должны **точечно** собирать выбранный ролик по параметру/пути, не рендерить весь каталог при каждом пуше. Не публиковать дорогостоящий массовый запуск без решения пользователя.
7. Выдать **две проверенные ссылки**: смотреть видео и скачать оригинальный MP4, как определено в AGENTS.md. Отметить состояние в STATUS.json после реальной проверки результата.
8. Каждый ролик — отдельный PR и отдельный цикл корректировок. Первые 2 пилота выпускаются только после согласования обоих сценариев, последующие — партиями по 3–5.

## Структура
`campaigns/balago-50/` — факты, идеи, сценарии, продакшн, статусы; `src/campaign50/` — будущие композиции; `public/assets/campaign50/` и `public/audio/campaign50/` — отдельные ассеты (создать только при реализации); `.github/workflows/` — выборочные workflow после двух пилотов. Корневые правила не заменять и не удалять.

## Контроль качества
Блокировка релиза если отсутствует город, нет одного из двух CTA, неверен номер, нарушено обращение «сиз», плохая кыргызская дикция, ошибочны цифры или файл не воспроизводится. Автотесты могут проверить текст/кодек/длительность; артикуляцию, художественное качество и соответствие голоса необходимо смотреть/слушать.

## Управление контекстом ChatGPT и Claude Code

Каждый ролик выполняется в **отдельной сессии Claude Code**, не одной сессией на 50 видео. Переписка не является источником истины: истина — GitHub, текущая ветка, корневые правила, сценарий и обновлённый журнал. Стартовать с `campaigns/balago-50/README.md`, затем `SESSION_PROTOCOL.md` и задач пилотов. После крупных правок записывать checkpoint в файле сессии прежде чем начинать новый чат/компактизацию. **Нельзя** делать вывод «готово» на основании старой переписки — проверять файлы, коммит, CI и MP4.
