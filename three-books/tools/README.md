# Проверка и галерея
## Документация
`node three-books/tools/validate.mjs`
Проверяет реестр, текущие документы, 200 исходных требований, ровно 100 новых на следующий выпуск, ID/дубли, ссылки и переход к производству. Смысловая новизна требует редактора; этот код её не доказывает.

## Реальные пять обложек
После создания пяти оригиналов заполнить `DELIVERY.json`: `episode_id`, `revision_id`, `thumbnails` из пяти записей с `path` (относительно DELIVERY) и `label`. Ссылки просмотра/скачивания дополняются после проверки выдачи.
`node three-books/tools/build-gallery.mjs three-books/episodes/TB-002/DELIVERY.json three-books/episodes/TB-002/assets/gallery`
Скрипт проверяет наличие, формат PNG/JPEG, точные 1280×720 и отсутствие побайтовых копий; затем создаёт страницу с пятью превью, открытием оригинала и скачиванием. Смысловое различие оценивается по контакт-листу отдельно.
Открывать через существующий приватный Preview/порт Claude Code. Само создание index.html не подтверждает внешний доступ владельца с телефона. После реальной проверки записать URL в DELIVERY.
Это утилита выдачи готовых изображений; она не генерирует обложки и не запускает рендер.
