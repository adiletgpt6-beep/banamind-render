# Краткая действующая база
Полный исходный архив: BASELINE-001.json. Приоритетные уточнения: ../CURRENT_RULES.md.
Пока выпущен только первый фильм и нет подтверждённых результатов применения новых сотен, новые универсальные решения не объявляются проверенными.
После каждого выпуска координатор добавляет полезные стабильные решения с ID исходного улучшения и ссылкой на доказательство; контекстные правила остаются в папке выпуска. Ошибочные не удаляются, а помечаются superseded с причиной.
Базовые опоры: самостоятельный смысл; три источника; ясная причинность; русский голос; счёт денег без противоречий; читаемые частицы; комфорт; 30:00 Full HD; пять реальных обложек и названий; честная выдача; GitHub-память.
