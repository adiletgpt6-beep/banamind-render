# Область действия: three-books/**
Это отдельная серия TB: три книги объединяются в оригинальную историю из цветных частиц. Корневые рекламные требования BalaGo по кыргызскому языку, Бишкеку, WhatsApp и CTA здесь неприменимы: владелец явно задал русский горизонтальный YouTube-формат.

Читать README.md → MASTER_CLAUDE.md → HANDOFF.md → STATUS.md → REGISTRY.json → папку своего TB-ID. Для этой серии эти файлы являются постоянной точкой входа; прежние чаты не нужны для основных правил.

Обязательно:
- Не терять уже одобренный первый фильм и его материалы.
- Реальные три источника перед содержательной подготовкой нового выпуска.
- Собственный сюжет, самостоятельные формулировки, отсутствие книжных атрибуций в зрительском результате.
- Ровно 100 новых улучшений на каждый последующий выпуск по RULES_POLICY.md; не считать старые 200 новыми.
- Пять названий, пять реальных обложек, просмотр и скачивание.
- Обновлять STATUS после каждого этапа и сохранять изменения в GitHub.
- Выполнять этапы без обязательного ожидания нового подтверждения, когда ресурсы и входные данные доступны.
- Не выдумывать готовые MP4, изображения, прослушивание, проверки или ссылки.
- Не изменять чужие ветки, фильмы, тарифы и секреты.
- Не запускать массовый/повторный рендер из-за правки документации.

Исключения первого задания перечислены в CURRENT_RULES.md. Архивный промпт первого фильма — исторический источник; он не отменяет новые решения владельца.
