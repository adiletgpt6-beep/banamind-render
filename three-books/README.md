# Три книги → одна новая история (TB)
Единая память серии для ChatGPT и Claude Code. Репозиторий: `adiletzainidinov/balago-video`. Рабочая ветка системы при создании: `docs/three-books-production-system`. Документы действуют уже в этой ветке; наличие в main и merge PR всегда проверять.

Система сохранена в [PR #133](https://github.com/adiletzainidinov/balago-video/pull/133). Рабочие документы доступны в его ветке до merge.

## Постоянный формат
- Один выпуск = три реально предоставленные книги → самостоятельная история, 30:00, 1920×1080, 16:9, 30 fps, H.264/AAC.
- Русские сценарий, приятная озвучка, экранные подписи, динамические субтитры и SRT/VTT.
- Цветные светящиеся точки формируют персонажей, предметы и осмысленные действия.
- Персонаж выбирается под историю. Нокса можно сохранить; новый герой разрешён владельцем.
- Каждый следующий выпуск отличается конфликтом, событиями, постановкой и выводом. Замены имён и декораций недостаточно.
- Имена авторов и названия книг отсутствуют во всех зрительских материалах. Внутренние источники и карта происхождения идей сохраняются.
- Для каждого выпуска: 5 названий + фаворит, 5 реально разных обложек 1280×720 + контакт-лист, работающие просмотр и скачивание.
- Каждый новый выпуск получает ровно 100 новых проверяемых улучшений; накопленная база не теряется.
- Производство в разрешённом объёме идёт без дополнительных согласований. YouTube-публикация не входит в задание.

## С чего начать новую сессию
1. Прочитать [AGENTS.md](AGENTS.md), [MASTER_CLAUDE.md](MASTER_CLAUDE.md), [HANDOFF.md](HANDOFF.md), [STATUS.md](STATUS.md), [REGISTRY.json](REGISTRY.json).
2. Открыть `episodes/TB-NNN/TASK.md`, `STATUS.md`, сценарий и последние подтверждённые результаты.
3. Проверить живые ветки/PR/релизы. Записи в документах — снимки, не замена текущему GitHub.
4. Прочитать [RULES_POLICY.md](RULES_POLICY.md), исходную базу и 100 правил данного выпуска.
5. Продолжить ближайший незавершённый шаг. Не начинать готовый фильм заново.
6. Короткие сообщения владельца находятся в [PROMPTS.md](PROMPTS.md).

## Структура
`episodes/` — задания, состояние, сценарии, новизна, карты источников, метаданные и ссылки.
`rules/` — исходные 200 требований и накопленные пакеты по 100.
`templates/` — формы нового выпуска.
`tools/validate.mjs` — недорогая проверка документации, без TTS и видеорендера.

Серия TB независима от BanaMind (BM), рекламы BalaGo и курса уроков. Переиспользовать проверенные технические компоненты разрешено, копировать чужие сюжеты и менять чужие выпуски — нет.
