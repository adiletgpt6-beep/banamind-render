# Отпечаток TB-001 — для сравнения следующих историй
Это описание первого фильма, не шаблон следующего.
- Главная проблема: доход увеличивается, а чувство свободы и остаток не улучшаются.
- Герой: янтарный лис Нокс, бирюзовая грудь, длинный хвост; ремесленная мастерская.
- Форма: последовательная история обучения, 15 глав по 2 минуты.
- Начало: 800 → 1000 заработка, расходы поглощают прибавку.
- Предметы: сосуд с огнями, компас, мост с опорами, шкатулка.
- Причинная цепочка: заработать больше → увидеть рост расходов → сохранить часть → заметить демонстративные покупки → уточнить цель → улучшить навык → устать от «ещё» → пережить поломку с запасом → пересмотреть способ → увидеть роль времени → признать разные условия → отказаться от непонятного обещания → связать решения → проверить неделю → открыть смысл свободного вечера.
- Условный счёт: 700 + 200 + 100 = 1000; три взноса по 100 = 300; ремонт 180 → остаток 120.
- Эмоциональное движение: узнавание → любопытство → умеренное напряжение → ясность и облегчение.
- Финал: шкатулка становится окном на мастерскую, близких и свободный вечер.
Для TB-002 обязательны другие проблема, причинная последовательность и финальное разрешение плюс ещё минимум два содержательных отличия.
