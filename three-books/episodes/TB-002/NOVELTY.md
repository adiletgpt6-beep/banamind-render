# TB-002 — проверка самостоятельности истории

Дата: 2026-10-21. Сравниваем только реально существующий TB-001; других двух предыдущих TB-выпусков в реестре нет. BM и рекламные серии не выдаём за предшествующие TB.

## Причинные цепочки

TB-001: заработок → увеличение желаний → пустой остаток → решение сохранять часть → несколько месяцев накопления → непредвиденный ремонт → запас смягчает последствия → переосмысление достаточности → шкатулка раскрывает ценность времени.

TB-002: сложный короб не покупают → громкое объяснение ничего не меняет → наблюдение за Наей обнаруживает конкретное неудобство → узкая задача исключает лишние функции → понятное предложение привлекает проверку → проверка выявляет наклон основания → исправление и повторный опыт → расчёт цены и правильное место → две покупки с ограниченными выводами → отказ обещать недоступный объём → следующий маленький тест.

## Что допускается переиспользовать

Движок частиц, принцип устойчивых силуэтов, шрифты с лицензией, кэш TTS, измерения аудио, экспорт, сборку сегментов, проверку файла и приватную выдачу. Код брать чтением из закреплённой версии TB-001; сюжет, персонажа, сцены, тайминг 15×120 и записи голоса не переносить.
