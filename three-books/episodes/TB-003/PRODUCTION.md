# TB-003 — конкретный порядок работы

Рабочая ветка `feature/three-books-tb-003-rin`. База `docs/three-books-production-system`; проверить текущий PR/HEAD в живом GitHub перед работой. Первое действие не требует TTS, сети или старого чата:

```bash
python3 scripts/three-books/tb003/prepare_sources.py
```

## Источники и точность

Команда стандартной библиотекой Python проверяет версии конвертера и индексов, канонический текст, оригинальные части, итоговые ZIP/FB2 и CRC. Затем даёт `.tb003-work/sources/S01.txt` … `S03.txt` и INDEX.md. Каталог сам содержит игнорирующий .gitignore и не попадает в коммит. Источники не копировать в public.

Для проверки формата выполнить с `--originals`, затем повторить конвертацию через `scripts/three-books/extract_fb2_zip.py`, сравнить SHA нормализованного TXT. Оригинальные книги сохранены целиком, картинки не притворяются распознанным текстом. Углублённое чтение делать по SOURCE_MAP и индексу, расширяя диапазоны по вопросам, не выводя все книги в контекст сразу.

## Сценарий и runtime

Полная речь уже в SCRIPT, 62 исходных блока. Девять частей и 45 сцен заданы предварительно. Claude может естественно отредактировать речь и разделение блоков с записью изменений, сохраняя историю, числовой смысл и 100 FROZEN механизмов. После редактуры обновить зависимые данные.

Получить через настроенный remote нужные refs из REFERENCE и прочитать закреплённые технические компоненты. Не сливать всю TB-002 ветку и не копировать голосовые блоки по совпавшим именам. Импортировать выбранные GL/text/shapes/инструменты с записью исходного commit/path и нового пути в IMPORTS.md. Сохранить лицензии точных шрифтов.

Новый runtime — `src/three-books/tb003/`, новые инструменты — `scripts/three-books/tb003/`, при необходимости зрительский preview — `public/three-books/tb003/`. Создать риги черепахи, цапли и лаконичного Сая. Риги лиса/енота не заменяют новых персонажей. В парсере удалить жёсткий assert 65 и конкретные пути TB-002; входом являются реальные данные TB-003.

## Звук и измеренное время

Начать с уже доступного George и настроек из REFERENCE, провести короткую внутреннюю пробу нового текста. Затем кэшируемая речь, проверка ASR и фактическое измерение блоков. Для каждого интервала посчитать голос + обязательное действие + паузы. Если бюджет отрицательный, редактировать или перераспределять время, а не обрезать слово и не прятать сцену за ускорением.

Точное полное время — 1800 секунд. Предварительные таймкоды не подтверждают длительность TTS. Финальные главы, SRT/VTT, captions и события строятся по одному measured timeline. Не добавлять музыки и чужих реплик.

## Внутренний пилот и полный фильм

Пилот: открытие с последующим возвратом к понедельнику; самостоятельный ответ Таи/разбор права решать; короткая финансовая ветвь. Проверить, что остановились решения, а не город, что персонажи узнаваемы и числа не складывают альтернативы последовательно. Проверить реальный H.264 и звук. Пилот не является обязательной остановкой для утверждения владельцем.

После исправлений полный рендер по абсолютным кадрам и seed: интервалы без пропусков `[0,54000)`, с возможностью продолжить только невалидный сегмент. Технические сегменты могут пересекать границы девяти частей. Полное техническое декодирование MP4, формат, звук, число кадров и хвост проверять по файлу. Художественный просмотр/прослушивание описывать с настоящим охватом.

Публикация приватных артефактов через существующий путь CI, если прямой доступ Claude к Releases ограничен. Отдельный тег **`tb-003-film`**, собственный pilot tag. Не менять nox-film и tb-002-film.

## Пять обложек и релиз

Выполнить пять различных THUMBNAILS_BRIEF, сделать реальные 1280×720, contact sheet и 320×180. Проверить картинки, пары с названиями и декодирование в галерее. Владельцу нужен доступный просмотр и отдельная загрузка каждого оригинала, localhost не является такой ссылкой для телефона.

Набор зрителя: `TB003_30min_RU_1920x1080.mp4`, `TB003_preview_960x540.mp4`, `TB003_narration_RU.wav`, `TB003_subtitles_RU.srt/.vtt`, `TB003_script_RU.txt`, `TB003_youtube_RU.txt`, пять `TB003_thumbnail_0N.png`/JPEG, контакт-листы и index.html. Реальные имена/форматы записать в DELIVERY.

Загружать по allowlist после проверок. Ни original.zip.part, ни TXT источника, ни gzip, ни приватные индексы/карты и словари не входят в зрительские assets. У внутреннего QA может быть очищенная зрительская копия без книжных атрибуций. YouTube не публиковать.

Не завершать работу общим планом при доступных ресурсах.
