# MUSLIM KIDS — Эксперимент 012 «Слои реальности»

**«Что скрывается внутри удивительного мира?»** — 60‑секундный образовательный
3D‑мультфильм (5–12 лет, русский язык) по теме суры «Аль‑Имран», 3:190–191.
Технология эксперимента: **3D layer separation / exploded view / scientific
cutaway / spatial reassembly** — объекты раскрываются на крупные осмысленные
объёмные слои и собираются обратно.

Отдельный проект: BalaGo и другие эксперименты не затрагиваются.

| Параметр | Значение |
| --- | --- |
| Композиция | `MuslimKidsLayersOfReality012` |
| Формат | 1080×1920, 30 fps, 1800 кадров (60 с) |
| Кодеки | H.264 (yuv420p, CRF 16) + AAC 192 кбит/с |
| Файл | `output/final/MuslimKids_LayersOfReality_012.mp4` (в Git не хранится) |

## Сцены

1. **0–6 с — Загадочная Земля.** Планета вращается, по октанту проступает
   золотой шов, сегмент слегка выдвигается на «Посмотри!».
2. **6–15 с — Земля и её слои.** Вращение → смена дня и ночи (подписи
   «ДЕНЬ/НОЧЬ», стрелка вращения). Затем отдельно: атмосферная оболочка
   поднимается, октант раскрывается радиально на кору, мантию, внешнее и
   внутреннее ядро (подписи, «Схема. Не в масштабе»), поэтапная сборка.
3. **15–25 с — Горы.** Камера ныряет к Тянь‑Шаню, совмещающий переход в
   горную диораму (хребты, снег, река, лес, облака). Передний блок
   выдвигается: поверхность поднимается, складчатые пласты пород расходятся,
   вид сбоку, сборка.
4. **25–35 с — Лист.** Дерево → выделенный лист → увеличенная модель листа:
   рентген‑прозрачность, светящиеся жилки, раскрытие на 5 тканей, выноска
   «Увеличенная схема» с клетками (палисадные и губчатые клетки с
   хлоропластами и ядрами, эпидермис без хлоропластов, проводящий пучок,
   устьице).
5. **35–44.6 с — Великое раскрытие.** Камера отдаляется: Земля, горы, лист и
   дерево в одной 3D‑композиции на фоне звёзд, все раскрыты, затем
   одновременная обратная сборка. «РАЗМЫШЛЯЙ О ТВОРЕНИИ» — 3:190 (изложение
   смысла).
6. **44.6–53.2 с — Слова из Корана.** Модели собраны, камера почти
   неподвижна, мир приглушён; неподвижный текстовый слой «Господь наш! Ты не
   сотворил это понапрасну» — 3:191, часть аята, перевод смысла Э. Кулиева.
7. **53.2–60 с — Посмотри глубже.** Земля и лист; лист на миг раскрывается на
   2–3 слоя и собирается; «ПОСМОТРИ ГЛУБЖЕ!» и типографическая заставка
   MUSLIM KIDS (официального логотипа в проекте нет — новый не придуман).

## Архитектура

Один общий 3D‑мир (Three.js + React Three Fiber через `@remotion/three`);
камера путешествует между моделями, а финальная композиция — это те же
объекты, увиденные вместе. Всё — чистые функции номера кадра: кадр N рендерится
одинаково независимо от предыдущих; процедурные данные — с фиксированными seed.

| Модуль | Файл | Назначение |
| --- | --- | --- |
| LayersOfRealityEngine | `src/engines/LayersOfRealityEngine.tsx` | Холст трека: камера, свет, видимость моделей |
| LayerSeparationEngine | `src/engines/LayerSeparationEngine.ts` | Спецификация слоя (типы A–F), циклы раскрытия, состояния ASSEMBLED → SEPARATING → EXPLODED/INSPECTING → REASSEMBLING → COMPLETE, позы (дуга, slerp, масштаб) |
| ExplodedViewController | `src/engines/ExplodedViewController.ts` | Логика раскрытия по объектам: сферическая (Земля), геологическая (горы), анатомическая (лист); тайминги; вращение Земли |
| LayerGeometryEngine | `src/engines/LayerGeometryEngine.ts` | Замкнутые объёмные слои: сферический сектор с гранями среза, слой между двумя поверхностями рельефа, толстая оболочка по параметрической поверхности |
| ScientificCutawayEngine | `src/engines/ScientificCutawayEngine.ts` | Научные модели: радиусы и цвета оболочек Земли, рельеф и складчатые пласты, форма и жилкование листа |
| LayerCameraController | `src/engines/LayerCameraController.ts` | Ключи камеры в орбитальных координатах, монотонная кубическая интерполяция (дуги без рывков) |
| LayerLightingSystem | `src/engines/LayerLightingSystem.tsx` | Key (солнце, мягкие тени), fill, rim, hemisphere; пресеты по сценам |
| LayerMaterialSystem | `src/engines/LayerMaterialSystem.ts` | Поверхность Земли, атмосфера (шейдер френеля), срезы с самосвечением по цвету слоя, породы, ткани листа, клетки |
| SceneTransitionSystem | `src/compositions/shots.ts` | Три трека камеры и совмещающие растворения |
| AudioSyncSystem | `src/compositions/cues.ts` + `src/timeline.json` | Все реплики измерены, анимация привязана к фактическим таймингам речи |
| TypographySystem | `src/components/Typography.tsx` | Unbounded + Manrope (OFL), подписи с выносками, привязанными к 3D‑точкам |

Модели: `components/Earth3D.tsx` (Земля + разрез), `MountainLandscape.tsx`
(горы + геологический срез), `GrowingTree.tsx`, `Leaf3D.tsx` (лист + ткани),
`PlantCell.tsx` (клетки), `Stars.tsx`. Оверлеи сцен: `src/scenes/Scene0N*.tsx`.

Движок переиспользуем: новый объект = геометрия слоёв + `LayerSpec[]` +
`ExplodeCycle[]` + ключи камеры.

## Ассеты (всё сгенерировано, без покупок)

- **Земля** — `scripts/make-textures.py`: собственная стилизованная текстура
  по контурам суши Natural Earth (public domain, пакет `world-atlas`),
  карта шероховатости, бесшовные облака.
- **Озвучка** — `scripts/generate-voice.py`: локальная нейросеть Piper
  `ru_RU-denis-medium` (через sherpa‑onnx, бесплатно). Каждая фраза
  синтезируется в 6 дублях, выбирается самый разборчивый по распознаванию
  Whisper small; темп не изменяется. Тайминги → `src/timeline.json`.
  `scripts/check-voice.py` — контроль распознаванием (CER).
- **Звук** — `scripts/make-sfx.py`: без музыки; мягкие воздушные звуки
  раскрытия, тихие касания при сборке, ветер, шелест листьев.
- **Шрифты** — Unbounded и Manrope (SIL OFL) из `@fontsource`.

## Запуск

```bash
cd muslimkids-layers-of-reality
npm install
npm run studio                       # предпросмотр

# (необязательно) пересоздать ассеты
node scripts/export-land.mjs && python3 scripts/make-textures.py
pip install sherpa-onnx soundfile    # модели: см. generate-voice.py
python3 scripts/generate-voice.py && python3 scripts/check-voice.py
python3 scripts/make-sfx.py

# рендер (Linux без GPU: WebGL через ANGLE/SwiftShader)
REMOTION_CHROME=/path/to/chrome-headless-shell \
npx remotion render MuslimKidsLayersOfReality012 \
  output/final/MuslimKids_LayersOfReality_012.mp4 --gl=angle --concurrency=4
node scripts/render-stills.mjs       # контрольные кадры → output/previews/qa
```

## Научная и религиозная корректность

- День и ночь объясняются только вращением Земли; слои показаны отдельной
  мыслью после этого.
- Ядро — не «огненный шар», мантия — твёрдая порода (лёгкая полосатость
  конвекции), а не океан лавы; кора утолщена — подпись «Схема. Не в масштабе».
- Пласты пород изогнуты и наклонены — «Схематическая модель».
- Клетки растений: клеточные стенки, хлоропласты (нет в клетках эпидермиса,
  есть в замыкающих клетках устьица), ядра, межклетники, проводящий пучок —
  «Увеличенная схема».
- Аллах, пророки, «процесс сотворения» не изображаются; текст Корана не
  деформируется и не анимируется как 3D‑объект. 3:190 дан как изложение
  смысла, цитата 3:191 — часть перевода смысла Э. Кулиева (проверено по
  тексту перевода: «Господь наш! Ты не сотворил это понапрасну»).
