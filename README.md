# BalaGo Video

Рекламные ролики BalaGo — сервиса перевозки детей из дома в школу и обратно в Бишкеке.
Проект на [Remotion](https://www.remotion.dev) (React + TypeScript): видео описано кодом,
все анимации зависят от номера кадра, поэтому экспорт совпадает с предпросмотром.

## Ролик `BalaGoMorningStory` — «Бир таң» (≈3 мин, голоса персонажей)

Анимационная 2D-история одного утра семьи (вертикально 1080×1920, 30 fps,
`out/balago-morning-story.mp4`). Папа неожиданно просит маму отвезти дочь в
школу; первое такси стоит на карте и не отвечает, второе — в пробке; дочь
опаздывает в школу, мама — на работу. Днём мама видит рекламу BalaGo и
оставляет предварительную заявку. Главная мысль: дорогу ребёнка в школу
можно организовать заранее, а не решать заново каждое утро.

BalaGo показан только как готовящийся к запуску сервис (предварительная
запись): без «уже возим», гарантий, проверок водителей, цен, приложения и
дат. Обычные таксисты не показаны «плохими»: первый просто не отвечает,
второй стоит в настоящей пробке. Учитель и руководитель делают замечание —
без штрафов. Белый седан BalaGo (Volkswagen Polo 2010) стоит у дома — без
пассажиров и без «такси»-раскраски.

Сцены (`src/morning-story/script.ts`): обычное утро → план изменился → мама
вызывает такси → первое такси → второе такси далеко → пробка → такси
приехало → опоздание в школу → опоздание на работу → главная мысль → звонок
в BalaGo → финал → финальный экран (логотип, «Балдар үчүн такси»,
«ҮЙ → МЕКТЕП → ҮЙ», «Алдын ала каттоо жүрүп жатат», «Баланы каттоо»,
неподвижный номер **0998 08 38 28** со значком WhatsApp, «Профилдеги шилтеме
аркылуу»). WhatsApp: https://wa.me/996998083828

**Голоса.** Каждая роль — свой голос ElevenLabs (eleven_v3, ky, stability
0.5, similarity 0.8, seed 51), каждая реплика — отдельный файл.
Голоса и запасные варианты — `MS_VOICES` в `src/morning-story/script.ts`
(если голос недоступен, берётся следующий; один голос — одна роль).
Итоговые голоса записаны в manifest.

**Файлы озвучки** — `public/audio/morning-story/`:
- `<реплика>.mp3` — по файлу на реплику;
- `manifest.json` — персонаж, текст, voice ID, модель, параметры, длительность, путь, положение на шкале;
- `timeline.json` — начала сцен и реплик.

Монтаж строится по **реальным** длительностям (`storyTimeline.ts`).

**Повторный рендер не обращается к ElevenLabs:** у каждой реплики хэш
(текст, тег, голос, модель, настройки, seed). Пока он не изменился,

**Команды:**
- `npm run audio:voice:story` — недостающие реплики (нужен `ELEVENLABS_API_KEY`);
- `npm run audio:music:story` — музыка и эффекты;
- `npm run stills:story` — контрольные кадры;

## Как заменить картинки

Материалы лежат в `public/assets/`:

| Файл | Что это |
| --- | --- |
| `logo.png` | Логотип BalaGo (круглый, обрезается по кругу) |
| `portrait.jpg` | Портрет водителя |
| `car-exterior.jpg` | Белый Volkswagen Polo снаружи |
| `car-interior.png` | Салон |

Самый простой способ — загрузить новый файл **с тем же именем** поверх старого
(на GitHub: папка `public/assets` → **Add file → Upload files**). После commit
Actions сам соберёт новое видео.

Если имя или формат другие (например, `.png` вместо `.jpg`), поменяйте путь в
`ASSETS` в `src/config.ts`. Кадрирование фото настраивается в `PHOTO_CROP` там же:

- `focusX` / `focusY` — точка фокуса в процентах от ширины/высоты (лицо, машина);
- `zoomFrom` → `zoomTo` — мягкое приближение за время сцены (1 = без увеличения).

Пропорции фото всегда сохраняются: картинка заполняет рамку и обрезается вокруг точки фокуса.
Перед загрузкой фото с телефона лучше удалить из него геоданные (EXIF/GPS).

## Где менять тексты, цвета и тайминги

Всё в одном файле — `src/config.ts`:

- `TEXT` — все надписи;
- `COLORS` — цвета;
- `ASSETS`, `PHOTO_CROP` — материалы и кадрирование;
- `NARRATION` — дикторский текст по фрагментам, голос и настройки ElevenLabs;
- `SCENE_PLAN` — какие фрагменты озвучки звучат в какой сцене;
- `TIMING` — пределы длины ролика, старт голоса, удержание финала, переходы;
- `SAFE` — отступы под интерфейс Instagram;
- `AUDIO`, `SFX_CUES` — музыка, громкость, звуковые эффекты.

Длину сцен вручную задавать не нужно: она считается по таймингам речи
(`src/timeline.ts`). Если озвучки ещё нет, тайминги оцениваются по длине текста.

## Звук

В ролике три слоя звука:

| Слой | Откуда | Лицензия |
| --- | --- | --- |
| Фоновая музыка без вокала (`public/audio/music.mp3`) | Сгенерирована кодом: `scripts/generate-music.mjs` | Собственная, свободно для рекламы |
| Мягкие эффекты на переходах (`public/audio/sfx-*.mp3`) | Сгенерированы тем же скриптом | Собственные, свободно для рекламы |
| Озвучка ИИ-голосом на кыргызском (`public/audio/voice/`) | ElevenLabs, модель `eleven_v3`: `scripts/generate-voice.mjs` | Коммерческое использование разрешено на платных тарифах ElevenLabs (Starter и выше) |

Пока звучит голос, музыка автоматически становится тише.
Пересоздать музыку и эффекты: `npm run audio:music`.

### Подключение озвучки ElevenLabs (с телефона)

1. В ElevenLabs откройте **Developers → API Keys** и создайте ключ. Достаточно права **Text to Speech**.
2. На GitHub откройте репозиторий → **Settings → Secrets and variables → Actions → New repository secret**.
   Name: `ELEVENLABS_API_KEY`, Secret: ваш ключ.
3. Запустите **Actions → Check & render BalaGo videos → Run workflow**.

Workflow использует сохранённую озвучку или создаёт новую после изменения
текста или голоса, затем собирает видео. Голосовые файлы
будут в artifact `balago-voice`, видео с голосом — в `balago-promo-mp4`.
Для готовой озвучки секрет не нужен. Если сохранённой дорожки нет и секрет
не задан, видео собирается с музыкой и эффектами, но без голоса.
Если текст или голос изменились, для новой озвучки нужен секрет.

Голос по умолчанию — «Eric» (дружелюбный уверенный мужской голос из
стандартной библиотеки ElevenLabs), модель `eleven_v3`, язык `ky`.
Другой голос задаётся переменной (не секретом) `ELEVENLABS_VOICE_ID`
на вкладке **Variables** — без правки кода.

**Как устроена озвучка.** Весь текст `NARRATION` озвучивается одним запросом,
поэтому интонация связывает предложения. ElevenLabs возвращает тайминги
каждого символа — по ним считаются начала сцен и акценты. Темп не ускоряется:
если ролик получается длиннее 30 с, сборка останавливается с просьбой
сократить текст. Перед первой фразой и слоганом стоят теги интонации
`[warm]` и `[cheerful]`; если по таймингам видно, что тег прозвучал вслух,
дорожка автоматически пересоздаётся без тегов.

В логе шага **Generate voiceover** печатается отчёт: длительность, паузы
между фразами, пик громкости, проверка «обрезанного» конца. Если у ключа
есть право **Speech to Text**, речь распознаётся обратно и сравнивается
с текстом (CER — доля несовпавших символов) — косвенная проверка произношения.

Проверенный дубль и его тайминги сохранены в Git:
`public/audio/voice/narration.mp3` и `manifest.json`. Пока текст и голос
не меняются, используется именно этот дубль — в основной ветке и без кэша.
После изменения текста или настроек новая дорожка создаётся через API
и сохраняется в кэш CI. После проверки нового дубля добавьте оба файла
в Git вместе, чтобы зафиксировать результат для повторных сборок.

### Подбор голоса (voice lab)

Если в корне есть `voice-lab.json`, CI озвучит короткую реплику несколькими
голосами и сохранит сэмплы в artifact `balago-voice-lab` — их можно послушать
с телефона. С полем `outDir` (например, `voice-samples/trip-questions`) пробы
сохраняются и в Git; при тех же настройках повторно не создаются.
Для списка голосов библиотеки и автоматической проверки произношения ключу
нужны права **Voices: Read**, **Models: Read** и **Speech to Text**.

## Локальный запуск (на компьютере)

Нужен Node.js 22.18+. Для создания музыки и обработки озвучки также нужен
системный FFmpeg (полная сборка с PCM, libmp3lame, atempo и loudnorm).
В GitHub Actions FFmpeg устанавливается автоматически до проверки аудио и обращения к ElevenLabs.

```bash
npm ci
npm run studio      # Remotion Studio: предпросмотр в браузере
npm run typecheck   # проверка TypeScript
npm run lint        # ESLint + TypeScript
npm run render      # экспорт out/balago-promo.mp4 (H.264, yuv420p)
npm run render:driver   # экспорт out/balago-driver-intro.mp4
npm run stills:driver   # кадры второго ролика в out/frames-driver-intro/
npm run audio:voice:driver   # озвучка второго ролика
npm run render:how      # экспорт out/balago-how-it-works.mp4
npm run stills:how      # кадры третьего ролика в out/frames-how-it-works/
npm run audio:voice:how      # озвучка третьего ролика
npm run render:morning  # экспорт out/balago-morning-rush.mp4
npm run stills:morning  # кадры четвёртого ролика в out/frames-morning-rush/
npm run audio:voice:morning  # озвучка четвёртого ролика
npm run audio:music:morning  # музыка и сигнал будильника четвёртого ролика
npm run render:founder  # экспорт out/balago-founder-story.mp4 (60 с)
npm run stills:founder  # кадры пятого ролика в out/frames-founder-story/
npm run audio:voice:founder  # озвучка пятого ролика
npm run audio:music:founder  # музыка и эффекты пятого ролика
npm run render:trip     # экспорт out/balago-trip-questions.mp4 (60 с)
npm run stills:trip     # кадры шестого ролика в out/frames-trip-questions/
npm run audio:voice:trip     # озвучка шестого ролика
npm run bundle && npm run stills   # контрольные кадры в out/frames/
npm run audio:music # пересоздать музыку и эффекты
npm run test:audio  # проверка FFmpeg и монтажа под речь
ELEVENLABS_API_KEY=... npm run audio:voice   # озвучка
```

Папки `out/`, `build/`, `node_modules/` и файлы `*.mp4` в Git не попадают.

Если Remotion не может скачать Chrome Headless Shell (закрытая сеть), укажите
установленный Chromium: `REMOTION_BROWSER_EXECUTABLE=/path/to/chrome npm run render`.

## Структура

```
src/
  config.ts          тексты, цвета, материалы, тайминги, звук
  Root.tsx           композиции: BalaGoPromo + отдельные сцены (папка Scenes)
  SpeechVideo.tsx    общий каркас «монтаж под речь»: сцены, переходы, звук
  BalaGoPromo.tsx    первый ролик
  BalaGoDriverIntro.tsx  второй ролик «Кто стоит за BalaGo»
  driver-intro/      сцены второго ролика
  BalaGoHowItWorks.tsx  третий ролик «BalaGo кантип иштейт?»
  how-it-works/      сцены третьего ролика
  BalaGoMorningRush.tsx  четвёртый ролик «Утро родителей»
  morning-rush/      сцены и иконки четвёртого ролика
  BalaGoFounderStory.tsx  пятый ролик «Почему я создаю BalaGo» (60 с)
  founder-story/     сцены, «бумажные» элементы и иконки пятого ролика
  BalaGoTripQuestions.tsx  шестой ролик «Мектепке жол: үч суроо» (60 с)
  trip-questions/    сцены и карточки шестого ролика
  Soundtrack.tsx     музыка с приглушением, эффекты, озвучка
  fonts.ts           шрифт Nunito из public/fonts
  timeline.ts        монтаж под речь: начала сцен и акценты по словам
  scenes/            семь сцен ролика
  components/        фон, фото с приближением, логотип, машинка, анимации
public/
  assets/            логотип и фотографии
  audio/             музыка, эффекты, озвучка (voice/)
  fonts/             Nunito (лицензия SIL OFL, см. OFL.txt)
scripts/render-stills.mjs     контрольные кадры
scripts/generate-music.mjs    музыка и эффекты
scripts/generate-voice.mjs    озвучка ElevenLabs + отчёт о качестве
scripts/voice-lab.mjs         подбор голоса по короткой реплике
.github/workflows/render.yml  проверка и рендер в GitHub Actions
.claude/skills/      официальные Remotion Agent Skills (npx skills add remotion-dev/skills)
```
