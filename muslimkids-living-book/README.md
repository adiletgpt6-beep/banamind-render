# MUSLIM KIDS — Эксперимент 003 · THE LIVING BOOK («Оживающая книга»)

Мультфильм **«Книга удивительного мира»** — 60 с, 1080×1920, 30 fps, H.264/AAC.
Тема: размышление о творении Аллаха (сура «Аль-Имран», 3:190–191), возраст 5–12 лет.

Технология: настоящая 3D-книга (Three.js через `@remotion/three`), из страниц
которой раскрываются бумажные pop-up миры и складываются обратно перед
перелистыванием. Это отдельный проект; проекты BalaGo он не затрагивает.

## Запуск

```bash
npm install
npm run studio                    # интерактивный просмотр в Remotion Studio
npm run audio                     # пересобрать озвучку и звук (нужны модели, см. ниже)
npm run stills                    # контрольные кадры → output/previews/
npm run render                    # финальный MP4 → output/final/MuslimKids_LivingBook_003.mp4
npm run verify                    # ffprobe-проверка готового файла
```

Без GPU (облако, CI) укажите Chromium с поддержкой WebGL — рендер идёт через
ANGLE/SwiftShader (`gl: "angle"`):

```bash
export REMOTION_BROWSER_EXECUTABLE=/path/to/chrome-headless-shell
node scripts/render-final.mjs --concurrency=3        # ≈ 1,7 с/кадр на 4 CPU, ~50 мин
node scripts/render-stills.mjs 10 19 29 --scale=0.5  # отдельные кадры
```

## Архитектура

```
src/story/timeline.json      единый таймлайн: сцены, фразы диктора, листы книги,
                             фазы pop-up, подписи. Его же читает build_audio.py.
src/engines/
  LivingBookEngine.ts        состояние книги во времени: створка (обложка + левый блок),
                             толщины блоков, верхние страницы, летящие листы, корешок
  PageTurnEngine.ts          деформация листа с толщиной: φ(s,z)=θ(p)+c(p)(s/W)²(1+κz),
                             интеграл касательной (без растяжения), φ∈[0,π] — без
                             прохода сквозь блок; нормали каждый кадр → свет и тени
  PaperFoldEngine.ts         геометрия сгибов: развёртка пирамиды, дольки глобуса,
                             складной листок, лента, облако, звезда, UV
  PopUpWorldEngine.ts        расписание раскрытия/складывания (типы FOLD_UP,
                             RADIAL_EXPANSION, LAYERED_POPUP, PAPER_BLOOM,
                             ORBITAL_STRUCTURE, WORLD_COLLAPSE), обратный порядок,
                             «уход в сгиб»
  BookCameraController.ts    камера: сплайн Эрмита/Катмулла–Рома по времени, проекция
                             3D-точек для HTML-подписей
  LightingController.ts      мягкий тёплый ключ + холодное заполнение + окружение
src/components/              Book3D, BookCover, BookPage, PopUpEarth, PopUpMountains,
                             PopUpTree, PopUpUniverse, PageDecoration (рамка),
                             PaperParts, Room, Overlays, World
src/scenes/Scene0X*.ts       ракурсы камеры каждой сцены
src/materials/               процедурные текстуры (Canvas), бумага, обложка, шейдер Земли
scripts/build_audio.py       озвучка Piper + звуковой дизайн + сведение + ASR-проверка
```

Всё движение — чистая функция времени `t = frame / fps` (`useCurrentFrame`),
без `Date.now()` и случайности браузера: рендер детерминирован.

### Как заменить содержание (переиспользование)

- **Текст диктора, тайминги, листы, фазы миров** — `src/story/timeline.json`.
- **Иллюстрации страниц** — функции в `PAGE_DRAW` (`src/materials/textures.ts`), ключи
  страниц указываются у листов (`front`/`back`) в таймлайне.
- **Новый мир** — компонент `PopUpXxx` на функциях `elementState`/`seq`/`tuckIntoGutter`
  и деталях из `PaperParts`; подключается в `World.tsx`.
- **Палитра и шрифты** — `src/styles/palette.ts`.
- **Камера** — массивы ключей в `src/scenes/`.

## Механика pop-up по сценам

| Сцена | Время | Мир и механизм |
|---|---|---|
| 1 | 0–6 | Обложка (скруглённая плита с фаской, тиснение золотом через metal/rough-карту) поворачивается вокруг гибкого корешка; пачка страниц и два листа перелистываются; из сгиба встаёт бумажный полукруг |
| 2 | 6–15 | 16 долек-«сот» с полудисками раскрываются веером на 360° в глобус (RADIAL) на складной подставке-пирамиде; золотой меридиан и орбита Луны (ORBITAL); Солнце на V-стойке. Земля делает ровно один оборот вокруг своей оси; Солнце неподвижно; освещённость шейдером от положения Солнца — честные день и ночь. Затем всё складывается |
| 3 | 15–24 | Три горы вытягиваются из линий сгиба (по очереди) со снежными шапками отдельным слоем и передними отрогами; холмы на шарнирах с упорами (LAYERED); облака из трёх слоёв на выдвижных стойках; река — три слоя бумажной ленты с бегущей волной |
| 4 | 24–34 | Семечко на слоистом холмике; облако на стойке, капли дождя; оболочка семечка раскрывается, стебель и два листочка; ствол растёт, ветви выходят из сгибов, кластеры кроны с листьями-«ромбами» раскрываются по одному (PAPER BLOOM) |
| 5 | 34–44 | Тёмно-синий разворот: арка ночного неба (FOLD UP), Солнце на колонне, орбиты-ленты обматываются вокруг него со спицами, Земля с днём/ночью, две планеты на орбите и окольцованная на нити, звёзды на откидных язычках и стойках |
| 6 | 44–54 | Космос складывается; из сгиба встаёт стрельчатая рамка из слоёв бумаги (основа, золотой кант, изумрудная лента с восьмиконечными звёздами). Перевод смысла — отдельный HTML-блок в окне рамки, не на сгибаемой бумаге |
| 7 | 54–60 | Рамка складывается; два листа и створка закрываются по очереди; «А ЧТО УДИВИЛО ТЕБЯ?» и MUSLIM KIDS |

## Исламская корректность

- Книга — «Книга открытий», обычная образовательная книга, не мусхаф. На страницах
  нет аятов: только заголовки разделов («Земля», «Горы», …), рисунки и абстрактные
  «строки» без смысла.
- Аллах не изображается, символов, представляющих Его, нет. Геометрия рамки —
  декоративный орнамент.
- Цитата 3:191 (перевод смысла Э. Кулиева): «Господь наш! Ты не сотворил это
  понапрасну» — дословно, в отдельном чётком блоке с подписью «Часть аята. Перевод смысла.»
- 3:190 передан пересказом смысла диктором и подписью «Сура Аль-Имран, 3:190».
- Научные примеры (вращение Земли, рост растения) не приписываются Корану.
  Смена дня и ночи показана вращением Земли вокруг своей оси при неподвижном Солнце.

## Звук

- **Голос:** локальная нейросеть Piper `ru_RU-ruslan-medium` (мужской, через
  `sherpa-onnx`), темп 1.12 (немного медленнее нормального — спокойная подача,
  без ускорения). Каждая фраза синтезируется до 6 раз, выбирается самый
  разборчивый дубль по обратному распознаванию GigaAM v2 (CER ≈ 0 для 14 из 15 фраз,
  результаты в `public/audio/narration.json`). OpenAI TTS и ElevenLabs в окружении
  сборки были недоступны.
- **Без музыки** (правило Muslim Kids). Процедурные эффекты бумаги: открытие обложки,
  перелистывания, шорох раскрытия/складывания, тихий ветер в горах, вода, дождь,
  листва. Во время цитаты — тишина атмосферы.
- Сведение: голос −16 LUFS, эффекты заметно тише, лимитер.

Модели для `npm run audio` (из релизов k2-fsa/sherpa-onnx):
`PIPER_VOICE_DIR=…/vits-piper-ru_RU-ruslan-medium`,
`ASR_MODEL_DIR=…/sherpa-onnx-nemo-transducer-giga-am-v2-russian-2025-04-19` (необязательно).
Готовые `public/audio/*.wav` уже лежат в репозитории.

## Ограничения

- Рендер программный (SwiftShader): мягкие тени PCF, без постобработки DOF —
  глубина передана размытым фоном комнаты, перспективой и светом.
- Горы «вытягиваются» из сгиба (вершина-гребень поднимается), а не разворачиваются
  из плоской звезды: развёртка высокой пирамиды не помещается на странице.
