# «Трактат о природе» простым языком — объясняет Банан (≈30 минут)

Первый фильм серии анимационных объяснений книг с постоянным ведущим-бананом
(персонаж вынесен в `src/banana-host/`). Отдельный проект в репозитории (не реклама BalaGo: правила BalaGo
о контактах, Бишкеке и кыргызской озвучке к нему не относятся). Прежние ролики не затронуты.

## Файлы

| Что | Где |
| --- | --- |
| Готовый MP4 1920×1080, 30 fps, H.264/AAC | релиз `lesson-traktat-banan` → `lesson_traktat_banan_30min.mp4` |
| Только новое вступление (первые 75 с, 1920×1080) | там же → `lesson_traktat_banan_30min-intro-75s.mp4` |

| Обратная проверка озвучки | `voice_qa.json` |

## Как сделано

1. **Расшифровка** (`scripts/lesson-traktat/asr_sherpa.py`): Whisper large-v3-turbo (sherpa-onnx,
   int8, локально на CPU) + Silero VAD, 221 фрагмент, 73:09 за 18 мин. OpenAI API в среде
   без кредитов, HuggingFace закрыт сетью — модели взяты из релизов k2-fsa/sherpa-onnx.
   Имя автора и два аята, которые звучат в уроке, перепроверены повторным распознаванием
   со смещённым окном.
2. **Сценарий** — данные `src/lesson-traktat/script.ts`: 31 сцена, 244 реплики (~3200 слов),
   6 вопросов с паузой 5 с, у каждой сцены интервалы исходной записи (`src`).
   `node scripts/lesson-traktat/export-docs.mjs` → `lesson_30min_script.md` и `source_map.md`.
3. **Озвучка** (`scripts/lesson-traktat/voice.mjs`): ElevenLabs, один голос на весь урок
   (Eric, multilingual v2, темп 0.9), реплика = файл, тайминги букв → рот и субтитры;
   −18 LUFS. Обратная проверка Whisper (`voice_qa.py`): средний WER 2 % (расхождения —
   в основном цифры вместо слов); 3 нечёткие реплики переозвучены.
4. **Анимация** — Remotion, точка входа `src/lesson-traktat/index.ts`: банан (`banana/`) —
   16 поз, 8 выражений, моргание, рот по буквам речи; 29 анимированных схем (`visuals/`)
   только по примерам из книги; таймер вопросов; полоска частей; субтитры.
5. **Хронометраж** (`timeline.ts`) строится по реальной озвучке; запас до 30:00
   распределяется по паузам (речь не ускоряется).
6. **CI** `.github/workflows/lesson-traktat.yml`: озвучка → 8 параллельных частей рендера →
   склейка без пережатия + звуковая дорожка по тайм-лайну (без музыки, тихий сигнал в конце
   паузы-вопроса) → AAC 192k, faststart → `verify.mjs` (формат, 29:30–30:30, громкость, нет
   чёрных кадров) → превью 960×540 → релиз.

## Команды

```bash
node --test scripts/lesson-traktat/*.test.mjs        # сценарий, вопросы, длительность
ELEVENLABS_API_KEY=… node scripts/lesson-traktat/voice.mjs
node scripts/lesson-traktat/stills.mjs s07,s16      # контрольные кадры
node scripts/lesson-traktat/mixdown.mjs out/audio.wav
npx remotion render src/lesson-traktat/index.ts TraktatLesson out/v.mp4 --muted
node scripts/lesson-traktat/verify.mjs out/lesson_traktat_banan_30min.mp4
```

## Версия 2: новое вступление

Почему старое начало было скучным: 3 с тишины с заставкой, затем приветствие и
«устраивайся поудобнее»; один статичный кадр 53 с; главный вопрос только на 0:27,
правила таймера — на 0:38, затем минута истории книги (Анкара, брошюра на арабском
и турецком); первый яркий пример из книги — лишь около 4:40.

Новое вступление (≈1 мин, 5 сцен, «толкающие» переходы, тот же банан и тот же голос,
но с более живой интонацией):

| Время | Сцена | Опора на запись |
| --- | --- | --- |
| 0:00–0:08 | Крючок: ветер опрокидывает баночки — «точное лекарство само?!» | 06:31–08:21 |
| 0:08–0:20 | Вопросы: мир внутри мухи? солнышко в каждой капле? сосна из семечки? | 10:24–11:22, 21:56–22:36, 29:56–30:52 |
| 0:20–0:29 | Главный вопрос: «Откуда всё это? Неужели само собой?» | 05:07–06:07 |
| 0:29–0:50 | «Трейлер»: книга, аптека «до грамма», дворец в пустыне, четыре дороги | 00:07–00:17, 06:07–06:51, 32:11–33:46 |
| 0:50–1:00 | «Я — Банан, твой проводник», правило вопросов, книга открывается → урок | — |

Старая сцена приветствия удалена (повторного приветствия нет), история книги сокращена
до двух реплик. Остальные 30 сцен, их анимации и озвучка не менялись. Вступление не
растягивается паузами (`tight`/`gap` в `script.ts`), запас до ~30 мин распределяется
по основной части.

## Версия 3: универсальный формат для широкой аудитории

- **Без таймеров.** Удалены обратный отсчёт в карточке вопроса (6 мест), кружок «5 —
  отвечай вслух» во вступлении и звуковой сигнал «конец отсчёта». Вопросы остались как
  «вопрос для размышления»: карточка с текстом вопроса и пауза 4 с, без цифр. Часы в
  сцене о часовщике — пример из книги, оставлены.
- **Тон для подростков и взрослых.** Обращение на «вы», убраны «Молодец!», «Пока-пока!»,
  «Смешно, правда?», «Это будет весело!», «Представляешь?»; ответы на вопросы — спокойные
  выводы, без «прыжков». Детская аналогия «рыба на дереве» заменена определением
  нелепости по книге (вывод, противоречащий разуму). Переписано 85 реплик из 242,
  смысл и порядок аргументов прежние; тесты проверяют обращения и отсутствие таймеров.
- **Персонаж для серии.** `src/banana-host/` — модель, позы, выражения, рот, моргание;
  фильм только размещает банана в кадре.

## Версия 4: канал BanaMind и анимированные титры

- Канал называется **BanaMind** («Big Ideas. Simply Explained.»); язык фильма — русский.
  Знак BanaMind добавлен на финальную заставку; банан, голос, сценарий, сцены и
  длительность (29:52) не менялись.
- Субтитры заменены фирменным компонентом `BanaMindAnimatedCaptions`
  (`src/banamind/captions/`): слова появляются в момент произнесения (таймкоды букв
  ElevenLabs — для всех 242 реплик), короткие фразы ≤ 2 строк, важные слова жёлтым,
  особо значимые — мятным акцентом книги, мягкое увеличение звучащего важного слова,
  slide + fade плашек строк, 5 кинетических моментов («САМО СОБОЙ?», «НЕЛЕПОСТЬ»,
  «НЕВОЗМОЖНО»). Настройки книги — `src/lesson-traktat/captions.ts`.
- SRT для YouTube строится из тех же титров: `lesson_traktat_banan_30min.srt`.
- Проверка: `node scripts/lesson-traktat/captions-check.mjs` и тест титров в `script.test.mjs`.
