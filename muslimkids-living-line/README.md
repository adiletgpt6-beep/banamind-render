# MUSLIM KIDS — THE LIVING LINE («Живая линия»)

Отдельный проект (не связан с BalaGo). Образовательные мультфильмы, в которых
весь мир рисует **одна непрерывная золотая линия** со светящимся кончиком.

**Эпизод 001** — «Кто создал этот удивительный мир?» (сура «Аль-Имран», 3:190–191).
Композиция `MuslimKidsLivingLine001`: 1080×1920, 30 fps, 1800 кадров (60 с), H.264/AAC.

## Быстрый старт

```bash
cd muslimkids-living-line
npm install
npm run studio                       # предпросмотр
node --experimental-strip-types scripts/qa-line.ts   # проверка непрерывности линии
npm run render                       # финальный MP4 → output/final/
```

В офлайн-окружении без загрузки Chrome:
`REMOTION_BROWSER=/path/to/headless_shell npm run render`.

## Архитектура (src/engines — переиспользуемые модули)

| Модуль | Назначение |
| --- | --- |
| `LivingLineEngine.ts` | Модель пути: штрихи `main` / `travel` / `branch`, видимая часть штриха в каждом кадре, положение, направление и скорость кончика, толщина при зуме, проверка непрерывности. Чистый TS. |
| `SceneTransitionEngine.ts` | `JourneyBuilder`: сцены продолжают путь с того места, где его оставила предыдущая; `draw()` отклоняет путь, который не начинается под кончиком; `travel()` — перелёт с исчезающим хвостом. |
| `LineMorphEngine.ts` | Ресемплинг по длине дуги и морфинг любых контуров (горизонт → дуга планеты, кольцо → штрих), «живая» волна при морфинге. |
| `PathSampler.ts` | Быстрое разбиение M/L/C путей на полилинию с длинами (тысячи запросов за кадр). |
| `LineDrawingSystem.tsx` | Рендер: свечение (один blur в экранном пространстве), чёткий контур, «свежие чернила» у головы, кончик с растяжением по скорости. |
| `CameraController.ts` | Виртуальная камера: ключи (центр, зум в лог-шкале, поворот), следование за сглаженным кончиком, world↔screen. |
| `LightingSystem.tsx` | Небо по ключам окружения, звёзды на трёх глубинах (параллакс), тёплый/холодный свет, виньетка и зерно. |
| `TypographySystem.tsx` | Кинетический текст по буквам, акцентные слова, локальные шрифты (Nunito, Lora — OFL). |
| `AudioSyncSystem.tsx` | Раскладка реплик по манифесту озвучки (реальные длительности фраз и предложений), дорожка звукового дизайна. |

Сцены эпизода — `src/scenes/s1…s7-*.ts` (геометрия и путь), заливки и свет —
`src/scenes/decor.tsx`, планета — `src/components/Planet.tsx`, мир и тайминг —
`src/episodes/ep001/`.

## Звук

- `scripts/generate_voice.py` — русская озвучка офлайн (Piper VITS через sherpa-onnx,
  голос `ru_RU-dmitri-medium`), мастеринг −16 LUFS, манифест с таймингами фраз,
  проверка произношения офлайн-распознаванием (GigaAM) с `--verify`.
- `scripts/generate_sfx.py` — процедурный звуковой дизайн без музыки
  (дыхание линии, воздух, ветер, капля, рост ростка, мерцание звёзд), приглушение под речью.

## Новый эпизод

1. Скопировать `src/episodes/ep001` → `ep002`, переписать `narration.json`, `timing.json`, `world.ts`.
2. Написать сцены через `JourneyBuilder` (каждая получает кончик там, где закончилась предыдущая).
3. `generate_voice.py --episode ep002`, `generate_sfx.py --episode ep002`.
4. `qa-line.ts` → превью 540×960 → финальный рендер.

## Источник смысла аятов

Перевод смысла — Э. Кулиев, 3:190–191: «Воистину, в сотворении небес и земли и в смене
ночи и дня заключены знамения для обладающих разумом, которые … размышляют о сотворении
небес и земли: „Господь наш! Ты не сотворил это понапрасну…“». На экране цитата помечена
«Часть аята. Перевод смысла.»; пояснения диктора не выдаются за дословный перевод.
Арабский текст не используется.
