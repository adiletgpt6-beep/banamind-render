## Цель
Производственная серия 500 **анимационных объяснений книг** с узнаваемым бананом, содержание только из предоставленной книги. Владелец присылает книгу только ChatGPT; координатор извлекает TXT, размещает и проверяет source pack в приватной BM-ветке по SOURCE_INGESTION.md. При SOURCE_READY_IN_PRIVATE_GITHUB в Claude Code передаётся только короткий промпт, без повторного вложения книги. ChatGPT пишет детальный `TASK.md` в GitHub и выдаёт краткое сообщение Claude Code; Claude делает книгу в отдельной ветке/PR, обновляет статус, потом отдаёт MP4, SRT, 5 превью и метаданные. При новом GPT/Claude читать GitHub, не старые чаты.
