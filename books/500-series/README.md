# BanaMind — производство 500 книг (BM-001…BM-500)

**Единая точка входа для ChatGPT, Claude Code и новых сессий.** Настоящая память проекта — GitHub, а не переписка. Это **документационный каркас**, не утверждение, что 500 фильмов или полностью автономный CI уже созданы.

## Быстрый старт
1. Прочитать **этот README**, [MASTER_CLAUDE.md](MASTER_CLAUDE.md), [WORKFLOW.md](WORKFLOW.md), [HANDOFF.md](HANDOFF.md), [REGISTRY.csv](REGISTRY.csv).
2. Для конкретного фильма открыть `books/500-series/tasks/BM-NNN/TASK.md`; он создаётся **по образцу** [templates/TASK.md](templates/TASK.md) лишь после получения источника. Содержание книги/автор/ссылки не угадывать.
3. Использовать короткий запуск из [PROMPTS.md](PROMPTS.md). Прежде чем что-либо делать, сверить реальное состояние GitHub (ветки, PR, workflow, release).
4. Документировать пройденные стадии в `tasks/BM-NNN/STATUS.md`, приложить доказательства проверок, ссылки на видео и пять обложек. После утверждения и слияния координатор обновляет REGISTRY.csv и HANDOFF.md.

## Границы проекта
- **BanaMind** — канал объяснений книг, *не* реклама BalaGo. Никаких CTA BalaGo, упоминания Бишкека и кыргызской рекламной озвучки.
- Английское название **BanaMind**, русский слоган **«Большие идеи. Простыми словами.»**. Базовый язык видео, субтитров и метаданных — русский, пока владелец не изменит.
- Пользователь предоставляет книгу в формате **audio / video / PDF** (при необходимости файл/ссылка до лимита Claude). Источник — только предоставленный материал. Привязка выводов к страницам или таймкодам обязательна.
- Для использования и публикации правообладатель/лицензия должны быть проверены владельцем. Переработка чужой аудиокниги или PDF сама по себе **не гарантирует** право на публикацию, и наличие анимации **не гарантирует** монетизацию YouTube.
- Не добавлять новые факты, богословские положения, цитаты, интерпретации от себя. В религиозных сценах не изображать Аллаха или пророков.
- Продолжительность указывать **по конкретной книге и брифу**, не растягивать материал ради ровно 30 минут. BM-001 («Трактат о природе») — ~30 минут.
- Персонаж и формат: `src/banana-host/`, `src/banamind/`, 1920×1080 / 16:9 / 30 fps / MP4 H.264 AAC; фирменные динамичные субтитры + SRT; без видимых таймеров; **5 разных YouTube-обложек** 1280×720 и сравнительный лист; YouTube-метаданные.

## Нумерация и память
- **BM-001**: «Трактат о природе» — существует PR [#121](https://github.com/adiletzainidinov/balago-video/pull/121), но мердж, релиз и окончательное утверждение отдельно проверяются; **не начинать заново**.
- **BM-002…BM-500**: зарезервированные пустые номера, **не** названия выдуманных книг.
- Реестр: [REGISTRY.csv](REGISTRY.csv). Стадии: `RESERVED → SOURCE_READY → BRIEF_READY → APPROVED → IN_PRODUCTION → QA_REVIEW → FINAL_APPROVED → PUBLISHED`; `BLOCKED` и `PR_OPEN` — технические статусы с пояснением в STATUS.
- Номер не менять и не переиспользовать, даже если проект отменён: `BLOCKED`/отмена с причиной.
- **Одна книга = одна ветка + один PR + собственный STATUS**. Параллельные Claude-чаты читают общие правила, но не редактируют чужие задания и не переписывают общий реестр. Координатор обновляет реестр после принятия результата.
