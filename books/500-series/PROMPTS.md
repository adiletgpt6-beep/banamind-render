# Короткие промпты BanaMind

Детальные правила и история живут в GitHub, не в чате. Подставить актуальные BM-ID, ветку и путь задачи. Не отправлять длинный пересказ вместо ссылки.

## 1. Claude Code — новая книга после создания TASK.md
```text
BanaMind, книга BM-NNN. Репозиторий: adiletzainidinov/balago-video.
Прочитай books/500-series/README.md, MASTER_CLAUDE.md, WORKFLOW.md, books/PRODUCTION.md, а главное — books/500-series/tasks/BM-NNN/TASK.md и STATUS.md в указанной ветке/PR.
Не спрашивай старый контекст. Сверь текущие PR/коммиты/исходник, продолжай с последней проверенной стадии. Работай только над BM-NNN, отдельная ветка/PR, сохраняй STATUS и доказательства. Без доступа к источнику или при отсутствии нужного утверждения — остановись с конкретным блокером. Пока нет одобрения брифа, не запускай дорогой финальный рендер.
```

## 2. Claude Code — новая сессия после переполнения
```text
Продолжай BM-NNN в репозитории adiletzainidinov/balago-video. Сначала читай books/500-series/README.md, MASTER_CLAUDE.md, tasks/BM-NNN/TASK.md и tasks/BM-NNN/STATUS.md. Проверь ветку, PR, Actions и артефакты; не повторяй завершённые этапы. Обновляй STATUS/коммиты и продолжай с точного NEXT_STEP. Итог: реальные проверенные файлы и ссылки или явный BLOCKED.
```

## 3. Новый ChatGPT — полный перенос проекта
```text
Продолжи мой долгосрочный проект BanaMind: анимационные объяснения 500 книг с бананом. GitHub: adiletzainidinov/balago-video, папка books/500-series/. Сначала прочитай README.md, HANDOFF.md, WORKFLOW.md, MASTER_CLAUDE.md, REGISTRY.csv и актуальные PR, не предполагай, что старые чаты доступны. BM-001 — «Трактат о природе» (PR #121); остальные номера назначаются по реестру. Я присылаю новую аудио-/видеокнигу или PDF, ты размещаешь в GitHub подробное задание для одной книги, а мне даёшь короткий промпт для Claude Code. Помоги продолжить с последней проверенной стадии, соблюдая исходник, права, формат 16:9, фирменный банан, динамичные субтитры, пять обложек и сохранение контекста через STATUS/PR.
```

## 4. Claude Code — статус без запуска производства
```text
Только проверь фактическое состояние BanaMind BM-NNN по GitHub/CI и обнови tasks/BM-NNN/STATUS.md: DONE, BLOCKERS, NEXT_STEP, ссылки на PR и артефакты. Не запускай рендер, не трать API-ресурсы, не меняй чужие книги.
```
