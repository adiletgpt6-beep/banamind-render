## Трудные места и решения

| место | решение |
|---|---|
| «Тулон» | поясняем через текст романа: минута, которая «выведет его из рядов неизвестных офицеров» (`part-08.txt:L110`) — без внешней исторической справки |
| масонство Пьера | только как факт романа и этап поиска; без обрядов и символов на экране |
| попытка самоотравления Наташи (`part-29.txt:L267`) | не упоминается; говорим о тяжёлом кризисе только через отказ и слова Пьера |
| казнь «поджигателей» (`part-47.txt:L79–L86`) | «Других пленных казнят у него на глазах» — без изображения |
| гибель Пети (`part-52.txt:L92–L96`) | без деталей; память Денисова об изюме |
| смерть Каратаева (`part-52.txt:L140–L145`) | «Позади раздаётся выстрел» — без изображения |
| Верещагин (`part-44.txt:L21–L43`) | не используется (натуралистичный самосуд) |
| «Тоже и они люди» | сцена милосердия, без героизации насилия |
| «дубина народной войны» | образ Толстого, без призывов к насилию |
| слитные слова в источнике («принадлежалк», «теперьего») | в цитаты фильма не попадают |
| неразрывные пробелы перед тире | проверка цитат их нормализует |
