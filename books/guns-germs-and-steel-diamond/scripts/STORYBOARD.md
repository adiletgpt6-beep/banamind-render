# BM-027 · STORYBOARD

Визуальная система «Лаборатория развилок истории»: светлый лабораторный фон с сеткой, чернильные контуры, бирюзовые стеклянные линзы-переменные, янтарь (зерно и запасы), шалфей (растения), небесный (океан), коралл (микробы), серо-синий (сталь), слива (спорные стрелки — пунктир со «?»). Карты — нарочно условные пятна с подписью «условная схема, не карта»; ни границ, ни реконструкций маршрутов. Ружьё — только значок слова из названия, без выстрела и цели; колониальное насилие и эпидемии не изображаются — вместо этого спокойное поле огоньков. Условные человечки без портретов и без признаков «расы». Без изображений издания, его 64 иллюстраций, карт, обложки, фото, кадров кино. Часов, таймеров и прогресс-полос нет.

Каждая сцена: появление с лёгким подъёмом и медленный «наезд» (Drift); элементы появляются по репликам; фон меняется по частям. Вверху слева — BanaMind и название части; вверху справа — метка типа утверждения. Титры BanaMind внизу, сдвигаются от банана; схемы держатся выше зоны титров.
