## Рекомендация: №2 «Интрига»

«География решает?» — короткий вопрос, который точно передаёт главный спор фильма: сильная гипотеза Даймонда и её границы. Знак вопроса честен (фильм не объявляет географию единственной причиной), два слова читаются даже в 320×180.

## Проверки

- формат: ✓ все пять — 1280×720, JPEG (sRGB), ≤ 2 МБ
- орфография (Hunspell ru_RU + books/dictionary.txt): ✓ 26 слов
- различие: ✓ минимальная попарная разница 37.1 (порог 25 из 255)
- читаемость в 320×180: [readability-320x180.jpg](readability-320x180.jpg)
