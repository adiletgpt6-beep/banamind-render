# BM-033 · STORYBOARD — «Бюро невозможных доказательств»

Визуальная ДНК: тёплый янтарный свет рукописи (сцены Бюро — бумага с тонкой сеткой и пятнами света лампы) против холодной синей ночи (замок, угроза, погоня — глубокий синий с точками-звёздами и ореолом луны, без чёрных кадров). Чёткие крупные точки собирают читаемые силуэты (замок, дневник, корабль, лупа, лампа, люди, знак вопроса), удерживаются, перестраиваются или рассыпаются; позиции детерминированы (без случайного шума и мерцания), без blur/bloom. Реквизит: дневник, конверты, телеграмма, газетная вырезка, фонограф, пишущая машинка, колбы фактов, прозрачные листы показаний, штампы «наблюдение / догадка / свидетельство», стилизованная схема-карта. Люди — условные силуэты без портретов; граф — пустой пунктирный силуэт без лица (не кинообраз). Ни крови, ни клыков, ни гробов, ни сцен насилия; без кадров экранизаций, постеров и издательской обложки. Таймеров, отсчётов и прогресс-полос нет.

Переходы: появление с лёгким подъёмом, медленный «наезд» (Drift) в каждой сцене, смена фона по частям (бумага ↔ ночь). Титры BanaMind внизу, сдвигаются от банана; схемы держатся выше зоны титров. Карточки цитат — с главой, файлом и строкой.
