# BM-026 · STORYBOARD

Визуальная система «Мастерская внутренней свободы»: светлый тёплый фон-бумага, чернильные контуры, бирюза (выбранное, ясное), янтарь (время, внимание), умеренный коралл (внешнее давление), фиолетовый (предположения). Пять прозрачных коробок на верстаке — сквозной образ: сначала их наполняют внешними вещами, потом меняются подписи-критерии. Чёткие точки собирают читаемые силуэты (конверт, человек, компас → корабль, дерево с корнями, дверь), удерживаются и совершают действие; позиции детерминированы (seed по номеру точки, без случайного шума и мерцания), без blur/bloom и тумана. Условные фигуры людей без портретов; без изображений издания, обложки, гравюр, кино. Часов, песочных часов, таймеров и прогресс-полос нет.

Переходы: появление с лёгким подъёмом, медленный «наезд» (Drift) в каждой сцене, смена фона по частям. Титры BanaMind внизу, сдвигаются от банана; схемы держатся выше зоны титров. Карточки цитат — с номером письма и параграфа.
