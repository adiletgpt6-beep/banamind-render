# BanaMind — постоянный порядок производства

Канал: **BanaMind** · слоган: **Big Ideas. Simply Explained.** Название и слоган — на английском,
язык фильмов — русский (озвучка, титры, обложки, метаданные). Бренд: `src/banamind/brand.ts`.
Это отдельный проект, не реклама BalaGo: правила BalaGo (кыргызская озвучка, Бишкек,
контакты, WhatsApp) к нему не применяются, а ролики BalaGo этот процесс не трогает.

## Для каждой новой книги

1. **Изучить книгу** — только по источнику, который дал владелец канала (аудио/текст).
   Расшифровка, карта источников «реплика → место в источнике». Без интернета и чужих
   толкований, без придуманных утверждений; неясные места помечать.
2. **Бриф** — тема, главная мысль, примеры из книги, длительность. Видео — только по
   утверждённому брифу.
3. **Видео** — тот же банан-ведущий (`src/banana-host/`): умный, любопытный, дружелюбный,
   иногда смешной; обращение на «вы», без сюсюканья. Формат YouTube: **1920×1080, 16:9,
   30 fps, MP4 H.264/AAC**. **Никаких таймеров, обратных отсчётов и индикаторов времени**
   в кадре. Аллаха и пророков не изображать.
4. **Пять обложек** по содержанию книги (раздел ниже).
5. **Метаданные YouTube** — пять названий + рекомендация, описание, теги, главы.
6. **Проверки** (раздел ниже) и выдача ссылок владельцу.

## Анимированные титры BanaMind — в каждом фильме

Компонент `BanaMindAnimatedCaptions` (`src/banamind/captions/`) — единый стиль канала;
фильм подключает его, а не пишет свои субтитры.

- **Время — только по реальной озвучке**: таймкоды букв ElevenLabs (`with-timestamps`)
  → время каждого слова; не по средней скорости чтения. Текст титров = текст сценария
  слово в слово (проверяется тестом), религиозные термины и имена — как в сценарии.
- **Фразы**: короткие смысловые куски по предложениям, запятым, тире и паузам речи;
  ≤ 2 строк, ≤ 34 знаков в строке; служебное слово не висит в конце строки, тире не
  начинает строку.
- **Анимации**: (1) слова появляются в ритме речи; (2) важное слово мягко увеличивается,
  пока звучит; (3) белый текст, важные слова — жёлтым, особо значимые — акцентом книги
  (не больше двух выделений на титр); (4) плашка строки и короткие фразы въезжают
  снизу (slide + fade); (5) редкая кинетическая типографика для ключевых слов
  («НЕВОЗМОЖНО») — не чаще раза в 45 с.
- **Читаемость**: Rubik 800, 52 px при 1920×1080, тёмная плашка у каждой строки,
  мягкая тень; низ кадра с отступом, сдвиг в сторону от ведущего; титр уходит до
  появления следующего и до карточки вопроса; без мерцаний и прыжков.
- **Настройки** — `src/banamind/captions/style.ts` (шрифт, размеры, цвета, ритм,
  отступы). Книга задаёт только словарь выделений, акцентный цвет и кинетические моменты
  (`CaptionBook`, пример — `src/lesson-traktat/captions.ts`).
- **SRT для YouTube** — из тех же титров (`scripts/lesson-traktat/srt.mjs`).
- **Проверка**: тест титров, `captions-check.mjs` (строки, перекрытия, текст, частота
  эффектов), кадр каждой сцены с самым длинным титром — титры не закрывают лицо банана,
  книгу и подписи схем; тестовый фрагмент 30–60 с перед полным рендером.

## Пять обложек — всегда пять разных концепций

| № | Концепция | Суть |
|---|---|---|
| 1 | Классическое | банан + книга, тематический фон, название книги + BanaMind |
| 2 | Интрига | главный вопрос книги крупно, удивлённый банан, книга в кадре |
| 3 | Профессор | библиотека/кабинет, банан в очках указывает на книгу, «Простое объяснение» |
| 4 | Противопоставление | две половины кадра — две идеи, которые сравнивает книга; банан в центре |
| 5 | Самый сильный | своя концепция: максимум любопытства без ложного кликбейта |

Правила: 1280×720, JPG, sRGB, ≤ 2 МБ; 2–4 крупных слова, читаемых в 320×180;
правильная кириллица; разные композиция, эмоция, типографика и цвета; обложка не обещает
того, чего нет в видео, и не противоречит книге. **Финальную обложку выбирает и публикует
владелец канала** — мы показываем все пять и рекомендуем одну с короткой причиной.

## Где что лежит

```
books/
  PRODUCTION.md           этот порядок
  dictionary.txt          слова канала для проверки орфографии (имена, названия)
  <slug>/
    book.json             книга, автор, где фильм (тайм-лайн, релизы)
    thumbnails.json       тексты, идеи пяти обложек, рекомендация и причина
    thumbnails/           thumbnail-01..05.jpg, comparison-sheet.jpg,
                          readability-320x180.jpg, checks.json, README.md
    metadata/             meta.json (правится вручную) → youtube.md, youtube.json
    video/README.md       ссылки на final-youtube.mp4 (большие файлы — в GitHub Releases)
    scripts/README.md     где сценарий, расшифровка и карта источников
src/banamind/             бренд канала: brand.ts (название, слоган, цвета), fonts.ts,
                          captions/ — анимированные титры BanaMindAnimatedCaptions
src/banana-host/          банан-ведущий (общий для всех книг; очки, бабочка — опции)
src/thumbnails/           набор обложек: kit.tsx (заголовки, значок канала, книга, банан),
                          Root.tsx (список книг BOOKS)
src/books/<slug>/thumbnails.tsx   рисунки пяти обложек книги
scripts/books/            thumbnails.mjs, youtube-meta.mjs, spellcheck.py
.github/workflows/book-assets.yml  CI: обложки, проверки, метаданные, релиз book-<slug>
```

## Как добавить книгу

1. `books/<slug>/book.json` (по образцу `traktat-o-prirode`), фильм — своя точка входа
   Remotion и свой workflow, как `src/lesson-traktat` + `lesson-traktat.yml`.
2. `books/<slug>/thumbnails.json` — пять концепций, все надписи в `texts`.
3. `src/books/<slug>/thumbnails.tsx` — пять компонентов из деталей `src/thumbnails/kit.tsx`
   и рисунков фильма; добавить книгу в `BOOKS` в `src/thumbnails/Root.tsx`.
4. `books/<slug>/metadata/meta.json` — названия, описание, теги, главы по id сцен.
5. Локально: `node scripts/books/thumbnails.mjs <slug>` и
   `node scripts/books/youtube-meta.mjs <slug>` (нужны ffmpeg, hunspell + hunspell-ru).
6. Пуш → `book-assets.yml` публикует релиз `book-<slug>`.

## Проверки перед выдачей

- видео: `ffprobe` — 1920×1080, 30 fps, H.264, AAC, полная длительность, звук; нет таймеров;
- обложки (`checks.json`): 1280×720, JPEG, ≤ 2 МБ; орфография Hunspell ru + `dictionary.txt`;
  попарное различие уменьшенных копий не ниже порога; глазами — `comparison-sheet.jpg`
  и `readability-320x180.jpg`;
- метаданные (`youtube.md`): названия ≤ 100 символов, описание ≤ 5000, теги ≤ 500,
  главы с 0:00, не меньше трёх, каждая ≥ 10 с, орфография;
- владельцу — ссылки на видео, обложки 1–5 и лист сравнения + рекомендация с причиной.
