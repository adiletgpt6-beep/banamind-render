## Рекомендация: №2 «Интрига»

Вопрос «Как мы договорились?» — это и есть главный вопрос фильма из первых секунд (тысяча незнакомцев, которые могут сотрудничать), он честно описывает содержание, вызывает любопытство без ложного кликбейта, а два коротких слова и контрастная сеть читаются даже в размере 320×180. Хорошо сочетается с рекомендуемым названием. Финальный выбор — за владельцем канала.
