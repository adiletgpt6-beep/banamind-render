# BM-017 — STORYBOARD «Театр закрытых дверей»

1920×1080, 30 fps. Реплики — id из `SCRIPT_DRAFT.md`. Движение камеры/объектов каждые 10–30 с;
зумы — не однотипные (чередуются: наезд на макет, панорама по доске, смена плана, параллакс).
Банан: позиция `left/right/corner/close/peek` (как в `src/lesson-traktat`), очки+бабочка в блоках анализа.
Титры — `BanaMindAnimatedCaptions`, акцент книги `#D9534F` («красная нить»); смещаются от банана.
**Никогда в кадре:** тела, кровь, оружие в действии, петля, вещества, название острова, текст считалки, таймеры.

## Визуальная система

| Элемент | Как выглядит | Что означает |
|---|---|---|
| Остров-макет | Изометрическая скала с домом (`Island`, `House`), море из волн | Сцена эксперимента |
| Окна дома | 10 окон; гаснут по одному | Персонаж «ушёл» (без изображения смерти) |
| Фигурки-жетоны | Фарфоровые силуэты с иконкой роли (`Figurine`, `RoleIcon`) | Гости; уход = фигурка уходит в тень (dim) |
| Доска предположений | Пробковая доска, карточки ролей (`Board`, `Card`), нити (`Thread`) | Красный пунктир — подозрение; жёлтая сплошная — проверенный факт |
| Два света | Тёплый `#F7C948` — наблюдаемое; холодный `#7FB2FF` — вероятное/домыслы | Разделение факта и догадки |
| Весы / молоток | `Scales`, `Gavel` | Закон / самозваный суд |
| Карточка вывода | Плашка «ВЫВОД №N» на доске | Новый смысловой результат блока |
| Карточка вопроса | `QuestionOverlay` без таймера | Вопрос зрителю, пауза 3–4 с |
