## Рекомендация: №5 «Самый сильный»

Два коротких слова читаются даже в размере 320×180, вопрос «само собой?» — главный вопрос книги и первые секунды фильма, сюжет с «лекарством из опрокинутых баночек» вызывает любопытство и честно показывает первый пример из видео, а изумлённый банан крупным планом — самая сильная эмоция из пяти. Финальный выбор — за владельцем канала.
