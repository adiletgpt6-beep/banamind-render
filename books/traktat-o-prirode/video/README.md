# Видео — final-youtube.mp4

`final-youtube.mp4` — рендер `lesson_traktat_banan_30min.mp4` из CI `lesson-traktat.yml`
(релиз `lesson-traktat-banan`), который тот же workflow копирует в релиз
`book-traktat-o-prirode` вместе с `final-youtube.srt`. Большие файлы в Git не хранятся.

Версия 4 (BanaMind): анимированные титры `BanaMindAnimatedCaptions` по реальным
таймкодам слов озвучки, знак BanaMind на финальной заставке. Банан, голос, сценарий,
сцены и длительность прежние.

| Параметр | Значение |
|---|---|
| Разрешение | 1920×1080, 16:9 |
| Частота кадров | 30 fps |
| Видео | H.264 (yuv420p, BT.709), MP4 с faststart |
| Звук | AAC 48 кГц, −17 LUFS |
| Длительность | 29:52 (1792,1 с) |
| Размер | ≈ 490 МБ |
| Таймеры в кадре | нет |
| Титры | анимированные BanaMind в кадре + SRT для YouTube |
