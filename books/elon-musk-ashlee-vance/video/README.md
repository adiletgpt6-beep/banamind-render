# BM-029 · видео

Большие файлы лежат не в Git, а в **приватном pre-release** `book-elon-musk-ashlee-vance`. Для доступа нужен вход в GitHub с правами на репозиторий.

- `pilot.mp4` и `pilot-preview-960x540.mp4` — пилот 30–60 с;
- `final-youtube.mp4` — финал 1920×1080, 30 fps, H.264/AAC;
- `final-youtube-preview-960x540.mp4` — облегчённый просмотр;
- `final-youtube.srt` — субтитры, копия в этой папке.

Рендер выполняет `.github/workflows/lesson-musk.yml`. Метка `[pilot]` в сообщении коммита запускает пилот, `[full]` — полный фильм; без метки идут только проверки. QA-кадры, ffprobe и verify сохраняются в `qa-pilot/` и `qa-full/`, распознавание озвучки — в `qa-voice/`.

**Не опубликовано на YouTube.** Права на публичную адаптацию не подтверждены, решение принимает владелец.
