# Фильм №33 «Мама на старом видео» — отчёт

- Композиция: `BalaGo33MomsOldVideo` (`src/Root.tsx`, код в `src/moms-old-video/`).
- Файл: `out/balago-33-moms-old-video.mp4`, 1080×1920, 9:16, 30 fps, H.264 yuv420p (bt709) + AAC 48 кГц, 155,9 с (4677 кадров).
- Ветка: `claude/balago-33-moms-old-video-24ds8n` (имя из задачи `feature/balago-33-moms-old-video` заменено веткой, которую выдала среда; других отличий нет).

## Команда рендера

```bash
npm ci
npm run test:moms-old-video          # MOV_STRICT_VOICE=1 — строгая проверка озвучки перед рендером
npm run render:moms-old-video        # → out/balago-33-moms-old-video.mp4
```

`render:moms-old-video` — это `node scripts/render-mov.mjs`: `remotion render BalaGo33MomsOldVideo` (h264, yuv420p, bt709, AAC 192k, props `{"preview":false}`) → двухпроходный `loudnorm` до −16 LUFS / −1,5 дБTP (видео копируется) → faststart → `scripts/verify-mov.mjs`. Без системного Chrome: `REMOTION_BROWSER_EXECUTABLE=<путь к chrome-headless-shell>`. Рендер детерминированный: музыка и эффекты синтезированы кодом, озвучка берётся из сохранённых файлов (хэш реплики), случайности в кадрах нет.

В CI: workflow **BalaGo №33 «Мама на старом видео» (2D)** (`.github/workflows/moms-old-video.yml`), ручной запуск **Run workflow** с `render = true` → артефакты `balago-33-moms-old-video-mp4`, `…-mobile-mp4` (540×960), `…-frames`.

### Языковые правки относительно задания

- «Үйдө уулун **няня** күтүп ала алат» → «Үйдө уулун **бала багуучу** күтүп ала алат»: заимствование «няня» во всех дублях звучало неразборчиво; в схеме маршрута подпись тоже «Бала багуучу».
- «BalaGo» в речи произносится «Балаго» (поле `spoken`), на экране и в субтитрах пишется BalaGo.
- Слоган «BalaGo менен жолго чыгалы!» озвучен одним запросом с призывом (отдельный файл распознавался хуже: CER 0,24).
- Сын в момент ошибки говорит короткое «Ой!» (без падения).
- Финальный призыв изменён по просьбе заказчика после первой сдачи: вместо «…профилдеги шилтеме аркылуу сайтка өтүп, алдын ала өтүнмө калтырыңыз» — «Профилдин башындагы шилтемеге өтүңүз же WhatsApp аркылуу жазыңыз: 0998 08 38 28». Номер диктор читает группами, как на экране: «нөл тогуз жүз токсон сегиз, нөл сегиз, отуз сегиз, жыйырма сегиз»; «WhatsApp» звучит «Ватсап». Формулировку выбирала панель из трёх вариантов и трёх независимых оценок (грамматика, произношение синтезатором, близость к просьбе).

## Проверки

Проверено в этой среде (коммит с финальным MP4):

- **Формат** (`scripts/verify-mov.mjs`): H.264 yuv420p 1080×1920, 30 fps, AAC 48 кГц, 155,904 с (звук 155,904 с), 4677 кадров, faststart, **−15,9 LUFS, true peak −2,7 дБTP**, чёрных участков нет.
- **Тесты** (`MOV_STRICT_VOICE=1 npm run test:moms-old-video`, 37 из 37): шкала (паузы между репликами ≥ 0,3 с, каждая реплика внутри своей сцены), озвучка полная и не устарела (хэши), все надписи на кыргызском, части субтитров не длиннее двух строк, не кончаются союзом и сменяются на своём слове озвучки (с учётом BalaGo/«Балаго», WhatsApp/«Ватсап» и номера цифрами/словами), номер WhatsApp совпадает с номером владельца; 22 проверки танца, в том числе стопа под нагрузкой не скользит. `npm run lint` (ESLint + tsc) проходит.
- **Озвучка**: каждая реплика синтезирована отдельно, выбран дубль из 3 по распознаванию Meta MMS в CI. Ключевые реплики: вопрос сына s01 — CER 0,062; ответ мамы m01 — 0; CTA n13 (новая редакция с номером) — 0,22: MMS записывает числительные цифрами («тогуз жүз токсон сегиз» → «99…»), поэтому CER у этой реплики завышен; по выравниванию ElevenLabs и громкости все 23 слова, включая каждое «нөл», озвучены, между группами номера паузы 0,3–0,5 с; «Балаго менен жолго чыгалы» распознано без ошибок. Начала реплик не обрезаны: на огибающих файлов и в финальном миксе громкость в первые 150 мс после старта у 21 реплики выше фона на 9–30 дБ; у n13 звук начинается на 0,15 с раньше метки выравнивания («Про-» в «Профилдин»), файл открывается тишиной (−85 дБ) — начало целое.
- **Музыка под речью**: средний уровень микса на речи −17,5 дБ RMS, без речи −25,0 дБ. Найдена почти полная тишина на стыке сцен 5→6 и перед репликой мамы в сцене 6 (до −50 дБ) — добавлен музыкальный мост. Остались только короткие паузы 0,3–0,6 с между близкими репликами с тихой подложкой (около −42 дБ).
- **Кадры**: листы контрольных кадров всех сцен (начало, середина, конец), кадр каждой реплики, по два кадра у каждого из 13 стыков сцен из готового MP4, плотные раскадровки передачи телефона, перехода через экран в воспоминание и совпадения жеста «прядь за ухо». Черновые фрагменты со звуком (половинное разрешение): начало с телефоном, танец мамы и сына, воспоминание, передача телефона папе, финальная карточка.
- **Синхронность губ и субтитров**: рот открывается по визе­мам из выравнивания ElevenLabs, умноженным на огибающую громкости. При дикторе рты закрыты (губы привязаны к роли говорящего). Субтитры берут те же тайминги, что и звук.
- **Сюжет и реклама**: заявка везде «алдын ала» (предварительная, «каттамды сүйлөшүү үчүн»), поездки не показаны начавшимися. Нет цены, адреса и названия школы. WhatsApp и номер — только в финале (последняя реплика и карточка), номер совпадает с номером владельца в `src/config.ts` (тест). Нет карандаша, иглы, чужого логотипа, английских надписей и кадров референса.

## Ограничения

- **На слух фильм не прослушан.** В среде нет аудиовыхода, у подключённого OpenAI закончились кредиты (`insufficient_quota`), распознавание Meta MMS работает только в CI. Звук проверялся по распознаванию (CER), огибающим, громкости и спектрограммам. Произношение «Балаго» и естественность интонаций нужно один раз прослушать человеку.
- **Движение проверено по кадрам и раскадровкам, а не в реальном времени.** Между проверенными кадрами плавность на 30 fps глазами не смотрели. Танцевальные стопы проверены тестом.
- Стилизация: телефон (ширина 58 px мира, одна и та же модель во всех сценах) слегка крупный относительно стилизованных кистей. Полотенце в сцене 11 небольшое.
- Ветка `claude/balago-33-moms-old-video-24ds8n` вместо `feature/balago-33-moms-old-video` — требование среды.
- После замены финального призыва (новая реплика n13, блок WhatsApp на карточке, финал 23,4 с, деление субтитров) фильм полностью перерендерен командой `npm run render:moms-old-video`; итоговый MP4 соответствует этому коммиту.
