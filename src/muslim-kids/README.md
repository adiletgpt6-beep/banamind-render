# Muslim Kids — анимационная система образовательных роликов

Отдельная точка входа Remotion (`src/muslim-kids/index.ts`), ролики BalaGo не затрагиваются.
Правила BalaGo о контактах, Бишкеке и кыргызской озвучке к Muslim Kids не применяются.

## Ролики

| Композиция                 | Тема                                              | Файлы        |
| -------------------------- | ------------------------------------------------- | ------------ |
| `MuslimKidsAliImran190191` | «Посмотри на небо!» — сура «Аль-Имран», 3:190–191 | `ali-imran/` |

## Повторно используемые части (`lib/`)

- `particles.ts` — формации (`(i, кадр) → состояние частицы`) и морфинг между ними:
  изогнутые траектории, разброс запуска (`stagger`, `order`), смешение цвета/размера.
  Всё детерминировано — кадры рендерятся параллельно без скачков.
- `ParticleCanvas.tsx` — холст на весь кадр: свечение на тёмном фоне, motion blur
  (шлейф) только для быстро летящих частиц, слои `below`/`above`.
- `shapes.ts` — облака точек: диск-подсолнух, серп Луны, Солнце с лучами, капля,
  дерево (рекурсивные ветви + крона), открытая книга, звёздное поле.
- `earth.ts` + `land-mask.ts` — Земля из частиц: материки Natural Earth 1:110m
  (маска 1°, `scripts/muslim-kids/build-land-mask.mjs`), вращение на восток вокруг оси
  с наклоном 23,4°, освещение параллельными лучами (ровно половина шара на свету).
- `ui.tsx` — сетка-фон, кинетическая типографика `Reveal`/`Header`, водяной знак.
- `theme.ts`, `../fonts.ts` — палитра (#08090D, #FFFFFF, #2878FF, #8FC5FF) и шрифты
  Inter / Unbounded / Amiri (OFL, лежат в `public/muslim-kids/fonts`).

## Как устроен ролик

1. `script.ts` — утверждённый текст по сценам; тип каждой реплики:
   объяснение / пересказ смысла / цитата перевода смысла.
2. `scripts/muslim-kids/voice.mjs` — озвучка ElevenLabs по репликам с таймингами слов
   (ключ — секрет CI). Готовые реплики с тем же хэшем не синтезируются повторно.
3. `timeline.ts` — длительности сцен и кадры слов из манифеста озвучки
   (без озвучки — оценка по тексту). `Cues.word("s2b", "ночь")` → кадр слова.
4. `choreo.ts` — путь частиц через весь ролик, привязанный к словам.
5. `scenes/*` — фон (`Back`, под частицами) и текст/SVG (`Front`, над частицами).
6. `sound.ts` + `scripts/muslim-kids/sfx.mjs` — звуки без музыки (воздух, частицы,
   капля, вода, ветер), процедурно и детерминированно.

## Команды

```bash
node scripts/muslim-kids/timeline.mjs           # тайм-лайн по текущей озвучке
node scripts/muslim-kids/sfx.mjs                # пересобрать звуки
npx remotion studio src/muslim-kids/index.ts    # просмотр
npx remotion render src/muslim-kids/index.ts MuslimKidsAliImran190191 out/mk.mp4
node scripts/muslim-kids/verify.mjs out/mk.mp4  # проверка формата, звука, пустых кадров
```

CI: `.github/workflows/muslim-kids.yml` — озвучка → проверка Whisper → рендер
1080×1920 30 fps H.264/AAC → проверка → релиз `muslim-kids-ali-imran-190-191`.

## Проверки «Посмотри на небо!»

- Озвучка: Whisper medium по всем репликам (CER 0–0,04); цитата 3:191 дополнительно
  проверяется large-v3 по словам (`ASR_STRICT_LINES`). В первых дублях модель слышала
  «сотворила» — в тексте для синтеза поставлены ударения «сотвори́л э́то», текст на экране
  и в субтитрах не изменён.
- MP4: `scripts/muslim-kids/verify.mjs` — H.264 1080×1920 30 fps yuv420p, AAC, длительность
  по тайм-лайну, громкость, нет чёрных участков и долгой тишины, faststart.
