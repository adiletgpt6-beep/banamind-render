# BalaGoUnansweredLetter2D — «Жооп берилбеген кат» (№21)

«Письмо, на которое мама не отвечала». 1080×1920, 30 fps, ровно 120 с
(3600 кадров). Кадр для телефона: тёмный фон; над карточкой — строка
активной темы («Кат / Мектеп / Календарь / Сүрөт / Жооп», постоянные цвета) и
дня; одна крупная карточка с действием (x 30–1050, y 250–1400; содержимое
рисуется в проектных координатах 940 px и масштабируется); под ней —
постоянная полоса субтитров (y 1424–1660) с портретом говорящего: Айжан,
коллега, муж и дочь — их собственные портреты (рот по их речи), рассказчик —
логотип BalaGo. Низ кадра свободен под интерфейс соцсетей. Без приглушённых
«следующих» карточек и вторых слоёв; смена планов — склейками.

Рассказчик — по одному предложению на файл: одной генерацией два
предложения звучали слитно (пауза ≈ 0,1 с, темп ≈ 16 букв/с), отдельные

уходит в прозрачность — на стыках нет тёмных кадров).

## Ракурсы ноутбука и машины

- Кабинет: Айжан сидит лицом к зрителю, перед ней ноутбук — видна только
  задняя сторона крышки (без текста) и край основания (`sets/Office.tsx`,
  `LaptopFront`). Письмо, набор и клики — в плане через её плечо
  (`graphics/LaptopOver.tsx`): тот же ноутбук с экраном, клавиатурой и
  тачпадом, кисти с пальцами (серии нажатий, курсор и щелчок по тачпаду).
- Дом: ноутбук в три четверти (основание, клавиши, тачпад, крышка на шарнире,
  экран к маме).
- Школа: седан в реальном масштабе относительно девочки (`sets/Sedan.tsx`),
  правостороннее движение. Общий план через дорогу: машина подъезжает справа
  налево к школьному тротуару (виден борт водителя). Встречная точка с
  тротуара: машина смотрит вправо, дочка идёт к ЗАДНЕЙ пассажирской двери
  (за передней, где мама), открывает её за ручку (шарнир у переднего края),
  садится — с этого момента рисуется между салоном и кузовом, дверь
  закрывается и её видно только через стекло; в салоне она на том же заднем
  месте за пассажирским креслом и пристёгивается; машина уезжает вправо —
  туда же растёт линия «Мектеп → Үй».

## Голоса (сохранённые голоса проекта, ElevenLabs eleven_v3, ky)

Рассказчик — новый голос Voice Design (`voiceDesign.ts`, вариант
narratorF-2: MMS CER 0,4 %, ровный тон без «надрыва»; сэмплы, отчёты и
распознавание — `voice-samples/unanswered-letter-2d/`). Прежний KG-teacher
звучал напряжённо: широкие скачки тона (F0 155–291 Гц) и глухой верх. Реплики
синтезируются сначала с паузой и страховочным словом (конечная интонация
фразы, затем вырезается), дубль с оборванным последним слогом не берётся.

рассказчик BalaGo — KG-narrator (Voice Design), Айжан — KG-mother, муж — KG-husband, дочка —
KG-daughter, коллега — Eric. Режимы: `narrator` (закадровый голос, рты персонажей закрыты), `live`
(говорит только этот персонаж), `inner` (внутреннее чтение — рты закрыты).

Контрольные записи рассказчика (начало и финальный призыв в трёх режимах
подачи: stability 0,5 / 1,0 / [warmly]) — `voice-samples/unanswered-letter-2d/control/`
(`voiceDesign.ts`, `UL2_NARRATOR_CONTROL`).

## Команды

```
npm run audio:voice:unanswered-letter-2d   # озвучка (нужен ELEVENLABS_API_KEY; готовые реплики из кэша)
npm run test:unanswered-letter-2d
npm run bundle && npm run stills:unanswered-letter-2d
npm run render:unanswered-letter-2d
node scripts/ul2d-cue-table.mjs > src/unanswered-letter-2d/CUES.md
node scripts/ul2d-loudness.mjs out/balago-unanswered-letter-2d.mp4
node scripts/verify-ul2d.mjs out/balago-unanswered-letter-2d.mp4
node scripts/ul2d-speech-check.mjs out/balago-unanswered-letter-2d.mp4
```

Workflow `.github/workflows/unanswered-letter-2d.yml` собирает оба MP4 и
публикует их в предварительном релизе `unanswered-letter-2d-preview`.
