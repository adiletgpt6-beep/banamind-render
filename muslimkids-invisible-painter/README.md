# MUSLIM KIDS — эксперимент 005 · THE INVISIBLE PAINTER

Мультфильм **«Когда краски оживают»**: размышление о творении Аллаха по суре
«Аль-Имран», 3:190–191. Возраст 5–12 лет, русский язык, 60 с,
1080×1920, 30 fps, H.264/AAC. Отдельный проект; к роликам BalaGo отношения не имеет.

Техника — **PAINTERLY WORLD ANIMATION**: краска сама растекается по бумаге,
складывается в рисунок, рисунок оживает (**PAINT → AWAKENING → ALIVE**),
а в финале всё возвращается на холст (**RETURN TO CANVAS**). Сцены переходят друг
в друга через трансформацию краски, без простых fade/cut/slide.

| Сцена | Время | Что происходит |
|---|---|---|
| 1. Первый мазок | 00:00–00:06 | золотое пятно растекается, два мазка вливаются, спираль → Солнце |
| 2. Нарисованная Земля | 00:06–00:15 | синий мазок → диск, материки, облака → объём, вращение, «ДЕНЬ»/«НОЧЬ» → нырок в океан |
| 3. Живой океан | 00:15–00:24 | синяя заливка отступает → полосы моря → живые волны → берег, лес, горы |
| 4. Росток и дерево | 00:24–00:34 | пар → облака → дождь → капля → развод → семечко → росток → дерево |
| 5. Небо и знамения | 00:34–00:44 | день сменяется ночью, звёзды из пятен краски, Земля на картине, 3:190 |
| 6. Главная мысль | 00:44–00:54 | всё возвращается в краску; неподвижная цитата 3:191 на резерве бумаги |
| 7. Посмотри вокруг | 00:54–01:00 | мальчик на холме смотрит на звёзды; вся картина; «А ЧТО УДИВЛЯЕТ ТЕБЯ?» |

## Запуск

```bash
cd muslimkids-invisible-painter
npm install
npm run studio            # просмотр в Remotion Studio
npm run stills -- 60 540  # контрольные кадры из реальной композиции → output/previews/
npm run render:preview    # черновик 540×960
npm run render            # финал → output/final/MuslimKids_InvisiblePainter_005.mp4
```

Озвучка уже лежит в `public/audio/` (s1…s7.wav + `voice.json` с длительностями).
Пересинтез — ElevenLabs (`node scripts/voice.mjs`, нужен `ELEVENLABS_API_KEY`;
в репозитории это делает workflow `.github/workflows/muslimkids-voice.yml`
при изменении `scripts/lines.mjs`). Сведение звука: `python3 scripts/sound.py`
(нужны numpy и ffmpeg) → `public/audio/soundtrack.wav`.

В облачной среде используется предустановленный Chromium
(`remotion.config.ts`, переменная `REMOTION_BROWSER`).

## Архитектура

```
src/
  engines/
    InvisiblePainterEngine.ts      конвейер кадра: слой краски → грануляция → бумага → multiply → свет
    WatercolorSimulationEngine.ts  пятно-wash: многослойная деформация, растекание языками,
                                   мокрый край, water bloom, текстуры бумаги и зерна
    BrushStrokeEngine.ts           мазок: Catmull-Rom, профиль нажима, щетинки, сухая кисть
    PaintMorphEngine.ts            пересэмплирование и «текучая» интерполяция форм
    PaintToLifeEngine.ts           состояния PAINT/AWAKENING/ALIVE и обратный путь
    PainterlyCameraController.ts   камера по ключам (Эрмит, лог-зум), параллакс слоёв
    PainterlyLightingSystem.ts     мягкое свечение (screen) после наложения краски, палитра
  painted/                         художественные объекты: LivingEarth, PaintedSky, PaintedLand,
                                   PaintedOcean, PaintedClouds, PaintedTree, PaintedBoy
  scenes/                          Scene01…Scene07 (тайминги и состояния), world.ts (единый холст),
                                   index.ts (порядок сцен и камеры)
  components/                      PaintingCanvas (canvas), Typography (неподвижные надписи)
  timeline.json                    кадры сцен и старты фраз озвучки (общий для видео и звука)
scripts/  voice.mjs, lines.mjs, sound.py, stills.mjs, sheet.py
```

Ключевые принципы:

- **Детерминизм.** Каждый кадр — чистая функция номера кадра: `useCurrentFrame()`,
  фиксированные seed, никакого `Math.random()`/`requestAnimationFrame`. Растекание
  пигмента — аналитическая функция прогресса, а не накопление симуляции: кадр 900
  рендерится без кадров 0–899. Геометрия пятен кэшируется по id.
- **Акварель = multiply.** Прозрачные слои перемножаются (синий + золотой → зелёный);
  гуашь (облака, блики, листва) — source-over; «резерв» бумаги — destination-out.
  Цвет пигмента заранее компенсируется, чтобы наслоения не «грязнили».
- **Свет — тоже краска.** Объём и тени кладутся лессировками; сияние Солнца и звёзд —
  мягкий screen поверх бумаги, без агрессивного bloom.
- **Текст отдельно.** Слова перевода смысла — чёткий неподвижный слой, появляется и
  исчезает целиком, никогда не превращается в мазки.

Чтобы сделать новый урок в том же стиле, достаточно новых объектов в `painted/`
(из `drawWash`/`drawStroke`), новых таймингов в `scenes/` и новой озвучки.

## Исламская корректность

- Краски — только художественный приём: в фильме нет «художника», руки, кисти или
  света, изображающих Создателя; о «невидимом художнике» в фильме не говорится.
- 3:190 дан как изложение смысла (подпись «изложение смысла»).
- 3:191 — часть перевода смысла Э. Кулиева, без изменений:
  «Господь наш! Ты не сотворил это понапрасну». Подпись: «Сура „Аль-Имран“, 3:191.
  Часть аята. Перевод смысла (Э. Кулиев)».
- Арабский текст не используется. Пророки не изображаются. Без музыки.
- Вращение Земли — вокруг своей оси с запада на восток при неизменном направлении
  солнечного света: освещённая сторона — день, теневая — ночь.
- Официальный логотип Muslim Kids в репозитории не найден, поэтому в финале — только
  текстовая надпись MUSLIM KIDS (новый логотип не придумывался).
