# MUSLIM KIDS — Эксперимент 004 · Geometry of Wonders

**«Удивительная геометрия мира»** — 60-секундный образовательный мультфильм
(5–12 лет, русский язык) по мотивам суры «Аль-Имран», 3:190–191.
Визуальный приём — **Pattern Bloom («Раскрытие узора»)**: простые фигуры
соединяются в орнамент, а орнамент перестраивается в объёмный объект.

Отдельный проект: не зависит от BalaGo и предыдущих экспериментов.

## Сцены и превращения

| Время | Сцена | Что происходит (геометрическая логика) |
| --- | --- | --- |
| 0–6 с | 1. Одна фигура | Треугольник → 6 копий радиально → ряды раскрываются из соседей через общее ребро (поворот в 3D) → розетка 486 треугольников |
| 6–14 с | 2. Рождение Земли | Розетка изгибается с растущей кривизной (диск → чаша → шар), грани окрашиваются по реальной карте, грани сглаживаются в Землю; сетка рёбер узора остаётся |
| 14–23 с | 3. День и ночь | Земля вращается вокруг своей оси (на восток), Солнце неподвижно слева; дуга из сегментов-стрелок; «ДЕНЬ»/«НОЧЬ» на словах диктора; грани проявляются при подлёте |
| 23–33 с | 4. Горы и лес | Треугольная сетка; вершины поднимаются → горы со снегом; осколки склонов летят вниз и собираются в кроны деревьев; ветви растут процедурно; раскрывается цветок |
| 33–43 с | 5. Соты | Центр цветка (шестиугольники) → 1, 2, 3 ячейки → соты по спирали, мёд, восковые крышечки; золотая волна «повторения»; ячейки поворачиваются на 30°, между ними — треугольники |
| 43–53 с | 6. Знамения | Плоский узор сот → большой радиальный орнамент 12-кратной симметрии; в центре Земля, символы неба, звёзд и Солнца; «РАЗМЫШЛЯЙ О ТВОРЕНИИ» |
| 53–60 с | 7. Главная мысль | Орнамент останавливается и раздвигается; перевод смысла 3:191; шесть треугольников складываются в знак; MUSLIM KIDS |

## Архитектура (src/)

```
engines/
  GeometryWondersEngine.ts     ядро: seed-RNG, easing, треки ключевых кадров (конфигурация),
                               ShapeState (координаты, размер, цвет, вращение, прозрачность,
                               глубина, состояние) → InstancedMesh
  GeometricMorphEngine.ts      ресемплинг полигонов, интерполяция вершин, соответствие фигур,
                               изгиб плоскости в сферу, раскрытие через общее ребро
  PatternGenerator.ts          розетка из треугольников, звёзды, ромбы, змеи, радиальная/зеркальная симметрия
  TessellationEngine.ts        шестиугольная спираль, треугольная сетка
  ProceduralWorldBuilder.ts    шум (fbm/ridged), рельеф, процедурные деревья и лес
  GeometryCameraController.tsx камера по ключевым кадрам, плавный облёт, мягкий параллакс
  GeometryLightingSystem.tsx   пресеты света (ключ, заполняющий, контровой, акцент, тени), смешивание
systems/
  AudioSyncSystem.tsx          реплики и звуки, время слов из manifest.json
  TypographySystem.tsx         надписи отдельным слоем (шрифт Nunito, OFL)
  earthTexture.ts              карта Земли из Natural Earth (world-atlas) + облака
components/                    RosetteSphere, GeometryEarth, GeometryMountains, GeometryForest,
                               GeometryFlower, Honeycomb, FinalPattern, LogoMark, GeometricSun, FinalTexts
scenes/                        Scenes01to03Planet, Scene04Landscape, Scene05Honeycomb, Scenes06to07Creation
compositions/                  MuslimKidsGeometryWonders004 (слои + переходы)
timeline.ts                    все тайминги; ключевые — по словам озвучки
```

Всё детерминировано: время берётся только из `useCurrentFrame()`, случайность —
из фиксированного seed. Много одинаковых фигур — `InstancedMesh`; розетка
и горы — одна `BufferGeometry` с пересчётом вершин на CPU.

### Как сделать новую историю

1. Новый узор — функция в `PatternGenerator` / `TessellationEngine`.
2. Превращение — `GeometricMorphEngine` (`morphPolygon`, `matchByPolar`,
   `rollToSphere`, `edgeUnfold`) + трек времени `makeTrack/sample` или `ramp`.
3. Сцена — компонент с `ThreeCanvas`, планом камеры `cameraPlan([...])`
   и пресетом `LIGHTS.*`; тайминги — в `timeline.ts` через `word("id", "слово")`.

## Запуск

```bash
cd muslimkids-geometry-wonders
npm ci
npm run studio                 # предпросмотр в Remotion Studio
npm run typecheck
node scripts/render-stills.mjs # контрольные кадры → output/keyframes/ (+ contact-sheet.jpg)
npm run render:preview         # 540×960
npm run render                 # 1080×1920 → output/final/
npm run verify                 # ffprobe-проверка итогового MP4
```

`remotion.config.ts` указывает Chromium из `/opt/pw-browsers` и `--gl=angle`
(программный WebGL). На другой машине уберите `setBrowserExecutable` —
Remotion скачает свой браузер.

### Озвучка

Текст и время начала реплик — `voice.json`. Синтез выполняет workflow
`.github/workflows/muslimkids-geometry-voice.yml` (секрет `ELEVENLABS_API_KEY`):
`scripts/generate-voice.mjs` → `public/audio/voice/*.mp3` + `manifest.json`
(тайминги слов), дубли проверяются распознаванием (`scripts/asr_ru.py`,
faster-whisper). Изменение `start` в `voice.json` не требует нового синтеза.

Звуки: `node scripts/generate-sfx.mjs` → `public/audio/sfx/` (синтез, без музыки).

## Исламская корректность

- Аллах не изображается ни в каком виде; геометрия — только художественный
  язык, она не «создаёт мир» и не подаётся как доказательство.
- Сцена 6 — пересказ темы аятов 3:190–191 (подписано «пересказ смысла»).
- Сцена 7 — дословно часть перевода смысла 3:191 (Э. Кулиев):
  «Господь наш! Ты не сотворил это понапрасну», подпись «Часть аята. Перевод смысла.»
- Нет арабских надписей-орнаментов, нет утверждений о сотах в Коране.
- Знак в финале — собственный (шесть треугольников + круг), официального
  логотипа Muslim Kids в репозитории нет.
