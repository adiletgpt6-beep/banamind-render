# lesson-80 · ролик 80-1-2 · Урок 1. Аллах — наш Создатель. Анимация 2: «Что спрятано в яблоке?»

Композиция Remotion **`Lesson80-1-2-WhatIsInsideApple`** (папка `Lesson80-1-2` в студии) —
1920×1080, 16:9, 30 к/с, H.264 + AAC 48 кГц. Восемь сцен, 43 реплики
авторского сценария (`80-1-2-001` … `80-1-2-043`), две обязательные паузы для
ответа зрителя: 4 с и 5 с.

Ролик продолжает визуальный мир первого фильма «Кто построил домик?»
(`src/lesson01`, композиция `Lesson01WhoBuiltTheHouse`). Используются те же риг и
модели героев (Мухаммад, Юсуф, Амир, Билал, 22 фоновых ученика), та же комната,
доска, рассадка и голоса. Домик первого фильма стоит на тумбе у стены.

## Команды

```bash
npm ci
npm run studio                         # предпросмотр (папка Lesson80-1-2)
npm run test:80-1-2                    # сценарий, шкала, паузы, озвучка, SRT
npm run render:80-1-2                  # → out/lesson-80-1-2-what-is-inside-apple-16x9.mp4
npm run render:80-1-2 -- --subtitles   # отдельная версия со встроенными субтитрами (по желанию)
npm run verify:80-1-2                  # проверка готового MP4 (формат, громкость, паузы по звуку)
npm run srt:80-1-2                     # пересобрать SRT по озвучке
npm run stills:80-1-2 -- 0,12.5s,300   # контрольные кадры (номер кадра или секунды)
```

Если Chrome Headless Shell не скачивается, укажите установленный Chromium:
`REMOTION_BROWSER_EXECUTABLE=/путь/к/chrome npm run render:80-1-2`.
Число потоков рендера: `RENDER_CONCURRENCY` (по умолчанию — число ядер).

Рендер (`scripts/lesson80-1-2-render.mjs`): проверяет полноту озвучки и паузы,
рендерит Remotion, выравнивает громкость (−17 LUFS, true peak ≤ −1,5 dBTP; меняется
только звук), затем запускает `scripts/lesson80-1-2-verify.mjs`.

## Озвучка

* Голоса — те же, что в первом фильме (`roles` и `group` в `voices.json`):
  учитель — «Lesson-teacher-Muhammad» (ElevenLabs Voice Design), дети — светлые
  молодые голоса проекта.
* CI `.github/workflows/lesson80-1-2.yml` при изменении `script.ts`/`voices.json`
  синтезирует недостающие дубли (ElevenLabs `eleven_v3`, `ru`, секрет
  `ELEVENLABS_API_KEY`) и сохраняет их в ветку. Готовые дубли повторно не
  синтезируются (ключ — хэш текста, голоса, модели, настроек и seed).
* `npm run audio:build:80-1-2` — сборка файлов реплик из выбранных дублей: обрезка
  страховочного слова и тишины, выравнивание громкости речи, тайминги слов/букв
  и огибающая для губ. Темп и высота тона не меняются.
* `npm run audio:qa:80-1-2` — распознавание каждой реплики (OpenAI
  gpt-4o-transcribe) и доля ошибок относительно сценария. По распознаванию обоих
  дублей выбраны `pick` в `voices.json`.

### Как заменить одну реплику и пересчитать время

1. **Своя запись.** Положите `public/audio/lesson80-1-2/override/80-1-2-0NN.wav`
   (или `.mp3`) и выполните `npm run audio:build:80-1-2`. Границы речи
   определятся по громкости.
2. **Новый синтез.** Измените `seed` (или `tag`/`spoken`) у реплики в `script.ts`
   и запушьте: CI синтезирует только её. Затем `npm run audio:build:80-1-2`.
3. **Другой голос роли** — `roles` в `voices.json`.

После замены: `npm run test:80-1-2 && npm run srt:80-1-2 && npm run render:80-1-2`.
Шкала, сцены, жесты, планы, паузы и субтитры пересчитываются автоматически: все
события привязаны к фактическим границам речи в манифесте (`A2_FLOW`).
Паузы для зрителя заданы одним событием (`{ pause: … }`) — от конца
произнесённого вопроса до начала ответа.

## Отчёт о сборке (10.10.2026)

**Результат:** `out/lesson-80-1-2-what-is-inside-apple-16x9.mp4` (в Git не хранится —
`out/` и `*.mp4` в `.gitignore`; воспроизводится `npm run render:80-1-2`).

Проверено фактически:

* Формат (`npm run verify:80-1-2`): 1920×1080, H.264 yuv420p, 30 к/с, AAC 48 кГц,
  **4:18,77** (план 4:20, рабочий диапазон 4:00–4:45; речь не ускорялась),
  −17 LUFS, true peak −4,1 dBTP, чёрных кадров нет.
* Паузы для ответа зрителя — по фактическим (акустическим) границам речи:
  4,13 с после «Ребята, назовите что-нибудь…» и 5,12 с после «Кто создал растения…»
  (123 и 153 кадра; нужно ≥ 120 / 150). По звуку готового файла внутри пауз —
  только фон комнаты (≈ −42…−46 дБFS; первые 50 мс — затухание последнего слога).
  Во время пауз: рты закрыты, схема на доске без подсветки, текста ответа нет,
  субтитр ответа появляется только с началом ответа (проверено тестом SRT).
* Речь: каждая из 43 реплик распознана (gpt-4o-transcribe) по обоим дублям; выбраны
  дубли с дословным текстом. Распознавание всей дорожки готового MP4 (Whisper):
  все реплики звучат в порядке сценария, посторонней речи и чтения служебного
  текста нет. «И за яблоко тоже!» — по контуру тона восклицание (тон падает
  356 → 232 Гц), а не вопрос.
* Изображение: обзорные листы всего фильма (кадр каждые 2 с) и раскадровки
  6 к/с до, во время и после действий: яблоко кладётся рукой на тарелку; нож
  берётся с салфетки, разрез (крупная вставка), нож возвращается на салфетку;
  раскрытие половинок; семечко — щепотью на отдельное блюдце; пчела на цветке
  яблони A → перелёт → цветок яблони B (пыльца на теле и на цветке B);
  лепестки опадают → завязи только у двух цветков из пяти → спелые яблоки;
  Юсуф придвигает блюдце с семечком.
* Первый фильм не затронут: кадры `Lesson01WhoBuiltTheHouse` (900, 4200)
  до и после изменений совпадают попиксельно.
* `npm run test:80-1-2` — 6/6; `tsc` и `eslint src/lesson80-1-2` — без ошибок.

Ограничения (честно):

* **Детские голоса — временные, те же, что в первом фильме.** Настоящих
  детских голосов в доступных сервисах нет (ElevenLabs Voice Design отклоняет
  описания детских голосов, библиотека голосов недоступна ключу, голоса OpenAI
  TTS — взрослые). Юсуфа, Амира и Билала озвучивают светлые молодые голоса
  проекта (основной тон ≈ 300 / 250 / 210 Гц) без изменения тона и темпа —
  ради преемственности с первым фильмом. По критериям ТЗ ролик с этими
  голосами не считается окончательным: замените реплики детей записями
  (см. «Как заменить одну реплику»), остальное пересчитается автоматически.
* Прослушивания «на слух» в среде сборки нет: звук проверен распознаванием,
  замерами громкости, основного тона и тишины в паузах. Движение проверено по
  покадровым раскадровкам, а не просмотром в реальном времени.
* Учитель всё время сидит на коленях у стола (как в первом фильме); жест к
  доске — открытая ладонь. Доска висит высоко, поэтому «учитель рядом с доской»
  в среднем плане читается по жесту и склейке на рисунок, а не одним кадром.
* Шрифт — Nunito из проекта (полная кириллица, локальный файл).
* Субтитры по умолчанию не встроены (основная версия понятна без них);
  встроенный слой включается `npm run render:80-1-2 -- --subtitles`, отдельный
  файл — SRT в `docs/lesson80-1-2/`.
