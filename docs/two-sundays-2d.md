# BalaGoTwoSundays2D — «Эмне үчүн анын эки жекшембиси бар?»

Сценарий №26 («Почему у неё два воскресенья?»). В детском календаре дочки
вместо среды написано «Биздин жекшемби», а настоящее воскресенье осталось на
своём месте. Мама думает, что дочка перепутала дни. В будни мама утром
отвозит дочку в школу, днём выезжает с работы, привозит её домой к бабушке и
возвращается доделывать задачи. Папа тоже работает в офисе, но по средам
работает из дома и заранее выделяет время на школьные поездки; мама в этот
день спокойно проводит встречи и приходит раньше. Вечером семья вместе
готовит ужин, разговаривает и играет — для дочки это праздник. Родители
сами находят BalaGo и отправляют **предварительную** заявку, чтобы обсудить
школьный маршрут на остальные дни (среда остаётся за папой; ни водителя, ни
подтверждённых поездок, ни цен). На следующем ужине календарь становится
общим: мама вешает его на холодильник двумя магнитами, папа дописывает
«Оюн» и спрашивает, кто выберет игру на среду, — дочка поднимает руку.
Дочка обращается к родителям на «сиз». Контакты — ровно последние 150 кадров: «Профилдин башындагы шилтемеге өтүңүз же WhatsApp аркылуу жазыңыз: 0998 08 38 28».

Код — `src/two-sundays-2d/`, композиция `BalaGoTwoSundays2D`
(`src/BalaGoTwoSundays2D.tsx`), аудио — `public/audio/two-sundays-2d/`,
workflow — `.github/workflows/two-sundays-2d.yml`.

## Что взято из референса (1000206955.mp4, по описанию задания)

Файл референса в среде сборки недоступен; использовано его описание.
Перенесены способы построить кадр — по смыслу, без подписей ракурсов,
стрелок поля зрения, счётчиков и чужих надписей:

1. **Предметный крупный план** — «Жекшемби» → «Биздин жекшемби» (сц. 1),
   лямка, сумка, крышка ноутбука, магниты, «Оюн» (сц. 3, 4, 14).
2. **Строго сверху** — лист календаря, вилки на столе, настольная игра,
   блокнот (сц. 1, 5, 7, 8, 11).
3. **Через плечо** — мама и папа рассматривают лист; экран ноутбука папы
   (сц. 2, 6, 10).
4. **С высоты ребёнка** — разговоры у детского стола (сц. 2, 9): мама
   садится рядом, камера на уровне глаз дочки, без взгляда сверху.
5. **Передний план с мягким размытием** — край миски, чашка (сц. 8, 13).
6. **Раскрытие пространства** — от детали к понятному общему плану
   (сц. 1, 8).
7. **Совпадение форм** — солнышко рисунка → пятно света на кухне (сц. 3);
   клетка «Шаршемби» → экран расписания (сц. 6); край тарелки → кухня
   (сц. 8); нарисованный стол → настоящий стол (сц. 8–9).
8. **Короткая типографика** — «Эмне үчүн эки жекшемби?», «Мектеп → Үй →
   Кеңсе», белые карточки с мягкой тенью и оранжевые акценты.

## Ассеты

- `props/Calendar.tsx` — один постоянный детский календарь: ровно семь
  клеток (4 + 3, без восьмой рамки), «Биздин жекшемби» в третьей клетке,
  рисунок «мама — дочка — папа за столом», оранжевое солнышко-наклейка;
  слои: карандашные контуры, последний луч, «Оюн» (раскрывается за кончиком
  карандаша).
- `props/Schedule.tsx` — рабочий день папы в среду: окна «Мектепке
  жеткирүү» и «Мектептен алып келүү» среди обычных задач.
- `props/PhoneScreen.tsx` — постановочный экран заявки: поиск «BalaGo» →
  страница («Балдар үчүн такси», «Үй → Мектеп → Үй», «Мектеп каттамын
  талкуулоо») → «Алдын ала өтүнмө», «Каттам күндөрү» (Дүй, Шей, Бей,
  Жума; среда — «Шаршембиде атасы алып келет») → «Өтүнмө жөнөтүлдү»,
  «Каттамды тактоо үчүн байланышабыз». Без адреса сайта, номеров, имён.
- `sets/Home.tsx` (детский стол, кухня с холодильником, прихожая),
  `sets/MomOffice.tsx`, `sets/Office.tsx` (офис папы), `sets/Street.tsx`.
- Персонажи — риг №22 (`rig/`): мама (тёмно-синий жакет; дома — кардиган
  того же цвета), папа (серо-голубая рубашка, без бороды), дочка 8–9 лет
  (косички; школа — тёмно-синий жакет, дома — оранжевая кофта, как на
  рисунке), бабушка (седой пучок, коричневый кардиган).

темп и высота тона не меняются. Рассказчик — KG-teacher
`EBOfpUWl9G5ltD2PkFgy`, мама — KG-mother `5Xx0r0RX4XWEq5vEdv8p`, папа —
KG-husband `NVEGeFqcDqc5o29VoAQm`, дочка — голос из проб
(`scripts/su2d-girl-probe.mjs`, `voice-samples/two-sundays-2d/girl-probe/`).

Прежний KG-daughter при слепом прослушивании (gpt-audio-1.5, без подсказки о
роли) оценивался неустойчиво: от «подростка» до «взрослой женщины» и даже
«мужчины». Детские описания Voice Design сервис блокирует (из трёх
описаний первого раунда и ремикса прошло одно), поэтому пробовались только
описания взрослых актрис дубляжа. Выбор — по слепому прослушиванию,
F0 и CER MMS; это технический фильтр, а не замена прослушиванию человеком.
Каждая новая реплика синтезируется в трёх дублях; в ролик идёт дубль с
наименьшим штрафом (CER + темп + для дочки профиль «ребёнок/возраст»).
Кэш — по хэшу текста, тега, голоса, модели и настроек: повторный рендер
ElevenLabs не вызывает.

## Звук

Музыка своя (`scripts/su2d-music.mjs`, без бочки и щелчков): любопытство →
будни (чуть больше пульса) → тёплая среда → очень тихо под объяснением
дочки (D02) → собранно (заявка) → мягкое завершение; под речью музыка
приглушается, к последнему кадру затихает. Эффекты
(`scripts/su2d-foley.mjs`, `scenes/sfx.ts`) — только с видимым действием:
карандаш, сумка, дверь машины, крышка ноутбука, приборы, лист, касание
кнопки, магниты. **Шагов нет.** Мастеринг −14 LUFS, true peak ≤ −1 dBTP.

## Повторный рендер

```
npm ci
npm run audio:voice:two-sundays-2d   # ELEVENLABS_API_KEY; готовое — из кэша, пересчёт timeline.json
npm run test:two-sundays-2d
npm run render:two-sundays-2d        # без полной озвучки рендер останавливается
node scripts/su2d-loudness.mjs out/balago-two-sundays-2d.mp4
ffmpeg -i out/balago-two-sundays-2d.mp4 -vf scale=540:960:flags=lanczos -c:v libx264 -crf 23 \
  -pix_fmt yuv420p -c:a aac -b:a 160k -movflags +faststart out/balago-two-sundays-2d-mobile.mp4
node scripts/verify-su2d.mjs out/balago-two-sundays-2d.mp4
```

Черновые кадры до готовой озвучки: `--props='{"preview":true}'`.
Workflow `.github/workflows/two-sundays-2d.yml` делает всё это сам и
публикует оба MP4 в pre-release `two-sundays-2d-preview`.
