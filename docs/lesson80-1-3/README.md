# lesson-80 · ролик 80-1-3 · Урок 1 «Аллах — наш Создатель» · мини-фильм 3 «А если я не вижу?»

Композиция Remotion **`Lesson80-1-3-WhatIfICantSee`** (папка `Lesson80-1-3` в студии) —
1920×1080, 16:9, 30 к/с, H.264 (yuv420p) + AAC 48 кГц. Восемь сцен, 42 реплики
авторского сценария (`80-1-3-001` … `80-1-3-042`), три обязательные паузы для
ответа зрителя (4 / 4 / 5 с) и отдельный невербальный опыт — выдох Юсуфа (≈3 с
без речи). Музыки нет.

Это третий мини-фильм **первого урока** (не «урок 3»): он продолжает «Кто
построил домик?» (`src/lesson01`) и «Что спрятано в яблоке?» (`src/lesson80-1-2`).
Те же риг и модели героев (Мухаммад, Юсуф, Амир, Билал и 22 фоновых ученика —
ровно 25 мальчиков в постоянной расстановке `SEATS`), та же комната, доска,
окно, шкаф, тумба с домиком из первого фильма и те же голоса.

## Озвучка

* Голоса — те же, что в первых двух фильмах (`roles` в `voices.json`): учитель —
  «Lesson-teacher-Muhammad» (ElevenLabs Voice Design), дети — молодые голоса
  проекта, которые серия использует временно (см. «Ограничения»).
* CI `.github/workflows/lesson80-1-3.yml` синтезирует недостающие дубли
  (ElevenLabs `eleven_v3`, `ru`, секрет `ELEVENLABS_API_KEY`; готовые дубли
  повторно не синтезируются — ключ = хэш текста, голоса, модели, настроек и
  seed) и распознаёт новые дубли и файлы реплик локальной моделью Whisper
  (`scripts/lesson80-1-3-asr.py`, кэш по хэшу файла).
* Сначала синтезированы пробные реплики (вопрос Юсуфа, реплика Амира, два длинных
  уточнения Мухаммада, итог Билала: `voices.json → stage: "samples"`), затем все 42.
* `npm run audio:build:80-1-3` — сборка файлов реплик: обрезка страховочного
  слова в самой тихой точке перед ним, начало — от настоящей тишины (тайминги
  синтеза бывают на 0,1–0,15 с раньше или позже звука), выравнивание громкости,
  границы речи по звуку, тайминги слов/букв и огибающая для губ. Темп и высота
  тона не меняются.
* Выбор дублей (`pick`) — по распознаванию всех дублей.

### Как заменить одну реплику

1. **Своя запись.** Положите `public/audio/lesson80-1-3/override/80-1-3-0NN.wav`
   (или `.mp3`) и выполните `npm run audio:build:80-1-3`.
2. **Новый синтез.** Измените `seed` (или `tag`/`spoken`) у реплики в `script.ts`
   и запушьте: CI синтезирует только её. Затем `npm run audio:build:80-1-3`.
3. **Другой голос роли** — `roles` в `voices.json`.

После замены: `npm run test:80-1-3 && npm run srt:80-1-3 && npm run render:80-1-3`.
Шкала, сцены, действия, планы, паузы и субтитры пересчитываются автоматически.

## Звук и сведение

Без музыки. Речь — файлы реплик (громкость выровнена); фон — тихая комната
(петля из первого фильма), воздух у открытого окна и край занавески (громче,
когда камера у окна), шуршание бумажных лепестков — только пока ротор
вращается и пропорционально скорости, вдох и выдох Юсуфа, касания подставки и
палочки, ткань, едва слышные шаги по моментам опоры стоп. Громкость петель
задаётся на всю длину ролика (`loopVolumeCurveBehavior="extend"`). Итог —
`loudnorm` до −16 LUFS, true peak ≤ −1,5 dBTP (меняется только звуковая дорожка).

## Ограничения

* **Озвучку не слушал человек.** Качество проверено распознавателями (тексты,
  имена, обрезки слов) и замерами (громкость, паузы, огибающие). Перед выпуском
  нужна проверка на слух: интонации, ударения, естественность.
* **Детские голоса временные** — те же голоса проекта, что в первых двух фильмах;
  Амир и Билал звучат как молодые женские голоса, а не как мальчики.
* **Имя «Юсуф» в 041.** Диктор произносит «Спрашивай, Юсуф» слитно, без паузы
  после запятой (во всех 14 дублях); Whisper слышит «Спрашиваю, Юсов» (в полном
  дубле с контекстом — верно). В 008 и 026 имя распознаётся как «Юсуф».
  Варианты — своя запись реплики (`override/`) или новый синтез.
* **015:** Whisper слышит «ощущение» вместо «ощущения» — стоит проверить на слух.
* **Распознавание:** кредиты OpenAI исчерпаны, у ключа ElevenLabs нет права
  `speech_to_text` — новые проверки только локальным Whisper в CI.
* **Лицо учителя:** рисунок усов модели серии (общий риг) визуально опускает
  уголки рта; в паузах добавлена улыбка, сам риг не менялся, чтобы не затронуть
  первые два фильма.
* **Плотная посадка класса:** на части крупных планов фоновые дети срезаны краем
  кадра по лбу или корпусу; лица героев и учителя в кадре целиком.
* **Звуки** (воздух, бумага, вдох/выдох, шаги) синтезированы
  (`scripts/lesson80-1-3-sfx.mjs`), тихие; их тоже стоит послушать.
* **Мелочи, оставленные сознательно** (отмечены ревьюерами как незначительные):
  в объясняющем жесте и при переносе правая рука учителя согнута поперёк
  корпуса (локоть у середины, ладонь раскрыта) — другие решения рига хуже
  (локоть к лицу Юсуфа или прямая рука через весь корпус); на склейке внутри
  проходок (сцены 2 и 8) меняется экранное направление движения; при
  постановке подставки на низкий столик на один кадр меняется порядок
  «подставка/рукав»; за крупным планом Амира виден торс Билала без головы.
