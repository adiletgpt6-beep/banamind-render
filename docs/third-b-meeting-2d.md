# BalaGoThirdBMeeting2D — «Переговоры в третьем “Б”»

Сценарий №23. Айжан руководит дизайн-студией «АЙКЫН». Утром клиенты (кафе
«БУЛАК») переносят встречу на 13:30 — ровно на конец уроков дочки; папа в
этот день проводит обучение сотрудников. Айжан подключается из машины у
школы. Посреди уверенной презентации дочка поднимает рисунок вывески класса
«3 Б» — лист попадает в веб-камеру, клиент спрашивает: «Кечиресиз… Сиз азыр
үчүнчү «Б» класстасызбы?». Мама с улыбкой представляет дочку, клиент тепло
шутит, затем проект согласуют. Вечером родители сами находят BalaGo и
отправляют **предварительное обращение** через WhatsApp (без цен, дат,
водителя, оплаты и подтверждённого маршрута). Дочка рисует вывеску «АЙКЫН»
для маминого кабинета и подписывает «Дизайнер — 3 Б». Контакты — ровно
последние 150 кадров. «АЙКЫН» и «БУЛАК» — вымышленные названия внутри
истории.

## Постановка в машине (геометрия звонка)

- Машина — обычный белый седан без логотипа и «такси»-раскраски
  (`props/Car.tsx`). Вид через улицу — нос влево, к зрителю левая сторона
  (водительская дверь); вид с тротуара — нос вправо, правая сторона.
  Передняя и задняя двери вращаются вокруг шарниров у переднего края.
- Мама приехала за рулём; на глазах зрителя (вид с пустой полосы дороги)
  открывает водительскую дверь, выходит с ноутбуком, закрывает дверь,
  открывает заднюю левую и садится (склейка в проёме). Перед отъездом —
  обратный путь: ноутбук в чехле, задняя дверь, водительская, ремень.
- Дочка — сзади справа на бустере с момента посадки; ремень от крепления у
  её внешнего плеча поперёк груди к замку у бедра (не через шею).
- Ракурсы (`scenes/cabinA.tsx`, `scenes/callShots.tsx`):
  **A** — камера между передними сиденьями смотрит назад: мама справа в
  кадре, дочка слева; у ноутбука видна только наружная крышка.
  **B** — экран через плечо: слайд «БУЛАК», клиент, партнёр и крупное окно
  «Айжан» (без зеркалирования).
  **C** — кадр веб-камеры, что получает клиент.
  **D** — рабочее место клиента: через плечо монитор с тем же потоком.
- Веб-камера смотрит маме в лицо, дочка сидит справа от неё — в кадре
  камеры лист входит слева; в ракурсе A дочка тоже слева, лист поднимается
  рядом с лицом мамы, не закрывая его. Состояние листа, лица мамы и клиента
  — функции абсолютного кадра (`scenes/callPlan.ts`), поэтому во всех
  ракурсах рисунок в одном и том же месте; бумажный рисунок никогда не
  появляется внутри слайда.

## Графический язык

Светлая 2D-графика с тёплым дневным светом: молочный `#F6F2EA`,
тёмно-синий `#182638`, жёлтый BalaGo `#FFD447`, янтарный `#EA974B` (лампа,
карандаш), спокойный зелёный `#718B7A` (школа, образцы). Шрифты Inter Tight
Black и Onest (OFL, расширенная кириллица Ү Ө Ң). Переходы между сценами —
4 коротких предметных связки (`Transitions.tsx`): окно звонка → крышка
ноутбука в студии; янтарная светящаяся линия на почти чёрном фоне (по
референсу, единственный «неоновый» акцент); вечерний круг на лампе; жёлтый
круг в карточку. Внутри действия предметы не превращаются друг в друга.

## Тайминг (по фактической речи)

Режим `narration` — рассказчик за кадром (рты закрыты); `live` — живая речь
(рот двигается только у говорящего, по таймингам букв и огибающей файла;
в окнах звонка — тот же персонаж в тот же интервал). Таблица обновляется
`node scripts/t3b-docs.mjs`.

обработка): повторный рендер не вызывает TTS.

доказательство естественности кыргызского произношения. Профиль audeering
относит все «детские» голоса к взрослым женщинам (известное ограничение).

## Звук

Музыка своя (`scripts/t3b-music.mjs`, без бочки и щелчков): любопытство →
лёгкий ритм сборов → тише во время звонка → прозрачно на вопросе дочки →
тепло в дороге → собранно вечером → тёплое завершение, продолжающееся под
карточкой. Под речью приглушается (под голосом дочки сильнее), к последнему
кадру затихает. Эффекты (`scripts/t3b-foley.mjs`) только с видимым
действием: альбом, лист, щелчок ремня, мягкая дверь, сигнал завершения
звонка, крышка ноутбука, одно касание «отправить», карандаш, тихий салон.
**Шагов нет.** Мастеринг −14 LUFS, true peak ≤ −1 dBTP.

## Повторный рендер

```
npm ci
npm run audio:probe:third-b-meeting-2d   # пробы (ELEVENLABS_API_KEY; один раз на конфигурацию)
npm run audio:voice:third-b-meeting-2d   # реплики из кэша; пересчёт timeline.json
npm run test:third-b-meeting-2d
npm run render:third-b-meeting-2d        # без полной озвучки рендер останавливается
node scripts/t3b-loudness.mjs out/balago-23-third-b-meeting-2d.mp4
ffmpeg -i out/balago-23-third-b-meeting-2d.mp4 -vf scale=540:960:flags=lanczos -c:v libx264 -crf 23 \
  -pix_fmt yuv420p -c:a aac -b:a 160k -movflags +faststart out/balago-23-third-b-meeting-2d-mobile.mp4
node scripts/verify-t3b.mjs out/balago-23-third-b-meeting-2d.mp4
```

Workflow `.github/workflows/third-b-meeting-2d.yml` делает всё это сам и
публикует оба MP4 в pre-release `third-b-meeting-2d-preview`. Во время
работы над роликом внешние сервисы (WhatsApp и т. п.) сообщений не
получают: экран телефона постановочный.
