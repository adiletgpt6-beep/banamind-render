# BalaGo №31 — «13:20дагы жолугушуу» («Встреча в 13:20»)

Композиция **BalaGoMeeting1320**, 2D, 1080×1920, 30 к/с, H.264/AAC, yuv420p,
faststart. Исходники — `src/meeting-1320/`, ассеты — `public/meeting-1320/`
(`voice/`, `music/`, `sfx/`, `grain.png`), постановка по планам —
`docs/meeting-1320-bible.md`.

Готовые файлы: `out/balago-31-meeting-1320-2d.mp4` и мобильная копия
`out/balago-31-meeting-1320-2d-mobile.mp4` (540×960, тот же монтаж и звук);
в CI — предварительный релиз `meeting-1320-2d-preview`.

## О чём фильм

В календаре директора каждый день есть встреча в 13:20 — без компании, имени
и номера комнаты. Другие встречи он переносит или проводит онлайн, эту —
никогда. Новая помощница замечает пункт; важный заказчик предлагает 13:30,
директор просит предложить 14:30 и постараться вернуться. В 13:20 он берёт
ключи, едет на своей машине мимо бизнес-центра во двор школы — и только
там зритель узнаёт, кто его ждёт: сын выбегает с новостью про удачный опыт.
Отец пристёгивает его, отвозит к бабушке (жена работает в другом районе) и
возвращается: заказчик уже приехал, отец заканчивает звонок на парковке и
включается в обсуждение. Вечером — «Уулумду мектептен алып кетем». Дома отец
сам находит BalaGo, показывает жене, они оставляют **предварительную**
заявку. Перед сном сын приносит рисунок опыта; отец отодвигает бумаги и
освобождает место рядом.

BalaGo в истории никого не возит и ничего не подтверждает: только
предварительная заявка. Семейная машина — своя, без логотипа; белый
Volkswagen Polo — только иллюстрация на финальной карточке. Финал — по
постоянным правилам проекта (`AGENTS.md`): Бишкек в озвучке и в кадре, оба
способа связи — ссылка в профиле и WhatsApp **0998 08 38 28** — в озвучке
и на неподвижной карточке. Адрес сайта не показывается.

## Команды

```bash
npm run audio:probe:meeting-1320   # пробы голосов (ELEVENLABS_API_KEY; один раз на конфигурацию)
npm run audio:voice:meeting-1320   # озвучка (кэш по хэшу; новая реплика — 3 дубля, лучший по MMS)
npm run audio:music:meeting-1320   # своя инструментальная музыка
npm run audio:sfx:meeting-1320     # эффекты и атмосфера
npm run test:meeting-1320          # тесты шкалы, голосов и текстов
npm run render:meeting-1320        # out/balago-31-meeting-1320-2d.mp4
node scripts/m1320-loudness.mjs out/balago-31-meeting-1320-2d.mp4   # −16 LUFS, TP ≤ −1 dBTP, faststart
node scripts/verify-m1320.mjs out/balago-31-meeting-1320-2d.mp4      # формат, длительность, громкость
node scripts/m1320-docs.mjs        # таблица тайминга ниже
```

CI — `.github/workflows/meeting-1320.yml`: пробы и озвучка (новые файлы
сохраняются в ветку) → по запросу (`workflow_dispatch` или «[render]» в
сообщении коммита) тесты, кадры, MP4 1080×1920 и копия 540×960 → проверки
(каждая реплика слышна и распознаётся MMS в готовом звуке) → релиз.

## Постановка (≈ 60 планов)

Монтажные приёмы референса — вставки предметов ровно на фразе (время,
календарь, ключи, ремень, телефон, бумаги, рисунок), наезд на деталь, которая
меняет смысл, чередование общий/средний/крупный, короткие надписи в момент
слова. Все склейки и действия привязаны к словам реплик (`sceneTools`:
`T.word`, `T.from`), абсолютных кадров в сценах нет.

1. **Календарь.** Макро «13:20» → отъезд к рабочему календарю; заголовок
   «13:20дагы жолугушуу»; дни перелистываются («Күн сайын. Бир эле
   убакыт.»), 13:20 остаётся; на «Компаниянын / аты-жөнү / бөлмөнүн»
   открываются пустые поля.
2. **Помощница замечает.** Общий офиса → она за монитором; встреча 11:00
   уезжает на 16:00, другая становится «Онлайн», 13:20 не двигается;
   уведомление «Кардар 13:30»; её взгляд на кабинет.
3. **«Жылдырсак болобу?»** Обратный план из-за ноутбука директора (экран к
   нему, крышка к нам) → вставка 13:20 → директор спокойно: «Кардарга саат
   эки жарымды сунушта…» → планшет помощницы: «14:30».
4. **13:20.** Часы 13:19 → 13:20; рука берёт ключи (звук в момент касания);
   выход мимо помощницы; рука с ключами → ручка двери своей машины (без
   логотипа); машина едет мимо башни «Бизнес-борбор»; сверху — поворот во
   двор. Школы и сына до этого момента нет.
5. **Школьный двор.** Только здесь вывеска «Мектеп»; сын выбегает: «Ата!» —
   пауза — «Бүгүн тажрыйбабыз ийгиликтүү болду!»; отец присаживается:
   «Айтып берчи». Задняя дверь со стороны тротуара, сын садится, крупно —
   ремень через плечо (не по шее) и щелчок замка. В дороге сын рассказывает
   с жестами; календарный пункт 13:20 получает смысл «Уулум — мектеп».
6. **Бабушка.** Дверь квартиры открывается, бабушка встречает внука, он
   машет отцу и уходит в квартиру; бабушка кивает — отец кивает в ответ.
   Один короткий кадр: мама за работой в офисе другого района (часы —
   после обеда, коллега приносит папку). Без конфликта.
7. **Возвращение.** Машина уже на парковке бизнес-центра — тогда звонок:
   «кардар келип калыптыр»; отец заканчивает разговор, убирает телефон,
   закрывает машину, входит в переговорную, садится и сразу включается.
8. **Вечер.** Помощница уточняет неделю (13:20 — каждый день, «Эртең»),
   спрашивает про завтра; «Ооба. Уулумду мектептен алып кетем.» — короткая
   улыбка понимания, кивок.
9. **Дома.** Жена и муж обсуждают дорогу; планер недели, палец жены по
   меткам 13:20. Отец сам берёт телефон, ищет «Балдарды мектептен алып
   келүү», открывает страницу BalaGo и поворачивает экран к жене — она
   придвигается вместе со стулом. Палец жены на «ҮЙ → МЕКТЕП → ҮЙ»; форма
   «Аты-жөнү / Дарек / Мектеп / Убакыт» (личные данные — серые штрихи) →
   «Өтүнмө калтыруу» → только **«Алдын ала өтүнмө жөнөтүлдү»**.
10. **Рисунок.** Поздний вечер: сын выходит из коридора с рисунком (магнит
    и скрепки, «Тажрыйба»), спрашивает — пауза — отец поднимает глаза;
    сверху его руки отодвигают стопку бумаг; он хлопает по спинке стула:
    «Жаныма отур…»; сын садится и кладёт рисунок на освободившееся место;
    вставка рисунка; тихий тёплый план.
11. **BalaGo.** N19: логотип, «BalaGo», «Бишкек • Балдар үчүн такси»,
    маршрут «ҮЙ → МЕКТЕП → ҮЙ», белый Volkswagen Polo подъезжает и встаёт.
    К началу N20 появляется блок контактов: «Профилдеги шилтемеге өтүңүз»,
    «же WhatsApp аркылуу жазыңыз» и крупно на жёлтой плашке «WhatsApp:
    0998 08 38 28». С этого кадра карточка неподвижна до конца ролика (больше
    5 с; после последнего слова N21 — не меньше 3 с). Всё важное — в x 90…900,
    y ≤ 1420; субтитры финала наверху и номер не закрывают.

## Голоса

ElevenLabs `eleven_v3`, кыргызский, stability 0,5, similarity 0,8. Голоса
выбраны автоматическими пробами (`npm run audio:probe:meeting-1320`,
отчёт — `voice-samples/meeting-1320/probe/report.json`): по три кандидата на
роль, оценка — распознавание MMS (`facebook/mms-1b-all`, адаптер `kir`),
темп и профиль возраст/пол (audeering). Диктор — KG-boss (спокойный
мужской), отец — KG-husband, помощница — KG-teacher, сын — KG-son. Каждая
реплика — три дубля, в ролик идёт лучший по CER; кэш по хэшу. Темп и высота
тона не менялись. В голосе бренд — «Балаго», в субтитрах — BalaGo.

## Звук

Музыка — своя (`scripts/m1320-music.mjs`), шесть инструментальных дорожек
без ударных и вокала: загадка календаря, дорога, тепло (школа, бабушка),
день, дом, финал. Под речью музыка приглушается, в сцене с рисунком —
тише всего. Эффекты — только на видимых действиях: ключи, дверь машины,
ремень (вытягивание и щелчок), вибрация и касания телефона, бумаги, рисунок
на стол, дверь квартиры, стул, мягкое уведомление; тихие атмосферы офиса,
улицы, двора и комнаты. Шагов и «вжухов» нет. Четыре записи — Gravity
Sound, CC BY 4.0 (`public/meeting-1320/sfx/CREDITS.md`), остальное —
синтез. Громкость готового файла: −16 LUFS, true peak ≤ −1 dBTP.

- `npm run lint` (ESLint + TypeScript) и `npm run test:meeting-1320` —
  11 тестов: порядок и паузы реплик, речь внутри своих сцен; финал по
  правилам проекта — Бишкек и оба способа связи в озвучке, на карточке
  «Бишкек • Балдар үчүн такси», «Профилдеги шилтемеге өтүңүз», «же WhatsApp
  аркылуу жазыңыз», «WhatsApp: 0998 08 38 28», карточка неподвижна ≥ 5 с,
  после последнего слова ≥ 3 с; голоса ролей постоянны (4 разных), начало и
  конец каждой реплики не обрезаны (по самой волне), субтитры = тексту,
  времена 13:20 / 13:30 / 14:30, поля формы, только предварительная заявка,
  нет адреса сайта, Polo только на карточке, без шагов, кыргызские буквы.
- Кадры ключевых моментов просмотрены и исправлены: загадка календаря,

- Звук готового файла (`scripts/m1320-speech-check.mjs`): все 30 реплик

- Распознавание MMS каждой реплики прямо в готовом MP4 (с музыкой и
  эффектами, `scripts/m1320-export-asr.mjs`, CI): все 30 реплик распознаны

  y ≤ 1423; субтитры финала наверху (y 150…308) и номер не закрывают; после
  последнего слова (N21 до 156,94 с) — 3,4 с.
- F02 «Айтып берчи» (0,7 с) сначала не проходила эту проверку: с тегом

  восклицанием (слова и субтитр те же), выбран дубль с CER 0. Пробы голосов
  при этом заморожены: правка реплики больше не перезапускает кастинг.

## Ограничения

- Прослушать звук ушами инструментами этой сессии нельзя: разборчивость и
  голоса проверены автоматически (MMS по каждому дублю и по готовому
  миксу, модель возраста/пола), а не слушателем.
- Голос сына KG-son — «мультяшный» детский голос взрослой актрисы: модель
  возраста относит все детские кандидаты к взрослым женским голосам;
  высоту тона механически не меняли (по требованию).
- Музыка синтезирована своим скриптом — простая, спокойная, без
  живых инструментов.
- Риг процедурный: персонажи показываются в профиль и анфас (вида со спины
  нет), поэтому вход в квартиру и коридор поставлены сбоку.
