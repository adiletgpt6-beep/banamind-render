# Урок 1. Аллах — наш Создатель. Анимация 1: «Кто построил домик?»

Композиция Remotion **`Lesson01WhoBuiltTheHouse`** — 1920×1080, 16:9, 30 к/с,
H.264 + AAC 48 кГц. Восемь сцен, 40 реплик авторского сценария, обязательные
паузы 4 / 5 / 4 с для ответа зрителя.

## Команды

```bash
npm ci
npm run studio                       # предпросмотр (папка Lesson01)
npm run test:lesson01                # сценарий, шкала, паузы, озвучка
npm run render:lesson01              # → out/lesson-01-who-built-the-house-16x9.mp4
npm run render:lesson01 -- --subtitles   # отдельная версия с субтитрами (по желанию)
npm run verify:lesson01              # проверка готового MP4
npm run srt:lesson01                 # пересобрать SRT по озвучке
```

Рендер: `scripts/lesson01-render.mjs` проверяет полноту озвучки и паузы,
рендерит Remotion, выравнивает громкость (−17 LUFS, true peak ≤ −1,5 dBTP —
меняется только звук) и проверяет файл. Если Chrome Headless Shell не
скачивается: `REMOTION_BROWSER_EXECUTABLE=/путь/к/chrome npm run render:lesson01`.

## Озвучка

* CI `.github/workflows/lesson01.yml` при изменении `src/lesson01/**` синтезирует
  недостающие дубли (ElevenLabs `eleven_v3`, `ru`, секрет `ELEVENLABS_API_KEY`)
  и сохраняет их в ветку. Готовые дубли повторно не синтезируются (ключ — хэш
  текста, голоса, модели, настроек и seed).
* `npm run audio:build:lesson01` — сборка файлов реплик из выбранных дублей:
  обрезка страховочного слова, тишины по краям, выравнивание громкости,
  тайминги слов/букв и огибающая для губ. Темп и высота тона не меняются.
* `npm run audio:qa:lesson01` — распознавание каждой реплики (нужен доступ к
  api.openai.com) и доля ошибок относительно сценария; по нему выбраны дубли
  (`pick` в `voices.json`).

### Как заменить одну реплику

1. **Своя запись.** Положите файл `public/audio/lesson01/override/<id>.wav`
   (или `.mp3`), где `<id>` — номер реплики (`L01`…`L40`, для разделённой
   реплики `L33a` / `L33b`), и выполните `npm run audio:build:lesson01`.
   Границы речи определятся по громкости; шкала сдвинется сама.
2. **Новый синтез.** Измените `seed` (или `spoken`/`tag`) у реплики в
   `src/lesson01/script.ts` и запушьте — CI синтезирует только её; затем
   `npm run audio:build:lesson01`.
3. **Другой голос роли** — `roles` в `src/lesson01/voices.json`.

После замены: `npm run test:lesson01 && npm run srt:lesson01 && npm run render:lesson01`.

## Отчёт о сборке (10.10.2026)

**Результат:** `out/lesson-01-who-built-the-house-16x9.mp4` (в Git не хранится,
см. `.gitignore`; воспроизводится `npm run render:lesson01`).

Проверено фактически:

* Формат (`npm run verify:lesson01`): 1920×1080, H.264 yuv420p, 30 к/с,
  AAC 48 кГц, **4:29.78** (рабочий диапазон 4:20–5:00), −17 LUFS,
  true peak −3,9 dBTP, чёрных кадров нет.
* Паузы для ответа зрителя (по звуку готового файла): 4,15 / 5,15 / 4,15 с от
  конца вопроса до начала ответа (нужно ≥ 4 / 5 / 4); внутри — только фон
  комнаты (≈ −45 дБFS).
* Речь: все 40 реплик звучат в порядке сценария (распознавание всей дорожки);
  каждая реплика проверена распознаванием, выбран точный дубль (L38 —
  повторный синтез: первый вариант произносил «сделает»).
* Изображение: контрольные кадры всех сцен и покадровые последовательности
  захвата кубика, установки крыши и деревца, посадки учителя, поднятой руки
  Билала, взгляда Юсуфа на ладони, артикуляции на крупных планах.
* `npm run test:lesson01` — 5/5, `npm run lint` для `src/lesson01` — без ошибок.

Ограничения (честно):

* **Детские голоса — временные.** Настоящих детских голосов в доступных
  сервисах нет: ElevenLabs Voice Design отклоняет описания детских голосов
  (403 safety), ключ не имеет права `voices_read` для библиотеки, голоса
  OpenAI TTS — взрослые. Юсуфа, Амира и Билала озвучивают светлые молодые
  голоса проекта (≈300 / 260 / 220 Гц), без изменения тона и темпа. По
  критериям ТЗ ролик с такими голосами не считается окончательным: замените
  реплики детей записями (см. «Как заменить одну реплику»), остальное
  пересчитается автоматически. Голос учителя создан Voice Design
  (голос «Lesson-teacher-Muhammad» сохранён в аккаунте ElevenLabs).
* Прослушивания «на слух» в среде сборки нет: звук проверен распознаванием,
  замерами громкости, основного тона и тишины в паузах. Движение проверено по
  покадровым последовательностям, а не просмотром в реальном времени.
* Ходьбы нет: переход к окну — начало подъёма героев и склейка на план у окна
  (как допускает ТЗ). Посадка учителя — плавное смешивание подготовленных поз.
* Шрифт — Nunito из проекта (полная кириллица, локальный файл).
