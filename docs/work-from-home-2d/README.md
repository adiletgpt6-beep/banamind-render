# №28 «Почему мама задерживалась дома?» — `BalaGoWorkFromHome2D`

Рисованный 2D-фильм (Remotion/React/SVG): 1080×1920, 30 fps, **2:33**
(4590 кадров). Готовые файлы: `balago-28-work-from-home-2d.mp4` и мобильная
копия `balago-28-work-from-home-2d-mobile.mp4` (540×960, тот же монтаж,
голоса и субтитры).

**Смысл.** Мама — аналитик и работает из дома, но ежедневные поездки за
сыном разрывают её день: после дороги нужно заново восстановить контекст
задачи, работа уходит в вечер, ужин остывает. Однажды сына забирает папа и
занимается с ним дома — при том же объёме задач мама закрывает ноутбук в
17:30 и спокойно смотрит тетрадь сына. Помогать каждый день папа не может,
поэтому родители сами находят BalaGo и оставляют **предварительную** заявку
на маршрут «Мектеп → Үй»; дома сына встречает мама. В тот же вечер мама
открывает книгу рядом с сыном. Последние 150 кадров — контактная карточка.

Без поездки BalaGo, подтверждения маршрута, оплаты и ответов сотрудников;
номер WhatsApp появляется только на карточке.

## Постановка

- Квартира одна и та же во всех сценах (`sets/Home.tsx`): гостиная с диваном
  и книжной полкой, кухня-столовая, дверь рабочей комнаты. Рабочая комната
  (`sets/WorkRoom.tsx`) — отдельная, дверь в семейную часть слева; та же
  жёлтая лампа видна из кухни через проём.
- Ноутбук в натуральном масштабе, экраном к маме: со стороны камеры видна
  только боковая грань крышки; рабочие экраны — отдельными вставками «из-за
  плеча» с руками на клавишах. Крышка закрывается вокруг петли, рука лежит
  на её верхнем крае (`lidTop`), после 17:30 ноутбук закрыт во всех планах.
- Машины в масштабе 460 px/м (седан ≈ 2,7 роста взрослого): у мамы
  серебристо-голубая, у папы — тёмно-синяя; без надписей. Посадка сына —
  вставками: открытая дверь → сиденье → ремень поверх тела к замку; машина
  трогается после закрытой двери.
- Риг персонажей — копия рига ролика №12 (`rig/`): шаг по пройденному пути,
  повороты «глаза → голова → корпус», губы по таймингам букв и громкости
  файла (рот двигается только у говорящего). Исправлено для профиля: при
  наклоне корпуса плечи и голова поворачиваются вместе с торсом (шея не
  отрывается).
- Предметы — по одному экземпляру: ключи лежат на столе до касания и дальше
  идут за кистью; тетрадь (голубая, «Менин үй-бүлөм») и книга (красная,
  «Жомоктор») различаются; тарелки, телефон.

## Команды

```bash
npm run audio:probe:work-from-home-2d   # голосовые пробы (ELEVENLABS_API_KEY)
npm run audio:voice:work-from-home-2d   # 19 реплик; готовые берутся из кэша
node scripts/wfh2d-docs.mjs             # timeline.json и lines.md
npm run test:work-from-home-2d          # шкала, тексты, контакт, озвучка
npm run bundle && npm run stills:work-from-home-2d   # контрольные кадры
npm run render:work-from-home-2d        # MP4 + мастеринг + мобильная копия
node scripts/verify-wfh2d.mjs out/balago-28-work-from-home-2d.mp4
```

Шкала сцен и моменты реплик — `src/work-from-home-2d/script.ts`
(`WFH_SCENES`, `WFH_LINES[].at`). После изменения текста или seed реплики
перегенерируется только она (хэш: текст, тег, голос, модель, настройки,
seed). При изменении длительности фильма карточка автоматически остаётся
последними 150 кадрами (`WFH_CARD_FROM = WFH_FRAMES − 150`).

**CI** — `.github/workflows/work-from-home-2d.yml`: voice (пробы + озвучка,
сохранение файлов в ветку) → render (lint, тесты, кадры, MP4, мастеринг,
мобильная копия, проверка) → publish (предварительный релиз
`work-from-home-2d-preview` с обоими MP4). Флаг `render` в
`scripts/wfh2d-probe.json` включает сборку MP4.
