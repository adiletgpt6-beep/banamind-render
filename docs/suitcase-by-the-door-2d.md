# BalaGo №36 — «Чемодан у двери» (Эшиктин жанындагы чемодан), 2D

Композиция **`BalaGo36SuitcaseByTheDoor2D`** (Remotion, 1080×1920, 30 fps, H.264 yuv420p +
AAC 48 кГц). Исходники: `src/suitcase-by-the-door-2d/`, озвучка:
`public/audio/suitcase-by-the-door-2d/`. Готовый файл:
`out/balago-36-suitcase-by-the-door-2d.mp4` (и облегчённая копия `…-mobile.mp4`, 540×960).

## История

Мама готовится к выступлению на профессиональной встрече в другом городе (три дня: дорога,
выступление, обсуждения с коллегами), но перед подтверждением поездки открывает школьное
расписание сына: обычно после уроков его забирает она, папа в эти часы на встречах, бабушка
может встретить мальчика дома — нужно организовать дорогу к ней. За ужином мама говорит, что,
может быть, попросит коллегу поехать вместо неё; папа напоминает, что выступление готовила она.
Папа сам договаривается с коллегой, одну встречу передаёт, другую проводит раньше и на три дня
берёт школьные поездки на себя. Мама снова кладёт папку в чемодан. Вечером родители обсуждают,
как готовиться к таким ситуациям, сами находят BalaGo и оставляют **предварительную** заявку,
чтобы обсудить маршрут и возможное расписание (без подтверждения, водителя и брони). Во время
командировки сына забирает папа. Вечерний видеозвонок: мама показывает фото зала, сын
спрашивает, стояла ли она на сцене. После возвращения мальчик находит мамин бейдж
«Айжан · Спикер», кладёт рядом свою школьную фотографию и просит показать, что она
рассказывала. Мама открывает ту же жёлтую папку и садится рядом. Финал BalaGo.

Визуальные якоря: серо-синий чемодан (колёса на одном торце, рёбра корпуса, крышка на шарнире),
охристая папка выступления, школьное расписание (Дш–Жм, дни поездки Шш–Бш), бейдж на синем
шнурке, школьная фотография (то же рисованное лицо мальчика — голова из рига), серая семейная
машина без логотипа, белая стилизованная Volkswagen Polo только в финале.

## Видеореференс и что из него взято

Приложенный ролик (720×1280, 24 fps, ≈ 94 с) просмотрен по кадрам (листы каждые 3 с и крупные
кадры 00:05, 00:17, 00:44, 01:04, 01:18). Взят визуальный язык, сюжет — новый:

- кремовый фон с широкими мягкими диагоналями и лёгкой бумажной фактурой
  (`kit.tsx: Paper`, неподвижное зерно `public/assets/suitcase-36/paper-grain.png`,
  `scripts/sd2d-paper.mjs`, детерминированно);
- тонкий тёмный слегка неровный контур у персонажей и предметов (у персонажей — подложкой
  в риге, у предметов — `roughRect/roughPath/roughEllipse` с неровностью, заданной один раз),
  карандашная штриховка в тенях;
- короткие тёмно-синие схемы со светлыми линиями (`Blueprint`, `BpLine`), обводящие круги
  с засечками (`Ring`) и стрелки — точечно, один акцент на вставку;
- крупные субтитры: светлый жирный текст с тёмной обводкой, без плашки, редкое выделение
  слова жёлтым;
- движение предметов объясняет историю (папка в чемодан и обратно, карточки встреч в
  календаре, поля заявки), переходы через форму предметов.

Чужие тексты, логотипы, никнеймы и производственный сюжет референса не переносились.

## Сборка и проверка

```bash
npm run audio:voice:suitcase-by-the-door-2d   # озвучка (только в CI: ключ — секрет репозитория)
npm run render:suitcase-by-the-door-2d        # → out/balago-36-suitcase-by-the-door-2d.mp4
node scripts/sd2d-loudness.mjs out/balago-36-suitcase-by-the-door-2d.mp4   # ≈ −16,5 LUFS, TP ≤ −1,5 дБ
node scripts/verify-sd2d.mjs out/balago-36-suitcase-by-the-door-2d.mp4     # 1080×1920, 30 к/с, H.264 yuv420p, AAC 48 кГц
node scripts/sd2d-speech-check.mjs out/balago-36-suitcase-by-the-door-2d.mp4
node scripts/sd2d-deliverables.mjs out        # SRT, текст озвучки, scene-timeline.json
npm run test:suitcase-by-the-door-2d
```

Контрольные кадры одной сценой: `node scripts/sd2d-frames.mjs who:0.5 trip:120 …`
(`SD2_SCALE`, `SD2_OUT`). Рендер в CI — workflow «BalaGo36SuitcaseByTheDoor2D»: запуск вручную
(Run workflow) или push с `[render]` в сообщении коммита. Артефакты:
`balago-suitcase-by-the-door-2d-mp4` (1080×1920), `balago-suitcase-by-the-door-2d-mobile-mp4`
(540×960), `balago-suitcase-by-the-door-2d-frames` (контрольные кадры),
`balago-suitcase-by-the-door-2d-docs` (SRT, текст озвучки, шкала).
