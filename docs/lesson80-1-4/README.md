# lesson-80 · ролик 80-1-4 · Урок 1. Аллах — наш Создатель. Мини-фильм 4: «Один Создатель»

Композиция Remotion **`Lesson80-1-4-OneCreator`** (папка `Lesson80-1-4` в студии) —
1920×1080, 16:9, 30 к/с, H.264 + AAC 48 кГц. Восемь сцен, 47 реплик
утверждённого сценария (`80-1-4-001` … `80-1-4-047`), четыре паузы для ответа
зрителя (4 / 5 / 5 / 5 с, всего 19 с), две экранные надписи.

Ролик продолжает серию «Кто построил домик?» (`src/lesson01`, 80-1-1) и
«Что спрятано в яблоке?» (`src/lesson80-1-2`): те же риг и модели героев
(Мухаммад, Юсуф, Амир, Билал и 22 фоновых ученика на своих местах), та же
комната (ковёр, низкий столик, доска, полка, окно, домик первого фильма на
тумбе), те же голоса. Предыдущие фильмы не изменены (см. «Отчёт»).

## Озвучка

* Голоса — те же, что в фильмах 80-1-1 и 80-1-2 (`roles` в `voices.json`):
  учитель — «Lesson-teacher-Muhammad» (ElevenLabs Voice Design); Юсуф, Амир,

  общий ответ детей «Один! Аллах!» — смесь шести голосов (`group`).
* CI `.github/workflows/lesson80-1-4.yml`: при изменении `script.ts`/`voices.json`
  синтезирует недостающие дубли (ElevenLabs `eleven_v3`, `ru`, секрет
  `ELEVENLABS_API_KEY`, по 3 дубля на реплику), затем распознаёт каждый дубль и
  каждую готовую реплику открытой моделью Whisper large-v3 (4 параллельные
  части) и сохраняет `docs/lesson80-1-4/voice-asr.json`. Ключи в коде и логах
  не хранятся.
* `npm run audio:pick:80-1-4` — выбор дублей: дословность по распознаванию,
  чистота разреза перед страховочным словом, интонация (по пробам).
* `npm run audio:build:80-1-4` — сборка реплик: начало режется по звуку (теги
  эмоций сдвигают тайминги синтеза), конец — в самой тихой точке перед
  страховочным словом, громкость речи выравнивается. Темп и высота не меняются.

### Как заменить одну реплику и пересчитать время

1. **Своя запись.** Положите `public/audio/lesson80-1-4/override/80-1-4-0NN.wav`
   (или `.mp3`) и выполните `npm run audio:build:80-1-4`.
2. **Новый синтез.** Измените `seed` (или `tag`/`spoken`) у реплики в `script.ts`
   и запушьте: CI синтезирует только её. Затем `npm run audio:pick:80-1-4` и
   `npm run audio:build:80-1-4`.
3. **Другой голос роли** — `roles` в `voices.json`.

После замены: `npm run test:80-1-4 && npm run srt:80-1-4 && npm run render:80-1-4`.
Сцены, жесты, планы, паузы и субтитры пересчитываются автоматически: всё
привязано к фактическим границам речи (`A4_FLOW`); паузы для зрителя заданы
одним событием `{ pause: … }` — от конца произнесённого вопроса до начала ответа.
