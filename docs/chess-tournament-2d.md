# BalaGo №27 — «Она сказала, что больше не любит шахматы» (2D)

Композиция **`BalaGoChessTournament2D`** (Remotion, 1080×1920, 30 fps).
Исходники: `src/chess-tournament-2d/`, озвучка: `public/audio/chess-tournament-2d/`.
Готовые файлы: `balago-27-chess-2d.mp4` и `balago-27-chess-2d-mobile.mp4` (540×960).

## История

Дочка (9–10 лет) отказывается от школьного шахматного турнира, а вечером папа
застаёт её за доской: она снова и снова решает одну задачу. Причина
раскрывается в разговоре у доски: дополнительные занятия заканчиваются в 15:00,
у папы в это время встречи, у мамы — работа, и она не хотела усложнять
родителям день. Папа слушает и просит расписание; родители вместе сравнивают
календари, сами находят BalaGo и оставляют **предварительную** заявку для
обсуждения маршрута (без водителя, оплаты, тарифов и подтверждённого
расписания). Мама пишет тренеру, что дочь хочет участвовать. Финал — новая
позиция, придуманная дочкой: «Ата, эми сенин жүрүшүң», папа снимает пиджак и
садится напротив. Последние 5 с — контактная карточка.

Хронология: крючок (отказ + вечерняя доска) → «Бир нече күн мурун»: кружок,
предложение турнира, обычный день (офис папы-инженера, совещание мамы, поездка,
бабушка) → вопрос о 15:00 и календарь папы → «Бир нече күндөн кийин»:
сообщение тренера → ужин → свет в комнате → разговор у доски → лист расписания
→ два календаря → поиск BalaGo и заявка → сообщение тренеру → новая позиция,
пиджак, ход папы → контакты.

## Шахматы

Доска 8×8, a1 — тёмное поле, h1 — светлое (у игрока белыми справа внизу
светлое). Дочка сидит со стороны белых, папа напротив; в плане со стороны
папы доска повернута вместе с камерой (`DAD_Q`).

| Позиция | FEN | Что показано |
| --- | --- | --- |
| Домашняя задача | `7k/4Q3/6K1/8/8/8/8/8 w - - 0 1` | Дочка примеряет ферзя e7 → f7 и возвращает на e7; один корректный ход — Qg7# (не объявляется) |
| Новая задача дочки | `2r5/8/8/8/8/8/2k5/K7 b - - 0 1` | Ход чёрных (папы); один корректный ход — Ra8#; папа только подносит руку к ладье |
| Учебная в кружке | `6k1/5ppp/8/8/8/8/8/R5K1 w - - 0 1` | Дочка делает ход Ra1–a8# (мат по последней горизонтали) |
| Воспоминание дома | `1k6/8/1K6/8/8/8/8/7R w - - 0 1` → после Rh1–h8# | Папа признаёт её ход |

Легальность (нет шаха стороне, которая не ходит; короли не соседствуют) и мат
после названных ходов проверяются тестом `scripts/chess-tournament-2d.test.mjs`.
Поднятая фигура в этот момент отсутствует на клетке (`held`), основание
опускается точно на клетку, контактная тень отделяется при подъёме.

  расписания: `props/Schedule.tsx`; телефон и экраны (переписка, календарь,
  поиск, страница BalaGo, форма, статус): `props/Phone.tsx`.
- Декорации: `sets/Home.tsx` (комната, коридор, кухня), `sets/Club.tsx`
  (кружок), `sets/CarViews.tsx` (салон), офис и совещание — в `scenes/Routine.tsx`.
- Звук: своя процедурная музыка `scripts/ch2d-music.mjs`, тихие эффекты
  `scripts/ch2d-foley.mjs` (фигура, лист, одно нажатие, салон). Шагов нет.

## Повторный рендер

```bash
npm ci
node scripts/generate-ch2d-voice.mjs   # из кэша; новые реплики — нужен ELEVENLABS_API_KEY
node --test scripts/chess-tournament-2d.test.mjs
npm run bundle && npm run stills:chess-tournament-2d
npm run render:chess-tournament-2d     # out/balago-27-chess-2d.mp4
node scripts/ch2d-loudness.mjs out/balago-27-chess-2d.mp4
ffmpeg -i out/balago-27-chess-2d.mp4 -vf scale=540:960:flags=lanczos -r 30 -c:v libx264 -crf 23 \
  -pix_fmt yuv420p -c:a aac -b:a 160k -movflags +faststart out/balago-27-chess-2d-mobile.mp4
node scripts/ch2d-speech-check.mjs out/balago-27-chess-2d.mp4
node scripts/verify-ch2d.mjs out/balago-27-chess-2d.mp4
```

В CI это делает workflow `.github/workflows/chess-tournament-2d.yml`: голос →
рендер → публикация обоих MP4 в предварительный релиз
`chess-tournament-2d-preview`.
