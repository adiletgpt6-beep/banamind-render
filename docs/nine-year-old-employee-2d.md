# BalaGoNineYearOldEmployee2D — «Тогуз жаштагы кызматкердин арызы»

Сценарий №22. Девятилетний Бектур кладёт папе на стол заявление «Мага эртерээк
кетүүгө уруксат беришиңизди суранам». Папа руководит небольшой IT-компанией,
мама — стоматолог; после школы сын едет в папин офис (он рядом со школой).
Настоящая причина — друзья строят во дворе картонный корабль. Папа слышит сына,
сам решает закончить работу раньше и помогает укрепить мачту. Вечером родители
сами находят BalaGo и оставляют **предварительную** заявку («Мектеп → Үй»,
14:30) — без цен, дат запуска, водителя и подтверждённого маршрута. Перед сном
бейдж «Бектур / Жардамчы» висит над столом, рядом — рисунок корабля с
Бектуром на носу. Контакты — ровно последние 150 кадров.

## Графический язык

По референсу (motion reel): тёплый бумажный фон `#F1EBDD` с редкой точечной
сеткой, почти чёрный `#111111`, оранжевый `#FF4B20`, синий `#2439F5`, жёлтый
`#FFD33D`, розовый `#F0ACC5`, картон `#BE9362`. Тяжёлый гротеск Inter Tight Black
(«9 ЖАШ», название, подписи), текст и субтитры — Onest; оба собраны с
расширенной кириллицей (Ү ү, Ө ө, Ң ң), лицензия OFL — `public/fonts/OFL-*.txt`.
Графические связки короткие и смысловые (`Transitions.tsx`): лист заявления →
белая плоскость офисного стола; цветные ленты; синий круг → доска с синей
рамкой; экран телефона → окно детской; жёлтый флажок рисунка → жёлтая карточка.
Внутри действия предметы не превращаются друг в друга. Во время признания и
ответа отца — спокойный фон, без лент, вращения и подпрыгивания. Надписи
референса («MAKE IT MOVE» и т. п.), рамки редактора и курсор не используются.

## Реквизит (`src/nine-year-old-employee-2d/props/`)

- `Letter.tsx` — заявление «АРЫЗ» / просьба в 4 строки / «Бектур, 9 жаш».
- `Badge.tsx` — бейдж «Бектур / Жардамчы», синяя полоса, клипса (на рубашке —
  через риг, `pose.badge`).
- `Photo.tsx` — фото друзей у корабля (рубка собрана, мачта лежит; Бектура нет).
- `Ship.tsx` — корабль во дворе и детский рисунок того же силуэта с Бектуром
  на носу (жёлтая рубашка, как у героя).
- `Laptop.tsx` — наружная крышка без экрана во фронтальном плане; экран — только
  со стороны папы; закрытие вокруг шарнира.
- `Car.tsx` — обычный белый седан, задняя дверь на шарнире у переднего края.

## Голоса

ElevenLabs `eleven_v3`, язык `ky`, stability 0,5, similarity 0,8, seed 221; темп и
высота тона не меняются. Рассказчик KG-teacher `EBOfpUWl9G5ltD2PkFgy`, папа
KG-husband `NVEGeFqcDqc5o29VoAQm`, мама KG-mother `5Xx0r0RX4XWEq5vEdv8p`, сын
KG-boy a2-3 `8QMDSJuOqCscZvQ6PqlL`.

Прежний KG-son не использован: он звучит как взрослая женщина. Детские описания
Voice Design сервис блокирует, поэтому `scripts/ny2d-son-probe.mjs` пробовал
только описания взрослых голосов, которыми в анимации озвучивают мальчиков, и
ремикс KG-son. Выбор сделан слепым прослушиванием моделью gpt-audio-1.5 (без
подсказки о роли) и по F0; это не заменяет прослушивание человеком — модель-
оценщик нестабильна, а профиль audeering относит голос к женскому, как и
большинство детских голосов.

## Звук

Музыка своя (`scripts/ny2d-music.mjs`, без бочки и щелчков): любопытство →
офис → тихо в признании → тепло (корабль, двор) → собранно (поиск) → мягкое
завершение; под речью приглушается (под голосом сына сильнее), к последнему
кадру затихает. Эффекты (`scripts/ny2d-foley.mjs`) — только с видимым действием:
лист, фото, дверь машины, крышка ноутбука, одно касание «Арыз жөнөтүү», тихий
салон. **Шагов нет.** Мастеринг −14 LUFS, true peak ≤ −1,5 dBTP.

## Повторный рендер

```
npm ci
npm run audio:voice:nine-year-old-employee-2d   # ELEVENLABS_API_KEY; готовое — из кэша, пересчёт timeline.json
npm run test:nine-year-old-employee-2d

ffmpeg -i out/balago-nine-year-old-employee-2d.mp4 -vf scale=540:960:flags=lanczos -c:v libx264 -crf 23 \
  -pix_fmt yuv420p -c:a aac -b:a 160k -movflags +faststart out/balago-nine-year-old-employee-2d-mobile.mp4
node scripts/verify-ny2d.mjs out/balago-nine-year-old-employee-2d.mp4
```

публикует оба MP4 в pre-release `nine-year-old-employee-2d-preview`.
