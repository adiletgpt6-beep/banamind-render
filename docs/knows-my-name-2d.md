# BalaGo №30 — «Ал менин атымды билеби?» («Он знает, как меня зовут?»)

Композиция **BalaGoKnowsMyName2D**, 2D, 1080×1920, 30 к/с, H.264/AAC.
Исходники — `src/knows-my-name-2d/`, озвучка — `public/audio/knows-my-name-2d/`.

## О чём фильм

Родители решают задачу школьной дороги через адреса и расписания, а сыну
важно познакомиться с человеком, который будет его встречать. Его вопрос
«Ал менин атымды билеби?» меняет разговор: семья учитывает не только маршрут,
но и самого мальчика — класс, выход у спортзала, знакомство и любимую
машинку. Родители сами находят BalaGo и оставляют **предварительную**
заявку. Утром сына в школу везёт папа; у ворот мальчик хочет сам назвать
своё имя при знакомстве. Затем — контактная карточка (последние 150 кадров).

Неизменные факты: мама руководит отделом, папа работает в IT, машина у семьи
есть (серо-синяя, без брендинга); дома мальчика может встретить няня, она
присматривает за младшей сестрой. BalaGo не приезжает, водитель не назначен,
ответа Адилета нет. Об Адилете — только «5000+ сапар», «Балдар менен иштөө
тажрыйбасы», «Балдарга араб тилин окуткан» (портрет — утверждённое фото
проекта `public/assets/portrait.jpg`). Номер WhatsApp 0998 08 38 28 — только
на карточке; другой контакт в настройках репозитория не найден.

## Герои и предметы

| Герой | Облик (rig/looks.ts) |
| --- | --- |
| Сын, 8–9 лет, 3 «Б» | `km2Boy`: тёмные волосы, светлая футболка с жёлтой полосой; `km2BoySchool`: тёмно-синяя кофта, тот же синий рюкзак |
| Мама | `km2Mom` (офис, жакет цвета морской волны), `km2MomHome` (кардиган того же оттенка); телефон в светлом чехле |
| Папа | `km2Dad`: короткая стрижка, без бороды и щетины, серо-голубая рубашка; блокнот и тёмная ручка |
| Няня | `km2Nanny`: пучок, ягодный кардиган, длинная юбка |
| Сестрёнка, ≈ 3 года | `km2Sister`: косички с бантиками |

Рабочий лист героев (спереди, ¾, сбоку и позы) — служебная композиция
`KM2CharacterSheet` (`src/knows-my-name-2d/CharacterSheet.tsx`), в фильм не
входит.

Постоянные предметы: синяя машинка с чёрными колёсами (`props/ToyCar.tsx`,
одна; в каждый момент либо на комоде, либо в руке, либо на столе), телефон
мамы (`props/Phone30.tsx`, экран внутри рамки, обратная сторона без экрана),
блокнот папы (`props/Notebook30.tsx`, строка проявляется за кончиком
ручки, вопросы без галочек), календарь папы (`props/Calendar30.tsx`).

## География

**Квартира** (`sets/Flat.tsx`): слева входная дверь (петли слева, ручка
справа), крючок для рюкзака, ковёр с кубиками; в центре обеденный стол —
мама слева, папа справа, рядом; сын стоит у свободного правого торца; за
ним комод с машинкой; над столом одна лампа, за столом окно.

**Школа** (`sets/School.tsx`): в центре основной вход (козырёк, три
ступени, двустворчатая дверь, петли у внешних краёв, ручки у середины,
вывеска «Мектеп»); справа крыло спортзала с отдельной дверью без ступеней
(петли справа, ручка слева, «Спорт зал»). Ворота слева, дорожка по
диагонали к основному входу. Та же схема — в блокноте папы.

## Сцены и приёмы референса

1. Вопрос, которого не было в списке — предметный план сверху → средний
   план стола → взгляд мамы поднимается.
2. «Ошол күнү эртерээк» — офис мамы, офис папы (ноутбук наружной крышкой к
   зрителю, пальцы на клавиатуре за крышкой), ключи и календарь (курсор
   переносит «Жолугушуу» на 16:00).
3. Няня и сестрёнка, мальчик вешает рюкзак на крючок.
4. «Кечинде» — поиск «Мектептен үйгө жеткирүү», сын подходит, K02; папа:
   глаза → голова → корпус, F01.
5. Тот же план вопроса; телефон ложится экраном вниз (касание стола); M01.
6. «3 «Б»» записывается после сказанного «Б»; схема школы; жест сына,
   взгляд папы; обводка и «Спорт залдын чыгышы».
7. Тот же телефон: карточка BalaGo → страница → Адилет; папа наклоняется,
   мама поворачивается к нему (M02).
8. Форма заявки → касание → «Алдын ала өтүнмө жөнөтүлдү»; вопросы в блокноте.
9. Машинка: хват с комода, K04, на стол рядом с блокнотом, вопрос записан;
   сын забирает машинку.
10. Синий рюкзак крупно (склейка по цвету) → «Эртеси эртең менен»: машина
    семьи, папа поправляет лямку.
11. Крупно сын (K05), папа наклоняется к нему (F02), кивок.
12. Несколько шагов к основному входу, папа у ворот, короткий взмах.
13. Карточка: BalaGo, «Балдар үчүн такси», WhatsApp, «Маалымат жана алдын
    ала каттоо — профилдеги шилтемеде».

Из референса (кадры ≈ 28, 36–48, 52–56, 60, 72 с просмотрены; звуковая
дорожка не прослушивалась): постоянные пропорции героев во всех ракурсах,
ясная география комнаты и двух школьных входов, позы «поза → действие →
поза», взгляды на собеседника и предмет, смена планов по смыслу, слои и
перекрытие, тёплый финал, отвечающий на вопрос начала.

## Голоса и звук

ElevenLabs `eleven_v3`, язык `ky`, stability 0,5, similarity 0,8; сохранённые
голоса проекта: рассказчик — KG-teacher, мама — KG-mother, папа —
KG-husband, мальчик — KG-son v7 remix-2 (выбран пробами
`scripts/km2d-voice-probe.mjs`, `voice-samples/knows-my-name-2d/probe/`).
Детский голос — синтез голоса взрослой актрисы озвучания (Voice Design не
создаёт детские голоса, библиотека голосов ключу недоступна); тон не
повышался, речь не ускорялась. Каждая новая реплика — 3 дубля, в фильм идёт
дубль с наименьшим штрафом (CER MMS + темп + профиль голоса). В TTS:
«БалаГо», «ай-ти», «үчүнчү бэ», в кадре — BalaGo, IT, 3 «Б».

Музыка — своя (`scripts/km2d-music.mjs`, без ударных), под речью
приглушается, сильнее — на K01, M01, K05, F02. Эффекты только по видимому
действию (`scripts/km2d-foley.mjs`): ручка, телефон на стол, машинка о стол,
шорох лямки, касание кнопки. Шагов нет.

## Команды

```bash
npm run audio:voice:knows-my-name-2d   # озвучка (ELEVENLABS_API_KEY; готовые реплики из кэша)
node scripts/km2d-music.mjs            # музыка
node scripts/km2d-foley.mjs            # эффекты
npm run test:knows-my-name-2d          # тесты
npm run render:knows-my-name-2d        # out/balago-30-knows-my-name-2d.mp4
node scripts/km2d-docs.mjs             # таблица тайминга в этом файле
```

CI — `.github/workflows/knows-my-name-2d.yml`: голоса → тесты, кадры, MP4
1080×1920 (−14 LUFS) и копия 540×960 → проверки → предварительный релиз
`knows-my-name-2d-preview`.
