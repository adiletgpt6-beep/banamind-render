# MUSLIM KIDS — Эксперимент 014: SAND UNIVERSE «Песчаная вселенная»

60-секундный мультфильм (1080×1920, 9:16, 30 fps, 1800 кадров, H.264 + AAC):
песчинки собираются в Землю, горы, дерево, звёздное небо и в общую композицию.
Основа: сура «Аль-Имран», 3:190–191 (перевод смысла Э. Кулиева).
Песок — только художественный материал анимации, не объяснение сотворения мира.

Отдельный проект: BalaGo и другие ролики репозитория не затрагивает.

## Запуск

```bash
cd muslimkids-sand-universe
npm install
npm run prepare:data            # маска материков (Natural Earth, world-atlas) → public/assets
pip install sherpa-onnx soundfile numpy scipy
python3 scripts/generate-voice.py   # русская озвучка (бесплатно, локально)
npx tsx scripts/analyze-motion.ts   # огибающая движения песка для звука
python3 scripts/generate-sfx.py     # шелест песка, ветер (без музыки)
python3 scripts/mix-audio.py        # итоговый микс −16 LUFS → public/audio/mix.wav
npm run studio                       # просмотр в Remotion Studio

# Финальный рендер (headless Chromium + программный WebGL «swangle»)
node scripts/render.mjs video MuslimKidsSandUniverse014 output/final/MuslimKids_SandUniverse_014.mp4 "" 3
# Контрольные кадры
node scripts/render.mjs stills MuslimKidsSandUniverse014 output/tests/control 2,5,10,14,19,23,28,32,38,43,47,54,59
```

Композиции: `MuslimKidsSandUniverse014` (финал), `MuslimKidsSandUniverse014-Preview540`
(превью 540×960) и короткие тесты `SandTestA-Macro`, `SandTestB-Assembly`,
`SandTestC-Disintegration`, `SandTestD-Reformation`, `SandTestE-Grand`.

## Архитектура

| Файл | Назначение |
| --- | --- |
| `src/engines/SandGrainGenerator.ts` | 5 типов неровных песчинок (кварцевая, угловатая, окатанная, плоская, многогранная): радиальная функция «скруглённого многогранника» + шероховатость; 3 уровня детализации (hero ≈30k граней, macro ≈1k, mid 80 граней); минеральная палитра, размеры (лог-нормально), ориентация |
| `src/engines/SandMorphEngine.ts` | состояния (цели по постоянному ID песчинки), сопоставление «полосы + ранги» (приближение optimal transport), переходы: индивидуальная задержка/длительность, Эрмитовы траектории через точки потока, easing, кувыркание, смена цвета, оседание с затухающим отскоком, макротень объекта (день/ночь, теневые склоны) |
| `src/engines/SandUniverseEngine.ts` | сборка всей хореографии и детерминированный расчёт любого кадра в буферы инстансинга |
| `src/engines/SandCameraController.ts` | кинематографическая камера: Эрмитовы сплайны + ограничитель Фритча–Карлсона (без рывков и перелётов) |
| `src/engines/SandLightingSystem.ts` | key / fill (hemisphere) / rim / ambient, пресеты по сценам с плавным смешиванием, туман глубины, фон |
| `src/materials/sandMaterial.ts` | библиотека матовых минеральных материалов (крапчатость, включения, вариация шероховатости, мягкое свечение только у «звёзд») |
| `src/geometry/*` | цели: Земля (реальная карта материков, океаны, леса, пустыни, лёд, облака), горы (пики, гребни, долина с рекой, снег), дерево (рекурсивный скелет, кора, кроны, дюна, семечко), небо (полоса, полумесяц, звёзды), общая композиция |
| `src/scenes/Scene01…08` | хореография 8 сцен: состояния, переходы, ключи камеры и света |
| `src/components/SandRenderer.tsx` | Three.js: 10 InstancedMesh (5 форм × 2 LOD) + hero-песчинка, ~10 draw calls на 80 000 песчинок |
| `src/components/Typography.tsx` | «ДЕНЬ/НОЧЬ», цитата (отдельный неподвижный текстовый слой, не из песка), финальная заставка |
| `src/timeline.json` | тайминг сцен, реплик, подписей — единый источник для видео и звука |

Детерминизм: все свойства песчинок из фиксированного seed, положение любой
песчинки — чистая функция времени (кадр 950 рендерится без предыдущих).

Переиспользование: новая форма = функция, возвращающая `ShapePoints`
(точки, цвета, порядок сборки, нормали), + сцена с переходом
(`assignGrains` → `fillState` → `TransitionSpec`). Мечеть, пейзаж, слова
урока — тем же движком.

## Озвучка и звук

* Голос: Piper VITS `ru_RU-ruslan-medium` через sherpa-onnx (локально, бесплатно).
  Для каждой реплики синтезируется несколько дублей, лучший выбирается
  автоматически по распознаванию Whisper (проверка произношения).
* Звук без музыки: микрощелчки песчинок, плотность которых пропорциональна
  числу реально летящих песчинок в кадре, мягкое оседание, тихий воздух и ветер;
  приглушение под голосом; спокойный финал под цитату.

## Результат (рендер 17.10.2026)

| Файл | Параметры |
| --- | --- |
| `output/final/MuslimKids_SandUniverse_014.mp4` | 1080×1920, 30 fps, 1800 кадров, 60,0 с, H.264 High ≈11,6 Мбит/с (2 прохода из мастера) + AAC 48 кГц стерео, faststart, −16 LUFS / −1,5 dBTP |
| мастер (локально, не в git: 387 МБ) | тот же рендер Remotion, H.264 CRF 16 ≈51 Мбит/с |
| `output/control/` | контрольные кадры 00:02 … 00:59, извлечены из готового MP4 |

80 000 песчинок, 10 draw calls + hero-песчинка. Рендер на CPU (SwiftShader):
≈3,2 с/кадр при 1080×1920, ≈1,6 ч на ролик; превью 540×960 ≈1 ч.
MSAA на программном GL в 3 раза медленнее, поэтому сглаживание — FXAA после тонмаппинга.

Ограничения: голос — локальный нейросинтез Piper (естественнее классических TTS,
но интонации проще студийной озвучки; платный API не использовался).
Официального логотипа Muslim Kids в проекте нет — в финале типографическая заставка.
