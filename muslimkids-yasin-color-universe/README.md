# Muslim Kids — Эксперимент №15: «Ясин — Вселенная цветных точек»

**YASIN — COLOR UNIVERSE.** Образовательная точечная инфографика о суре «Ясин»
(36-я сура, 83 аята, мекканская) для детей 6–14 лет. 1080×1920, 9:16, 30 fps,
80 с (2400 кадров), H.264 + AAC, русская озвучка, без музыки.

Отдельный проект: не зависит от кода BalaGo и предыдущих экспериментов.

## Запуск

```bash
npm install
python3 scripts/generate-voice.py      # озвучка → public/audio/narration.wav, src/voice.json
node scripts/generate-sfx.mjs          # деликатные эффекты → public/audio/sfx.wav
npm run studio                         # предпросмотр
npm run test:render                    # первый тест 9 с: точки → 36 → 83 → сетка 83
npm run render                         # финал → output/final/MuslimKids_Yasin_ColorUniverse_015.mp4
node scripts/control-frames.mjs        # контрольные кадры из настоящего рендера
```

Remotion использует системный Chromium (`remotion.config.ts`, переменная `REMOTION_BROWSER`).

## Архитектура

| Модуль | Назначение |
| --- | --- |
| `engines/DotMorphEngine.ts` | Пул из 7000 точек с постоянными ID. Для каждого перехода один раз считается соответствие «точка → цель» сопоставлением рангов по пространственному ключу (кривая Гильберта, угол, высота, x…). Те же точки перестраиваются в новую форму; лишние точки скрыты и следуют за видимой точкой-якорем, поэтому новые точки «отделяются» от соседей. Группы частей (`match`) сохраняют неподвижными общие элементы (земля остаётся землёй, звёзды — звёздами). |
| `engines/ShapeSamplingEngine.ts` | Векторный силуэт (Canvas-путь или глиф шрифта) → маска → гексагональная укладка точек; цвет каждой точки = градиент части + параметр u (x, y, радиус, угол, шум, индекс, своя функция). |
| `engines/DotTrajectoryEngine.ts` | Траектории: curve, spiral, scatter (радужная сборка через облако), wave, rise, fall, direct. |
| `engines/ParticleColorSystem.ts` | Палитра из ТЗ + производные оттенки, 50+ градиентов, LUT в линейном пространстве, плавный перелив без «шва». |
| `engines/ColorDotEngine.ts` | Отрисовка Canvas 2D: фон-градиент, тонкая сетка как в референсе, мягкий bloom в ¼ разрешения на тёмных фонах. |
| `engines/CameraController.ts` | Приближения/отдаления точечного слоя. |
| `shapes/draw.ts`, `shapes/catalog.ts` | Библиотека силуэтов: «?», 36, 83, сетка ровно из 83 точек (8×10+3), книга, сердце, следы, сухая/зелёная земля, капли, росток, колосья, финиковая пальма, виноград, Солнце, дуга пути, Луна и 5 фаз, орбиты, Земля, рука, галочка, цветные ленты. |
| `scenes/Scene01…09` | Девять сцен: формы, переходы, надписи, звуковые акценты. |
| `timeline.ts` | Сборка сцен, фоны (долгие мягкие наплывы, без стробоскопа), камера. |

Каждый кадр зависит только от номера кадра (`useCurrentFrame`), случайность — с фиксированным
сидом, порядок рендера кадров не важен. Арабская надпись «يسٓ» и цитата — отдельные
неподвижные типографские слои (Amiri Quran / Manrope), из точек не собираются.

## Проверка текста (перевод смысла Э. Кулиева)

Сверено с изданием `rus-elmirkuliev` (зеркало fawazahmed0/quran-api на GitHub; quran.com
из окружения был недоступен), копия суры — `scripts/source-kuliev-36.json`:

- 36:2 «Клянусь мудрым Кораном»; 36:12 — запись совершённого и оставленного после себя;
- 36:33–35 — мёртвая земля оживлена, зерно, сады из финиковых пальм и винограда, плоды;
- 36:37–40 — ночь и день, Солнце, положения Луны; **36:40 «…Каждый плывет по орбите»** (цитата в кадре дословна, помечена как часть аята);
- 36:78–83 — оживление после смерти, могущество Аллаха.

Озвучка — педагогический пересказ, не цитаты. Фраза сценария «После дождя она оживает»
заменена на «Мёртвая земля оживает» (ближе к 36:33). Дождь — только художественная иллюстрация.
Не используются: «Сердце Корана», обещания награды, изображения Аллаха, пророков, ангелов,
загробного мира.

## Озвучка

Бесплатный офлайн-синтез Piper (`ru_RU-denis-medium`, sherpa-onnx), по предложению, с
паузами; ударения «Яси́н», «Алла́х», «зна́мение» исправлены собственным словарём espeak-ng
(`scripts/espeak-ru_extra.txt`). Платный TTS не использовался. Проверка — распознавание
речи обратно (Whisper small, офлайн).
