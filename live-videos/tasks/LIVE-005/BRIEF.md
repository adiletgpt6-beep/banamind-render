# LIVE-005 — первое видео из BalaGo Video Studio

**Источник правды:** [GitHub Issue #76](https://github.com/adiletzainidinov/balago-video/issues/76).
**Статус:** исходник загружен и проверен в приватном Cloudflare R2; монтаж ещё не сделан.

## Как Claude Code получает реальный MP4, без пересылки исходника в чат

В карточке #76 напишите строго `/prepare-source` (это запускает
[Live source handoff](../../../.github/workflows/live-source-handoff.yml)) либо запустите
workflow вручную с `issue_number=76`. Доступ предоставляется приватным
GitHub Actions Artifact **LIVE-005-source-private** ровно на 1 день.

Успешный запуск автоматически оставляет в #76 комментарий с точным
`gh run download` и ссылкой на приватный artifact. В Claude Code:
1. Прочитать #76 и комментарий об успешном handoff.
2. Получить исходник, используя `gh run download <RUN_ID> -n LIVE-005-source-private -D /tmp/balago-LIVE-005`.
3. Убедиться, что это оригинальное MP4 (видео, аудио, длительность); полностью
   посмотреть и прослушать видео. Не делать вид, что исходник просмотрен,
   если инструмент не смог открыть файл.
4. Никогда не коммитить оригинальный MP4 и не публиковать его в Release,
   не копировать API ключи в код или в комментарии GitHub.
5. Если artifact уже истёк, запросить новый через `/prepare-source`.

В рендере GitHub Actions ключи `R2_*` доступны на сервере.
[`live-videos.yml`](../../../.github/workflows/live-videos.yml)
уже передаёт их в шаг подготовки источника; для preview использовать
`node apps/balago-studio/scripts/fetch-source.mjs live/raw/c1a07194-c62b-4504-85f8-334b2bd24c71/source.mp4 <путь_к_MP4_в_public>`.
Когда Claude создаёт `task.json`, источник должен быть указан как
`"sources": {"r2": {"key": "live/raw/c1a07194-c62b-4504-85f8-334b2bd24c71/source.mp4"}}`.
Создать также `TASK.md`. Регистратор LIVE пропускает папку с одним BRIEF.md
до появления готового `task.json`, чтобы не запускать рендер преждевременно.

Это не означает, что Claude Code автоматически запускается от создания Issue.

## Монтаж: сначала анализ, затем индивидуальный стиль

- Полностью просмотреть LIVE-005, понять содержание и интонацию. Не угадывать,
  что говорит автор по миниатюре, и не копировать склейки из LIVE-004.
- Учесть `AGENTS.md`, `CLAUDE.md`, `live/STYLE.md`,
  `live-videos/RULES.md`, `live-videos/reference/REFERENCE.md`,
  карточки последних 5–10 LIVE.
- Бренд: BalaGo, Бишкек; живое лицо и оригинальный голос. Никакой
  искусственной озвучки, если автор отдельно не попросил.
- **Кинетические кыргызские субтитры:** короткие фразы точно по речи,
  белый и жёлтый акценты, динамичные позиции по сценам, без однотипной
  широкой синей подложки и повторяющегося текста.
- Выразительный, светлый, современный монтаж — смысловые зумы,
  анимации и графика под конкретную речь. Не перегружать.
- Если автор произнёс приглашение: визуально подсказать ссылку в шапке
  Instagram `@balago.kg` и WhatsApp `0998 08 38 28` строго по словам
  и жестам, без дублирующей голосовой вставки. Если CTA в исходнике
  отсутствует, зафиксировать проблему в #76 перед финальной сборкой.
- Один ролик = одна новая композиция, свой `task.json` только
  **после того, как исходник изучен и монтаж/план готовы**.
- Первый рендер **только превью 540×960**; проверить читаемость субтитров,
  звук и синхронность. Полный финал 1080×1920 / 30fps — только после
  одобрения владельца. Старые видео/2D не пересобирать.

## Дальнейшая автоматизация

Первая связка — контролируемая: Studio -> Issue -> приватный artifact
для Claude Code -> план монтажа -> превью -> одобрение -> финал.
Запуск Claude Code без открытия чата потребует отдельной интеграции
(и её авторизации/оплаты); **не заявлять об автоматическом AI-монтаже,
пока он не работает и не протестирован.**
