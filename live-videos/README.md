# Живые видео BalaGo — производство

Постоянная система для серии из 150 живых роликов (съёмка + голос основателя
+ сдержанная смысловая графика). 2D-анимацию эта папка не затрагивает.

| Файл | Что это |
| --- | --- |
| [RULES.md](RULES.md) | постоянные правила живых видео (обязательны) |
| [../live/STYLE.md](../live/STYLE.md), [../live/WORKFLOW.md](../live/WORKFLOW.md) | гибкий стиль, решения владельца, этапы производства |
| [reference/](reference/) | единственный референс монтажа (хранится один раз) |
| [REGISTRY.md](REGISTRY.md) | реестр заданий LIVE-001 … LIVE-150 |
| [templates/](templates/) | шаблоны `task.json` и `TASK.md` |
| `tasks/LIVE-NNN/` | задание: данные (`task.json`) и описание (`TASK.md`) |

## Порядок работы над одним видео

1. Исходники загружаются в отдельный GitHub Release.
2. `npm run live:new -- <tag> "<название>"` создаёт `tasks/LIVE-NNN/`.
3. Расшифровка реальной речи с таймкодами. Для кыргызской речи —
   MMS в CI, как в `scripts/live04/asr.py`.
4. Прочитать карточки последних 5–10 роликов, выбрать направление (`live/STYLE.md`).
   План: 0–3 вставки на конкретные слова (`plan.ts` задания). Финал естественный:
   CTA автора не дублируется, Бишкек — надписью, если не назван.
5. Композиция в `src/live-videos/liveNNN/`. Общие части — в `src/live/`
   (субтитры, контактный блок, иконки, тема).
6. `stage: "preview"` → push → workflow `live-videos.yml` публикует
   превью 540×960 в Release `previewTag`.
7. После согласования `stage: "final"` → тот же workflow выдаёт
   оригинал 1080×1920, 30 fps, H.264/AAC и превью.
8. Новая версия того же видео — новая запись в `versions` с новой
   композицией и новым `previewTag`. Старые версии не перезаписываются.

## Команды

- `npm run live:new -- <tag> "<название>"` — новое задание.
- `npm run live:check` — проверка всех `task.json` и планов (лимиты вставок и звуков).
- `node scripts/live-videos/stills.mjs <Composition> [outDir]` — контрольные кадры (после `npm run bundle`).
- Ручной запуск: Actions → **Live videos (LIVE-NNN)** → Run workflow → `task: LIVE-004`.
