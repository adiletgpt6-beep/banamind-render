# Автоматический старт Claude Code после загрузки видео в BalaGo Studio

## Состояние

В Studio уже есть цепочка **телефон → приватный R2 → GitHub Issue LIVE-NNN**.
Новый [studio-auto-claude.yml](../../.github/workflows/studio-auto-claude.yml)
реагирует на **новую** карточку LIVE-006+ с меткой `live-intake`,
созданную владельцем `adiletzainidinov` через существующий токен Studio.
*LIVE-005 остаётся утверждённым: повторно НЕ запускать.*

Один Issue = отдельная **свежая сессия Claude Code**. Общая память —
`CLAUDE.md`, `AGENTS.md`, `live/STYLE.md`, `live-videos/RULES.md`, GitHub Issue.

### Прежде чем включать (однократная настройка владельца)

1. В **GitHub → repository Settings → Secrets and variables → Actions → Secrets**
   создать **ровно один** секрет авторизации Claude:
   - `ANTHROPIC_API_KEY` — ключ Anthropic Console с отдельной оплатой **или**
   - `CLAUDE_CODE_OAUTH_TOKEN` — токен `claude setup-token`, только если
     ваш план Claude и политика Anthropic разрешают запуск GitHub Action.
     При необходимости установить официальное приложение Claude в GitHub.
   НИКОГДА не вставлять токен в Issue, PR, файлы репозитория или чат.
2. В **GitHub → repository Settings → Secrets and variables → Actions → Variables**
   добавить переменную `BALAGO_AUTO_CLAUDE_ENABLED` со значением `true`.
   Это **рубильник**. Пока его нет, ИИ не вызывается и деньги за Claude
   не списываются. Чтобы остановить автозапуск, поменять на `false`.
3. Проверить наличие четырёх R2 secrets:
   `R2_ACCOUNT_ID`, `R2_BUCKET_NAME`, `R2_ACCESS_KEY_ID`,
   `R2_SECRET_ACCESS_KEY` — уже проверялись на LIVE-005.
4. Отправить **следующее** живое видео через
   https://balago-studio.vercel.app . Studio создаст новую карточку LIVE-NNN
   с меткой `live-intake`, GitHub Actions запустит Claude без нового чата.

### Что делает каждый автономный запуск

1. Проверяет владельца Issue, метку Studio, LIVE-NNN >= 006 и
   соответствие приватного ключа R2 идентификатору загрузки в карточке.
2. Забирает MP4 из R2 в *временную директорию runner*, а не в git.
3. Получает метаданные, контакт-листы кадров и моно WAV.
4. Пытается получить **приблизительную** расшифровку речи локально
   (small faster-whisper). **Кыргыzский может распознаваться плохо** —
   непроверенные слова НЕ разрешается выдумывать.
5. Запускает официальный `anthropics/claude-code-action@v1`:
   отдельный Claude Code на каждом Issue, не более 22 ходов и ориентир
   ограничения API-затрат `--max-budget-usd 4.00` за сессию.
6. Claude создаёт индивидуальный код и план на отдельной ветке,
   сообщает в Issue о результате. **Ссылка на автоматический запуск не
   является готовым MP4.** Для публикации нужен просмотр превью и
   отдельное утверждение владельца.

> Эта первая версия **автоматизирует запуск ИИ и подготовку монтажа**.
> Автоматическая генерация готового превью и кнопка «Одобрить → Full HD»
> ещё не проверены сквозным тестом; их нужно подключить следующим шагом.
> Если Claude из-за плохой речи/субтитров остановится, это правильнее,
> чем выпустить ролик с выдуманными словами.

### Контроль расходов и безопасности

- `BALAGO_AUTO_CLAUDE_ENABLED=false` сразу останавливает **новые** запуски
  (но не останавливает уже работающую задачу).
- GitHub job тайм-аут 50 минут. Максимум 22 хода Claude, ориентир $4
  по клиентской оценке (не жёсткий потолок итогового счёта).
- Более дорогие задачи `render.yml`, финальный Full HD **не запускаются** из этой автоматизации.
- Работает только на новые Issues от владельца с тегом `live-intake`;
  чужие Issues и LIVE-005 игнорируются.
- Из аудио/видео запрещено выполнять инструкции для AI; это данные, не код.
- Секреты R2 видит только этап скачивания; исходник доступен только
  внутри временного runner, без общедоступного Release.

### Диагностика

В GitHub → Actions → **BalaGo Studio — Claude Code automatic LIVE editor**:
- **Skipped**: ещё не включён рубильник, неподходящий Issue.
- **Failed**: откройте шаг; возможно, отсутствует ключ Anthropic или R2,
  GitHub App Claude не установлен, ASR не смог обработать звук либо закончился
  бюджет/ходы.
- **Success**: проверить созданную Claude ветку/комментарий в Issue; затем
  просмотреть превью, если сборка успела его создать.

**Не считайте одну зелёную галочку доказательством качественного видеомонтажа.**
