# Статус переноса BalaGo / BanaMind

Перенос продолжается. Это публичная копия проверенных снимков веток, а не зеркало оригинальной истории Git.

Источник: `adiletzainidinov/balago-video` (PRIVATE).
Новая рабочая копия: `adiletgpt6-beep/banamind-render` (PUBLIC).

Уже опубликованы и сверены по SHA дерева Git:

- `main`: основной код, React/Remotion, сценарии, производственная документация и архивы метаданных.
- `docs/banamind-500-production-system`: `books/500-series/REGISTRY.csv`, `HANDOFF.md` и правила производства BanaMind. Нумерация и статусы реестра сохранены.

Остальные рабочие ветки публикуются. В источнике обнаружено 223 ветки и 214 различных последних коммитов. Их оригинальные имена и SHA сохранены в `.migration/archive/source-branches.json`.

Все workflow перемещены в `.github/workflows-disabled/` и не исполняются. Рендеры, TTS и платные функции при переносе не запускались. Исходный репозиторий не изменялся.

## Ограничения

- История коммитов, исходные авторы Git-коммитов и связи между ветками не импортированы. Новые коммиты содержат только безопасные снимки.
- 142 тега и 143 релиза сохранены как архив метаданных. Нативные теги и релизы не созданы; 856 вложений релизов (~31,2 ГБ) не скопированы.
- 162 PR, 6 issues и 179 комментариев сохранены в `.migration/archive/` как JSON, а не как работающие PR/issues GitHub. Полнота истории ревью не подтверждена.
- Приватные тексты книг, неподтверждённые медиа и архивы не опубликованы. Старый статус SOURCE_READY в реестре не означает, что сам текст книги присутствует в этой публичной копии.
- Публикация изображения из приватного источника отклонена автоматической проверкой; изображения оставлены вне публичной копии. Лицензии добавляемых шрифтов OFL сохранены в `.migration/font-licenses/`.
- Проверены доступные текстовые файлы снимков веток; вся старая история Git недоступна для полного сканирования через это подключение. Подтверждённых действующих секретов в проверенных файлах не обнаружено.
- Настройки, секреты, Actions artifacts, LFS-объекты и внешние хранилища автоматически не переносятся. Административные настройки GitHub Actions старого и нового аккаунта через это подключение не менялись.

Изначальный README целевого репозитория сохранён в `.migration/original-target-README.md` и в его первоначальном Git-коммите.

После завершения публикации этот отчёт будет дополнен итоговой сверкой всех веток и командами для недоступного переноса истории.
