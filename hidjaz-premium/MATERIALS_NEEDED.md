# Что нужно от владельца для рекламы @hidjaz.premium

Instagram из облачной среды Claude Code недоступен, а в открытом поиске
нет ни одного упоминания аккаунта (подробно — `INSTAGRAM_ANALYSIS.md`).
Без этих материалов нельзя установить ассортимент, поэтому ролик пока
собран только как технический прогон с заглушками.

## 1. Скриншоты профиля (с телефона, без обрезки)

1. Шапка профиля: аватар/логотип, имя, bio, ссылка, кнопки (Написать, WhatsApp
   и т. п.), счётчики публикаций и подписчиков.
2. Названия всех Highlights (актуальное) + по 1–2 скриншота из каждого,
   особенно «Цены», «Отзывы», «Доставка», «Как заказать».
3. Первые 3 ряда сетки (9–12 публикаций), закреплённые посты.
4. 3–5 самых популярных Reels: первый кадр и экран с числом просмотров.
5. По одному скриншоту комментариев под 3–5 постами с вопросами покупателей
   (цена, размеры, ткань, доставка) — для раздела «вопросы и возражения».

## 2. Фотографии товара (оригиналы, не скриншоты)

- 6–12 фото **того товара, который нужно рекламировать** (или 2–3 товаров),
  желательно 1080 px и больше по короткой стороне.
- Обязательно: 1 «геройское» фото целиком, 2–3 крупных плана деталей
  (ткань, отделка, упаковка), 1–2 фото «в использовании».
- Логотип в PNG/SVG (если есть) — иначе возьму с аватара.
- Если у фото есть автор/модель — подтверждение, что их можно использовать в рекламе.

## 3. Факты (текстом, 5 минут)

- Что именно продаётся и какой товар главный для рекламы.
- Подтверждённые характеристики: материал/состав, размеры, цвета, комплект.
- Цена или «цена в Direct» (в ролик цену ставлю только по вашему указанию).
- Город/страна, доставка (куда, сроки), способ заказа: Direct, WhatsApp
  (номер), ссылка в профиле, адрес магазина.
- 2–3 отличия от конкурентов, которые вы готовы подтвердить.
- Конкуренты, на которых ориентируетесь (2–5 аккаунтов) — для `/ig-viral`.

## Куда положить

Любой способ:

- приложить в этот чат;
- в репозиторий: фото → `hidjaz-premium/public/products/`, логотип →
  `hidjaz-premium/public/brand/`, скриншоты → `hidjaz-premium/research/screenshots/`
  (репозиторий **публичный** — файлы увидят все);
- в Cloudflare R2 и прислать ключ объекта.

## Альтернатива: открыть доступ

Добавьте в Network access окружения домены `instagram.com`,
`cdninstagram.com`, `fbcdn.net` — тогда я прочитаю публичный профиль сам.
Instagram без входа может показать только часть профиля или стену входа;
входить в аккаунт от вашего имени я не буду.
