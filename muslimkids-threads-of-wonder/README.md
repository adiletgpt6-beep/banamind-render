# MUSLIM KIDS — эксперимент 011: THREADS OF WONDER («Нити мироздания»)

Образовательный 3D-мультфильм **«Удивительная картина мира»** (сура «Аль-Имран», 3:190–191)
для детей 5–12 лет. Русский язык, 60 с, 1080×1920, 30 fps, 1800 кадров, H.264 + AAC.
Визуальный стиль — **MUSLIM KIDS — WOVEN WORLDS («Тканые миры»)**.

Это отдельный проект: BalaGo и другие ролики репозитория он не затрагивает
(собственный `package.json`, `node_modules`; исключён из CI-рендера BalaGo).

Итоговый файл: `output/final/MuslimKids_ThreadsOfWonder_011.mp4` (в git не хранится,
выдаётся отдельно; см. «Сборка»).

## Анализ видео-референса (только планка качества)

Референс: 79,3 с, 720×1280, 30 fps, H.264/AAC. Инфографика из **частиц-точек** в плоском 2D:
резкие смены чёрного и белого фона, один синий акцент, заголовок сверху с выделенным словом,
вывод одного объекта в центре кадра. Новые объекты появляются так: облако точек → сборка в форму
за ≈0,5–1 с с лёгким «рассыпанием», затем полная остановка. Старые объекты распадаются в облако
точек или исчезают на резкой смене фона. Камера неподвижна, глубины и света нет (плоская графика);
внимание держат 1 объект + 1 строка текста; одновременно движутся сотни точек, но всегда в
понятную форму. Сила ролика — **плавные морфинги «хаос → узнаваемая форма» и ясность**.

Что мы взяли как планку: плавность морфингов, ясность «одна мысль — один объект», ритм ≈ 6–10 с
на сцену. Что сделали иначе (своё): вместо точек — **непрерывные объёмные нити**, настоящая 3D-
глубина, свет и тени, кинематографическая камера, материалы ткани; наши сцены, композиции,
траектории, переходы, звук. Кадры, звук и графика референса в фильм не включены.

## Сценарий и синхронизация

| Сцена | Время | Что происходит |
|---|---|---|
| 1. Одна золотая нить | 0–6 с | макро шёлковой нити, петля, 2-я и 3-я нити, переплетение «над — под» |
| 2. Тканая Земля | 6–15 с | полотно изгибается в сферу, материки по маске суши, вращение, день/ночь |
| 3. Горы из нитей | 15–24 с | контролируемое расплетение → волнистое полотно → хребты, снег, река, облака |
| 4. Дерево из волокон | 24–34 с | семечко-клубок → корни → росток → утолщение ствола → ветви → листья |
| 5. Небо и картина | 34–45 с | нити неба из кроны, серебряные звёзды, отъезд: всё — один гобелен в раме |
| 6. Слова из Корана | 45–54 с | спокойная камера, отдельный типографический слой с цитатой |
| 7. Возвращение нити | 54–60 с | золотая нить выходит из Солнца, завиток, «А что удивляет тебя?», MUSLIM KIDS |

Реплики стоят по фактическим длительностям TTS (`src/data/voice-timings.json`,
`src/timeline.ts`): «нить» — нить, «Земля» — сформированная Земля, «горы» — растущие хребты,
«дерево» — растущее дерево, «небес» — тканое небо. Во время цитаты движение замедлено.

**Цитата сверена** с переводом смысла Э. Кулиева (tanzil.net/trans/ru.kuliev через пакет
`quran-json`): 3:191 — «…Господь наш! Ты не сотворил это понапрасну…». В сцене 5 — педагогическое
изложение темы 3:190, не дословная цитата. Текстильные нити — только художественный метод;
Аллах и пророки не изображаются, нити не показаны как первооснова творения.

## Архитектура

```
src/
  engines/
    ThreadsOfWonderEngine.ts   оркестратор: состояние всех нитей для любого кадра
    ThreadContinuityEngine.ts  ID нитей, цепочки форм, морфинг бегущим фронтом с провисанием
    ThreadWeavingEngine.ts     полотняное переплетение: σ = (−1)^(i+j), разведение на 2A ≥ 2r
    WovenSculptureEngine.ts    изгиб полотна в сферу (кривизна κ: 0 → 1/R), драпировка рельефа
    ThreadUnravelEngine.ts     расписание расплетения Земли (параллели с севера, меридианы позже)
    TextileDynamicsEngine.ts   сглаживание стыков, колебания свободного конца, провисание, ветер
    ThreadCameraController.ts  сплайн Эрмита по ключам с непрерывной скоростью
    ThreadLightingSystem.ts    ключ (тени), заполняющий, контровой, окружение — по сценам
    palette.ts                 палитра WOVEN WORLDS и типы волокон
  geometry/TubeBuilder.ts      объединённые буферы трубок: 3-прядная скрутка, рамки параллельного
                               переноса, сужение кончиков, LOD
  materials/                   ThreadMaterialSystem: шёлк, золото, хлопок, грубое волокно, шерсть, серебро
  textures/fiberTextures.ts    процедурные карты нормалей волокон, саржа подложки неба, свечение
  scenes/                      формы и хореография сцен 1–5, ключи камеры
  components/                  ThreadWorld (R3F), Typography (отдельный слой текста)
  compositions/                MuslimKidsThreadsOfWonder011
```

Ключевые решения:

* **Настоящие нити.** Каждая нить — трубка вдоль 3D-кривой с трёхпрядным сечением
  `r(θ) = R(1 + lobe·cos 3(θ − φ(a)))`; пряди закручиваются вдоль длины (угол ≈ 30°), сверху —
  процедурная карта микроволокон. Материалы отличаются шероховатостью, ворсом (sheen),
  анизотропным блеском шёлка.
* **Переплетение без пересечений.** Уток и основа в каждом узле разведены по нормали полотна
  на ±A (A чуть больше радиуса нити) с противоположными знаками — нити проходят строго над/под.
* **Непрерывность.** Параллели Земли становятся рядами гор, меридианы — основой гор, полярные
  шапки — снегом на вершинах, облака Земли — облаками в горах; зелёные нити лугов — листьями;
  тёмно-синие нити неба вытягиваются из верхних веточек; золотая нить — Солнце и финал.
* **Детерминизм.** Всё — чистая функция номера кадра (нет `Date`, `requestAnimationFrame`,
  случайности без зерна): кадр 1200 корректен без кадра 1199, превью = финал.
* **Оптимизация.** Одна draw call на тип волокна (объединённые буферы, переиспользуются),
  кэш статичных форм, LOD по радиусу/кадру, процедурная текстура для большой подложки неба.

## Озвучка и звук

* Голос: офлайн **Piper `ru_RU-denis-medium`** (датасет CC0), мужской, тёплая обработка
  (`scripts/voice.py`, модель — `scripts/fetch-voice.sh`). Разборчивость проверена локальным
  ASR (`scripts/asr_check.py`, sherpa-onnx GigaAM v2). Платные сервисы не использовались
  (настроенный OpenAI TTS недоступен — у ключа закончились кредиты).
* Без музыки (правило Muslim Kids). Деликатные процедурные эффекты: шелест нити, мягкий шорох
  переплетения, воздушные переходы, ветер в горах, шелест листьев; на цитате — только голос
  (`scripts/mix_audio.py` → `public/audio/mix.wav`, −16 LUFS).

## Сборка

```bash
npm install
npm run landmask            # маска суши из world-atlas (уже лежит в src/data)
bash scripts/fetch-voice.sh && npm run voice && npm run audio
npm run stills -- preview   # контрольные кадры 540×960 из реальной анимации
npm run render              # финал: output/final/MuslimKids_ThreadsOfWonder_011.mp4
```

Рендер WebGL идёт программно (SwiftShader, `--gl=swangle`); путь к Chromium задаётся
`BROWSER_EXECUTABLE` (по умолчанию — предустановленный headless shell).

## Переиспользование

Сценарий меняется через `scenes/*` и `timeline.ts`; формы — функции `s → xyz` с цепочкой
`ThreadKey` для каждой нити; палитра и материалы — `palette.ts`, `materials/*`; голос —
`SCRIPT` в `scripts/voice.py`; хронометраж и камера — `timeline.ts`, `scenes/cameraPath.ts`.
