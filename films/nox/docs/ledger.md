# Учёт условных денег Нокса (ledger)

Все суммы — вымышленные «огоньки» (абстрактные единицы), иллюстрация механизмов, не прогноз и не норма.
Масштаб на экране обозначается подписью: в главе 1 «1 огонёк = 1 единица», в главе 3 «1 огонь = 100 единиц».
Начислений, процентов и доходности нет нигде: запас растёт только из отложенного заработка.

| Глава | Событие | Заработок | Необходимое | Покупки/радости | В сосуд | Сосуд после |
|---|---|---|---|---|---|---|
| 01 | первый месяц | 800 | 700 | 100 | 0 | 0 |
| 01–02 | второй месяц (прибавка «исчезла») | 1000 | 700 | 300 | 0 | 0 |
| 02 | другой вариант того же месяца (сравнение) | 1000 | 700 | 200 | 100 | — (пример) |
| 03 | месяц 1 нового решения | 1000 | 700 | 200 | 100 | 100 |
| 03 | месяц 2 | 1000 | 700 | 200 | 100 | 200 |
| 03 | месяц 3 (3 × 100 = 300) | 1000 | 700 | 200 | 100 | 300 |
| 06 | плата первого заказчика | часть того же месячного заработка (не новый «клад») | | | | 300 |
| 08 | поломка станка: ремонт 180 из запаса (300 − 180 = 120) | | | | −180 | 120 |
| 09 | ограниченный опыт: «детали с полки» — денег из сосуда не тратит | | | | 0 | 120 |
| 10 | три месяца по 100 из заработка | 1000/мес | 700 | 200 | +100 ×3 | 220 → 320 → 420 |
| 12 | «обещание»: Нокс запас не отдаёт | | | | 0 | 420 |
| 15 | тот же условный месяц в финале | 1000 | 700 | 200 | 100 | 420 + 100 = 520 |

Проверки арифметики (V072): 700 + 100 = 800; 700 + 300 = 1000; 700 + 200 + 100 = 1000; 3 × 100 = 300;
300 − 180 = 120; 120 + 3 × 100 = 420; 420 + 100 = 520. Потраченные 180 не появляются в сосуде и не оплачивают ничего другого.
В главе 15 повторяется композиция первого кадра, но сосуд уже не пуст: 420 + 100 = 520 (видимое отличие от начала).
