# Проверка озвучки распознаванием (Whisper medium, faster-whisper)

Автоматическое распознавание помогает найти смысловые ошибки (числа, отрицания, имена), но не доказывает приятность тембра и естественность исполнения (G095). Расхождения ниже проверены вручную по тексту.

Блоков: 116; общий WER ≈ 0.030
